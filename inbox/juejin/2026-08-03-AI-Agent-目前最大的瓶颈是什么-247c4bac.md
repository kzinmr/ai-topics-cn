# AI Agent 目前最大的瓶颈是什么？

AI Agent 目前最大的瓶颈不是“不会完成复杂任务”，而是不能以可测量、可复现、可恢复、可治理的方式持续完成复杂任务。 模型决定能力上限，工程决定可用下限。
