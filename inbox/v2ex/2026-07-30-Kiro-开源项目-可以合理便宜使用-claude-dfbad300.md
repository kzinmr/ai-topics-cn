# Kiro 开源项目，可以合理便宜使用 claude

问题所在
由于 A\ 不做人，以及最近的封号潮，想要使用比较纯净的 claude 系列模型难上加难（原价 API 除外）
项目优势
目前使用 kiro 这种方案是相对好的替代品了
已经用在许多企业内部使用，解决了广大程序员的 AI 需求
虽然有很多 kiro 的开源项目，但是都有一些问题所在，当前项目 
https://github.com/yupanzi/kiro2claude
解决了如下问题：

credit 实时显示和计算
kiro 的缓存推测（官方无输出）
协议兼容，claude 和 openai 协议

唯一的要求就是 AWS IDC 认证，有需要的可以共同开发
