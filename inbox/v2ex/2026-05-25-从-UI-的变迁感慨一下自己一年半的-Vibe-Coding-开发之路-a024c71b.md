# 从 UI 的变迁感慨一下自己一年半的 Vibe Coding 开发之路

写了一年半的小程序，每一个版本都截图做了几年，今天完成了第 N 次的首页改造，还挺感慨的，挑选了几张比较有代表性的截图来探讨一下当时的我对于工具类小程序首页的想法



V1.0 是属于放飞自我，当时用 Claude Code 编码比较多，对于图片切分的功能比较刚需，想着自己写一个自用，于是就看到了这标志性的紫色 tailwind 背景，这时候属于是能用就行

V1.3 这时候想着不仅仅只做一个功能，所以原有的图片切分就被收拢在了二级菜单，首页新增了一个图片拼接的入口，随便让豆包生成了两个图片凑合一下，现在看真的很适老化

V1.8 增加了两个与节日有关的功能，这时候已经开始觉得首屏有一些塞不下，开始着手优化首页

V1.9 - V2.2 我将其称之为归类 + 缩小，将原有一行一个的入口改为两行，用户能够在一屏看到更多的内容，这时候也做了一些微调，把不常用的节日头像向下放，主旨是能够让用户看到最新的功能模块

V3.0 功能越做越多了，这时候想开发一个主页编辑的功能，于是在第一页的最后一个入口新增更多功能的模块，用户可以自定义首屏的内容

V5.0 后台看到用户点击更多功能的意愿不大，于是在保留原功能的基础上模仿手机增加了多屏滑动的功能，能够让用户减少几步点击的操作

V6.0 NPY 说主页的色块好杂，而且顶部的标题这么大，还不如砍掉多加两个入口来的实在。我觉得很有道理，于是让 GPT 帮我把图标抠了出来，统一背景和文字，在图标的背部做一层晕染，同时原本首页六个入口增加到 10 个

现在用户每天也有二三十个，也算是给了我一些动力哈哈哈
