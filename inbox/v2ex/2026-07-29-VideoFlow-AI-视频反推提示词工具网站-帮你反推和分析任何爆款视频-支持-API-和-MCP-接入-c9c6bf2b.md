# > VideoFlow - AI 视频反推提示词工具网站，帮你反推和分析任何爆款视频｜支持 API 和 MCP 接入

VideoFlow 是一个 AI 短视频提示词反推工具。上传视频或粘贴抖音、小红书、B 站链接，它会自动拆解视频的剧情、分镜、运镜、动作和台词，再生成可以继续用于 AI 视频创作的结构化提示词。
简单说下为什么做它。
我 2025 年基本一整年都在做 AI 视频，YouTube 累计大概 3 亿播放，也靠这个赚到过一点钱。当时经常要参考、复刻和改编爆款片段，手动拆镜头太慢，就做了 VideoFlow 。
VideoFlow 是 2026 年 3 月上线的，算视频反推提示词这个小领域里比较早的一批产品。网站一直更新到现在，这次加的是 API 和 MCP ，方便接进自己的脚本、工作流或者 Agent 。
所以更准确地说，它是这个小领域里还在持续更新的老牌工具，不是已经停止维护的旧版工具。
网站： https://videoflow.cc
API 文档： https://videoflow.cc/zh/developers
MCP 接入： https://videoflow.cc/zh/developers
网页版现在能做什么

上传本地视频，或直接粘贴抖音、小红书、B 站公开分享链接
自动识别镜头切换，逐镜分析画面、景别、运镜、动作、声音和台词
还原故事概要、时间线和完整剧本
生成场景、角色、道具的生图提示词，以及逐镜视频提示词
输出可以继续喂给即梦、Seedance 、可灵等视频模型
哪里分析得不准，可以继续追问修改
