# [分享] 写了个把长文一键排到小红书 / 公众号 / Twitter 的工具，原文不改写

背景：
自己写公众号、运营小红书，被排版烦到崩溃。
市面上的工具要么收费要么登录，要么悄悄用 AI 改写原文，索性自己做了一个。
特点：

原文锁定 - 不用任何 AI 改写，只做排版
一稿多发 - 小红书多图 / 公众号 / X 推文串
富文本智能粘贴 - 飞书 / Notion / Word 复制直接进，自动转干净 Markdown
公众号样式精准还原 - 复制粘贴到后台直接用，背景色圆角间距全保留
小红书自动分页 - 3:4 / 9:16 比例 + 违禁词检测 + ZIP 批量下载
X 推文串 - 标准串 / 中文流 / 长帖三种模式
内置多套主题 - 长文 / 杂志 / 科技 / 暗色 / 手帐风格
完全免费 不用登录 不用注册

技术栈：

React 18 + TypeScript + Vite 5 + Tailwind 3
markdown-it / turndown / highlight.js
Cloudflare Pages 托管
Vitest 单测 + Playwright E2E
