# AI Coding 推荐把这条提示词加入到约束中

- 禁止为纯理论、低概率的边界情况增加兜底逻辑。例外：用户明确要求，或涉及数据损坏、资源泄漏、安全问题。

假如不加这一条，AI 会习惯把各种极端假设情况都考虑到，写长长的防御性代码占满你的屏幕
这种代码撸棒性拉满，但是对人类来说阅读维护成本更高，不符合开发效率优先的现状
