# 从 Ubuntu 24 换到 Windows 11，全身舒服了

家中有一台小主机，之前为了跑 OpenClaw 装了 Ubuntu 24 Desktop ，同时想用来跑跑 AI ，慢慢发现事情没有想象中那么简单。
首先是远程控制，RDP 折腾了一会儿发现不太行，最后配了 RustDesk ，但是连接不太稳定，质量检测显示速率大概几百 K ，帧率始终在 10+ 徘徊，AI 帮助下折腾了不少配置，但改善的不多。
其次是双显示器的问题，本地是双显示器，希望远程过去后能够同时使用这两台显示器，研究了很长时间，没能搞定。
还有一些杂七杂八的小问题譬如：

注销后再登录，无线网络断开，WIFI 按钮变成灰色，应该是我的驱动问题，当前是通过重启解决
微信死活不走系统通知，不弹窗，只有图标闪烁提醒，各种调整通知和权限无效
没声音，无法共享本地的音箱
没有显示器 RustDesk 连不上，最省事的方式是插一个 hdmi 欺骗器。AI 说可以用软件虚拟显示器，但是没尝试
...

相信这些问题慢慢折腾肯定是都可以解决的，但是就是麻烦，最终还是选择了装回 Windows 11 + 装一个 Ubuntu 24 Desktop 虚拟机，所有问题全部消失了：

Windows 自带的远程连接，全 4k 高清显示，2 台显示器完美识别
网络顺畅，远程操作如同本地，有时候甚至搞不清是在本地还是远程环境中了
本地的音箱远程环境也能使用

总体感觉就是，远程操作和本地操作完全感受不到差别。
无意引战，只是感慨一下，虽然 Windows 经常被吐槽，但巨硬确实还是做了不少东西，除非有充分理由，不然还是 Windows + wsl + Linux 虚拟机最省事，少很多的折腾。
