# 把豆包的图片、视频、3D 生成，装进一个桌面应用

AstraForge Studio —— 火山方舟 Doubao 系列模型的开源桌面创作客户端

一个很小但很烦的问题
火山方舟上的豆包生成模型这两年补得很齐：Seedance 做视频、Seedream 做图片、Seed3D 做三维资产。能力是够用的，但真正上手时会遇到一层摩擦——
想试一个视频创意，要么打开文档翻参数、写一段 Python 调接口，要么在控制台的体验页里点。前者每换一次分辨率就得改代码，后者参数给得有限，而且视频、图片、3D 分散在不同页面，来回切换。
更琐碎的是异步任务：视频和 3D 都是提交后返回 task id ，你得自己轮询状态、自己保存结果链接——那些链接还会过期。
AstraForge Studio 想解决的就是这一层摩擦：把三种生成能力放进同一个桌面应用，参数以表单形式给全，任务状态自动轮询，结果直接预览和下载。
三个工作台，一个窗口
顶部一键切换，三种模态各有独立工作区。
视频 · Seedance 2.0 系列
支持 Seedance 2.0 、2.0 Fast 、2.0 Mini 三个模型，四种生成模式：文生视频、图生视频（首帧）、图生视频（首尾帧），以及多模态参考——最多 9 张参考图 + 3 段参考视频 + 3 段参考音频混合输入。
分辨率、画面比例、时长（ 4–15 秒）、同步音频、固定摄像机、水印、返回尾帧，都是表单里的一项。提交后每 5 秒自动查询任务状态，成片直接在右侧内联播放，不用先下载再打开。任务排队太久也可以直接取消。
