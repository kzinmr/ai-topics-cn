# 用 GPT image 2 做了一个解说视频生成器

GPT image 2 的图片质量是目前最好的，就用这个做了个解释视频生成器 Knowcast 。
在 https://www.knowcast.app
要做知识科普，故事解说都可以用这个。
做的过程中发现越做越难。
发现 GPT image 2 还是有不少问题，比如它有极繁主义倾向，而且连贯故事的 prompt 不是很好写，画面 prompt 调整了好久。下了很多功夫。找到合适的 API 也麻烦(吐槽一下好多 gpt image 中转站质量很差)
如果大家想生成一些讲解解说类视频，很推荐试一下。
可以生成教学视频，绘本，新闻讲解等等。
