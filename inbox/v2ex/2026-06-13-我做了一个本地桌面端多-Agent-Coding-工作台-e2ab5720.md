# 我做了一个本地桌面端多 Agent Coding 工作台

最近在做一个开源项目 YCode ，一个本地桌面端多 Agent Coding 工作台。
它可以把 Claude Code 、Codex 、Gemini CLI 、Cursor 或其它自定义 CLI Agent 放到同一个窗口里运行。每个 Agent 都是真实 PTY 会话，可以并排、分栏、网格或主从布局显示。
除了多 Agent 终端，YCode 还集成了项目管理、历史会话搜索、文件树、代码编辑器、右侧 Shell 、Git Changes 、LSP 支持、主题和通知等能力。
GitHub:
https://github.com/melon95/YCode
