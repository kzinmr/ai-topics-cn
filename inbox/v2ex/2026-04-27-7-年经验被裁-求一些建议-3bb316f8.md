# 7 年经验被裁，求一些建议

本人 7 年多工作经验，毕业后一直在二线城市一家中等规模的公司工作，最近几年效益不好，公司开始大规模裁员，裁了几波轮到我了。这家公司可以说是 wlb 了，加班不多，压力也小，之前甚至有考虑过干到退休，没想到还是没苟。
基本情况：今年 30 左右，学历为排名靠前的 985 本科

项目经历：干过的项目比较杂，没有在一个方向上持续深入，没有高并发和大规模分布式的实操经验，只看过一些技术书籍和博客，技术水平一般般。之前搞 java ，后面也搞过 python ，最近一个项目是 agent 项目，基于开源项目二次开发的

经济情况：存款+公积金大概 100 个，无车无房无对象，没有负债
关于下一步该怎么走，想请教一下各位，给些建议。

我自己最近在学 agent 开发相关的知识，想着被裁后先朝这个方向找，边学边找，也知道现在社招地狱难度，万一找了好几个月也拿不到理想的 offer ，就打算考公了，准备往南方考，因为哥哥在那边。
碎碎念：下一步也得考虑找对象结婚买房的事了，在一家公司干了七年多也能看出我是个求稳没太多冲劲的人，现在 AI 发展这么快，感觉就算找到工作，可能也干不长久，到时候又得继续找，年龄一大就更不好找了。考公竞争也很激烈，脱产考的话，压力也非常大，万一考了几年没考上，就更废了。但其他方向的话，也不知道干啥，哎。。。。。
