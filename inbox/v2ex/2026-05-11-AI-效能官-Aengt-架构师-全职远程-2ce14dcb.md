# AI 效能官,Aengt 架构师 全职远程

40 岁内 本科及以上
AI 效能官 20-50
 [硬性能力要求] 
1. 熟练掌握 Python 、Node.js 、php go 等开发语言其中之一；
 能独立写脚本抓取数据、调用 API 接口。极度精通主流大模型（ Claude 3.7/Opus 4.6 、GPT-5.4 、Gemini 2.5 Pro ）的 Prompt 工程和调优。
2. 必须有在 Coze 、Dify 、FastGPT 等主流低代码平台上，独立搭建并上线过企业级 Agent 工作流的真实项目经验（面试需带作品并现场上机演示）。
3. 具备极强的业务 Sense ，能在一周内看懂一个陌生业务的完整流转链路，并准确画出可以用 AI 提效的替代漏斗图。

 [岗位职责] 
1. 深入各业务线，识别高价值的 AI 替代/增强场景，设计并落地 Agent 自动化工作流
2. 主导内部 AI 工具选型、搭建与推广，持续提升全团队人效
3. 建立 AI 效能评估体系，用数据证明每个自动化项目的 ROI
4. 作为公司 AI 能力输出的对外窗口，支持业务赋能与合作方接洽
5. 跟踪 AI 前沿动态，将新模型/新工具快速转化为业务实战价值

 [加分项] 
1.懂 RPA （ UiPath 、影刀）结合 LLM 实现全自动跨域端网页填表抓取经验
2.在出海、泛娱乐、游戏买量或灰产领域有实际操盘经验，懂业务黑话
3.曾在互联网大厂担任过内部效能工具产品经理（ B 端 PM ）

Aengt 架构师 20-40
💡 岗位定位
在这里，你不仅是一个 Coder ，更是业务效能的放大器。我们不需要你只做单一模块的“螺丝钉”，而是希望你能以“AI 产品工程师”的视角，主导 AI 落地，从 0 到 1 打造直接驱动业务、提升组织运转效率的智能化工具与 Agent 架构。
