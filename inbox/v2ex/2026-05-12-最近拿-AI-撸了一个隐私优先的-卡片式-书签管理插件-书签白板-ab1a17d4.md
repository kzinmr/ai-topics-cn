# 最近拿 AI 撸了一个隐私优先的“卡片式”书签管理插件：书签白板

各位大佬好，最近自己动手写了一个 Chrome 插件：书签白板。

起因：传统的书签栏文件夹套文件夹，找起来太心累；市面上有些插件又太重，还要登录账号。
我想要一个像“看板”一样直观，且数据绝对安全的工具。

核心逻辑：
视觉化：书签不再是冷冰冰的文字，而是像卡片一样排在白板上。
纯本地： 隐私第一，不设服务器，不上传任何数据，你的书签只属于你。
轻量： 支持侧边栏呼出，不干扰正常浏览。

目前状态：版本刚过审，目前还在持续开发中（ TODO：优化视觉 UI 、增加更多分组图标等）。

商店地址： https://chromewebstore.google.com/detail/书签白板/iceockbgpgoemnfccjdlnemihodlnmbj?authuser=0&hl=zh-CN

非常希望听到大家的真实反馈，无论是功能建议还是 Bug 吐槽，我都感激不尽！
