# 归档了 10,365 张经典魔兽争霸 3 地图

2010 年暑假，我还在上小学的时候, 在放学托管班里看见同学在玩《魔兽争霸 3 》的 Boom 海战，那时候就觉得好有意思, 操作小船炮击敌人.
接下来三年的寒暑假基本都搭在这个游戏上。那时候都在浩方或者腾讯对战平台上玩, 天天就是刷新局域网, 寻找新的 RPG 图，于是我的地图文件夹一路膨胀。那段时间很是着迷，不仅是玩游戏，我还去学习了地图编辑器，摸清了一点光环效果的用法和技能脚本的编写。
再后来玩得少了，偶尔和高中同学开一局自定义英雄世界、疯狂六角星，绿色循环圈啥的。这几年对战平台一轮轮的开了关，关了开。当年天天玩的地图基本都消失了，平台也基本限制了游戏内交换地图，同时大量的雷霆氪金图出来了。氪金图玩着也没意思, 画面和 UI 始终感觉不搭.
于是我动用了 AI, 把四处搜集的地图整理并挂到了 github page 上, 基本是 2005 到 2012 年的地图.
希望喜欢这个游戏的朋友们能找到自己喜欢的图.
页面: https://war3-archive.github.io/war3-maps/
