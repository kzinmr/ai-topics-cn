# 一个获得干净的 IP 来连 Claude Code 的方法

用 Cloudflare WARP (1.1.1.1 那个)，一个免费的 VPN

也就是 Claude Code -> Cloudflare WARP -> 你的梯子的出口（ Claude Code 支持的国家的节点）-> CF 出口服务器 -> Anthropic 服务器

我直接用我梯子的各国的节点，Claude Code 都报国家不支持，怀疑这些 IP 都被拉黑了，外面套一层 CF WARP ，相当稳。

而且感觉 Anthropic 应该不太容易封 CF WARP ，挺多海外的正常用户开着它用的。
