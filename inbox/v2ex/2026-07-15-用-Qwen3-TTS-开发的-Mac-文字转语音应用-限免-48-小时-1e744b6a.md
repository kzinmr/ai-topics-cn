# 用 Qwen3-TTS 开发的 Mac 文字转语音应用-限免 48 小时

之前分享过语音转文字的帖子，有网友向我推荐 Qwen3-TTS ，最近新增了文字转语音的功能：

原汁原味的本地 Qwen3-TTS (1.7B) 应用底层直接集成了基于 Qwen3 的 TTS 引擎，不需要连网，不需要配置任何 API Key ，打开就能生成。无论断网还是在飞机上，都能随时随地转换高质量的语音。
支持“风格指令 (Style Instruction)” 除了单纯的念稿子，你可以通过输入情感和风格指令，让声音带有特定的情绪（比如：“用非常激动的语气”、“带有疑惑的语气”等），出来的效果非常自然。
多发音人与多语言支持 内置了像 Aiden 等多个高质量发音人，中英双语混合播报毫无压力，并且支持在界面上直观地预览试听。
可视化波形与便捷导出 生成的音频不仅能在原生界面中丝滑播放，还支持一键导出为 .wav 格式的高清音频文件，方便用在视频剪辑或播客创作中。


长篇文章会崩溃(下个版本修复)，篇幅短可以正常使用。不知道大家在日常使用 TTS 时，还有哪些未被满足的强需求？
