# 找个长期远程 Go 后端开发，高并发时序数据平台

项目背景：开发一款高并发、海量时序数据的统计聚合 Web 平台。对第三方 API 进行动态高频数据接入，千万/亿级流水数据的复杂计算与重算/增量计算。前期 Docker 单机部署，后续分布式演进。
前端（用户端 + 管理端，20+ 页面）已全部完成，需后端接入真实数据。
核心技术栈： Go 、ClickHouse 、MySQL 、Redis （熟悉 PostgreSQL + TimescaleDB 更佳，懂 Vue 3 / ECharts 全栈最佳）
技术要求：

Go：精通 Goroutine 高并发、异步任务调度，能实现稳定的数据接入管道（限流、重试、动态降频/休眠）
ClickHouse：精通时序数据表结构设计、物化视图、窗口函数，手写优化复杂聚合 SQL
MySQL：常规业务数据处理
Redis：任务队列、缓存、排行榜
熟悉 JWT 认证、敏感数据加密存储、基本安全防护
有邮件服务集成经验（验证码、通知）加分
熟悉 Kafka 消息队列加分
3 年以上，能独立扛项目
熟练使用 AI 辅助编程提效
