# 微信点开大图被 PDD 偷听这事，难道没有搜广推的同学出来科普一下？

各个大厂内部有一套针对热门词 entity_id 的画像/特征系统。甚至小众冷门的都有。腾讯也不例外。采集对象是全量 API 数据。
图片里的东西不是障碍，无论 OCR 还是多模态都烂大街了
那个截图包含的有商业价值的 entity_id 在第一个人上传的那一刻就被离线队列分析完归档了，只待有缘人在行为链里绑定身份了。
你点开看大图本身就是一个强信号，特定游戏做一个 ttl 很短的实时 feature 很常见吧
然后 广点通 RTA 实时去查询同设备用户喜好，这个也很合理吧？
为什么这个特定游戏的手办精准度特别高呢？
