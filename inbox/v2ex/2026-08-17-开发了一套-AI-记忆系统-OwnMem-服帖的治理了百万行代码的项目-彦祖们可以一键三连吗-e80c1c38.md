# 开发了一套 AI 记忆系统： OwnMem，服帖的治理了百万行代码的项目，彦祖们可以一键三连吗？

仓库地址
https://github.com/grpcer/ownmem


👍彦祖们走过路过可以点个 Star 吗

背景

起因是手头有个百万行代码的项目，每天从家里和公司的电脑轮换开发

📢 经常要重复跟 AI 说：

“服了你了，说了多少次，这个 bug 不要再犯了”
“每次开发完，记得补充单元测试”
“每次写完 SQL ，帮我检查索引”

🤔 于是我在想，有没有一套记忆系统，可以跨电脑记忆，随着 Git 可以提交，并且还有以下优势呢
1. 记忆跟随 Git 仓库流转
git pull
→ 得到代码
→ 同时得到这个项目积累的工程经验和记忆


2. 不依赖某个 AI ，同时支持

claude code
codex
Agv
Grok
Cursor


3. 语义召回不调用模型，不烧 token
在本地通过 Exact、Unicode-aware BM25F、多查询 RRF 等方式检索。

不调用额外模型
不请求网络

完整编译层还支持 n-gram、fuzzy、graph 和 embedding，你还可以在控制台接入siliconflow或Cloudflare 的 bge-m3 模型做强力语义查询。

4. 完整的 markdown 体系
.ownmem/
├── MEMORY.md                          ←  L1  总目录
├── MEMORY-release.md                  ←  L2  领域目录
├── MEMORY-database.md                 ←  L2  领域目录
├── npm_publish_requires_2fa.md        ←  L3  一课一文件
├── sql_query_requires_index_review.md
