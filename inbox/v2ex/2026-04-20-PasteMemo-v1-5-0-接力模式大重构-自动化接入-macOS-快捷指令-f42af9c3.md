# PasteMemo v1.5.0：接力模式大重构，自动化接入 macOS 快捷指令

PasteMemo v1.5.0 是一次大版本更新，两条主线：


接力模式的全面重构，易用性大幅提升


自动化规则接入 macOS 「快捷指令」，拓展无限可能
下面分别展开，另外还有若干来自社区的贡献和细节优化。


一、接力模式：Hero + 抽屉布局重构

接力面板的信息密度一直偏高，这次拆成两层：


Hero （常驻区）：当前条目内容、进度条、上一条/跳过、循环/暂停/退出、自动化规则提示，所有高频操作保留在这里。


抽屉（可折叠）：完整队列列表。默认展开，随队列长度自动展开/收起；手动点「收起」之后会记住偏好。
收起抽屉后，面板只剩必要信息，适合并行工作时只瞄一眼的场景。
配套的视觉调整：


所有区块水平/垂直内边距统一，左右边缘严格对齐


完成状态从绿对勾改为绿点，跳过改用斜线圆圈，进度条跳过段颜色加深


退出按钮图标改为语义清晰的「退出门」


循环开关从复选框改为蓝色 pill


面板整体字体 +1pt



二、自动化：接入 macOS 快捷指令，打开想象空间

自动化规则新增一个动作：运行快捷指令，把剪贴板内容作为输入喂给系统「快捷指令」 app 里的任意一条 Shortcut ，再用 Shortcut 的输出替换原内容后继续走自动化链路。
这条动作的意义在于：macOS 快捷指令本身就是一个完整的自动化生态——它能调用 AI 、网络 API 、本地脚本、文件系统、跨 App 传递数据。快捷指令能做什么，你的剪贴板现在就能做什么。
几类典型用法：


AI 改写 / 翻译 / 总结：复制一段英文，规则挂一条调用 ChatGPT / Claude / 本地 LLM 的快捷指令，粘贴出来已经是中文


格式化处理：复制 JSON / YAML / SQL 自动格式化；复制 Markdown 自动转纯文本
