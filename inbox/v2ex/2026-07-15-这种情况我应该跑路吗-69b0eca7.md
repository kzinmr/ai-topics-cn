# 这种情况我应该跑路吗？

我在一个不知名杀毒软件公司里
感觉把这辈子的亏都吃完了

刚入职的时候
这家公司编译出包各个信创架构平台的产品，都是物理机编译
我搭了交叉编译平台，统一了编译出包环境，节省大量人力成本

然后就和其它同事一样，维护产品、对接项目

后面由于 SDK 版本太多，shell 作为出包脚本越来越难维护
我用 python 把自动化出包脚本重写了

然后项目需要 Linux 下的主防驱动以实现系统监控、反勒索、文件保护、自保护
我又收集了 Linux 系统中的十种监控方式，深入研究了 7 套，成功落地了两套，花费我大量心血

再往后我发现 C++11 的第三方库逐渐停止维护
于是我把所有的工具链对齐到 C++17
这样开发也能方便些

回过头我突然发现自己的薪水仅仅比新人高，随便一个老员工都能盖过我
而且我做的东西从来没人主动去维护
做的东西越多，维护的就越多

现在我手里有：主防服务、主防驱动、交叉编译平台、python 自动化出包脚本、SM 专用机产品分支、4 个 SDK 产品分支，我还要和其他同事一起参与主线版本迭代，最近 Linux 客户端向鸿蒙的移植也落到了我的头上

然后我看了看 Windows 端的人员配置：单人负责主防驱动、单人负责主防服务，x86 架构不需要交叉编译，单人负责杀毒客户端，还不需要考虑什么 deb 、rpm 、tar 、bin 包类型

然后我看了看杀毒引擎：单人负责，使用我提供的交叉编译平台

勤快人活该被累死啊

我们 CEO 是二股东老板的前任的闺蜜
听说是经营美容店的，同时管理着我们这边，琢磨不透她在想什么
现在是人也不招，谁涨薪水也不给涨
我先前提涨薪，领导原话告诉我：”他年纪这么小……”
我服了，你赶紧上菜市场招几个老头去吧

我是看透了也寒心了，最近几个月一直找工作，真想赶紧跑路啊
这市场环境，难不成真要被她拿捏了？
