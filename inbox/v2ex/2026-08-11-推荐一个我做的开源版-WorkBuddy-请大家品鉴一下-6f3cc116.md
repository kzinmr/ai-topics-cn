# 推荐一个我做的开源版 WorkBuddy，请大家品鉴一下

项目地址： https://github.com/pqpo/pragma  求个 star 啦~~~
通过和内置 Agent：Pragma 对话就可以直接创建出专家和专家团，每个专家都可以设置不同的 Agent Harness 和 模型。比如我会把设计交给 gemini + agy ，和 claude + cc 探讨方案，chatgpt + codex 实施代码，deepSeek + cc 代码 cr ，codex 执行自动化测试。
组建好团队之后，剩下的就把任务交给团队，团队内部会自动选择合适的专家完成你的任务。团队中的不同专家运行在不同的 Agent Harness ，但是共享团队记忆、团队白板，保证高效、高性价比的完成任务。
