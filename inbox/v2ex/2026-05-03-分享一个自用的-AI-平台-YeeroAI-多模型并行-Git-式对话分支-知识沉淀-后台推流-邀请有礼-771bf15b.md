# 分享一个自用的 AI 平台 YeeroAI（多模型并行 + Git 式对话分支 + 知识沉淀 + 后台推流 + 邀请有礼）

最近在用一个 AI 平台 YeeroAI （ yeero.ai ），功能做得还挺扎实，分享给可能有需要的朋友。
为什么不用 ChatGPT / Claude 直接聊
几个我自己遇到过的痛点：

多模型对比太麻烦：想看 GPT 和 Claude 对同一个问题的回答，得手动切来切去，复制粘贴提示词
聊完就忘：有价值的信息下次对话全丢了，还得重新解释背景
复杂任务只能线性推进：想同时探索几个方向，只能开一堆窗口，自己都搞混
知识散落各处：找不到之前聊过的关键内容

这个平台怎么解决的
1. 一次提问，300+ 模型同时回答
勾选多个模型，一条消息同时发给它们，答案并排展示。支持按供应商筛选（ OpenAI / Anthropic / Google / DeepSeek / Meta 等）、按模态筛选、只看免费模型。SSE 流式输出，不用等所有模型都生成完。
2. Git 式对话分支
对话可以从任意节点 Fork 一个新分支，两条思路并行推进，随时切换、对比、合并回去。每个分支还能独立配置模型和参数。处理复杂问题的时候特别好用，思路不会乱。
支持多标签页同时打开多个对话，IDE 风格切换，不用来回找。
3. AI 自动提炼知识 + 记忆注入
每次对话后，AI 自动从回复中提取关键信息生成"知识条目"（标题 + 摘要 + 标签），用 bge-m3 做 1024 维向量索引。下次问相关问题时，系统自动检索最相关的知识注入上下文。
另外还有"记忆"系统——AI 自动提取用户偏好、习惯等关键信息，对话时自动携带，越用越懂你。
上下文摘要功能可以把历史消息压缩成精华，长对话 Token 消耗大幅降低。
