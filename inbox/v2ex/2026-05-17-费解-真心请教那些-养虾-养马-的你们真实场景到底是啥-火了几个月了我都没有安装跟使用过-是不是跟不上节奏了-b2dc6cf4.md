# 费解，真心请教那些“养虾”，“养马”的你们真实场景到底是啥？火了几个月了我都没有安装跟使用过，是不是跟不上节奏了

说回正题，从过完年的小龙虾火爆，公司也统一安装了一个，并接入了某办公软件，我自己是一次都没玩过，不知道到底能干嘛，负责的技术哥们说可以写 ppt ，但是我感觉 ppt 不如我用 codex 或者 claude code 的 pptx-skill ，所以没用过，还有说可以拿来抓取某些网站数据然后形成报告啥的，这个我多年之前就用 python 抓取然后总结过，我本人也是 RSS 重度用户，所以好像也没有用。
所以真心求问，大家花几千块买了 mac mini ，拿来养虾养马，真的有用吗，真实使用场景是哪些，欢迎老哥们分享。
我先分享个我知道的，业务同事有使用 workbuddy 的，有时候会让我给他们写个脚本啥的，我丢给他们，他们拿 workbuddy 就可以自动安装环境跑起来，不知道这算不算，但是我感觉这个场景用 opencode 啥的也可以实现，或者 codex ，只是把门槛降低了一些。另外，我们公司的那个 openclaw ，基本没人用，我看了下日活这两个月基本都是个位数，没啥人用。
