# 国内用 Claude Code 半年踩坑，自己搭了一个聚合中转

去年下半年开始重度用 Claude Code 写代码，被 Anthropic 风控搞过几次。家里、公司、有时候去咖啡馆，出口 IP 不一样，几个月连封了三次号。换梯子能登，但 Claude Code 跑长任务时 SSE 经常中途断流，生成到一半要重发 prompt 这事儿挺难受。再加上 Sonnet 4.7 输出 $15/M tokens ，我那段时间一个月跑出 $80 多。

折腾够了，索性自己搭了一个，claude-api.org 。把 Claude / GPT / Gemini 三家放到一个 sk- 开头的 Key 后面，Anthropic 原生协议和 OpenAI 兼容协议两个端点都开着，Claude Code / Cursor / Codex CLI / Cline / Chatbox / Open WebUI 改一行环境变量就能切。

价格按官方倍率走，Claude 0.7 、其他 0.5 ，后台有个"可用渠道"页直接看每个模型多少钱，按 token 计费没套餐没阶梯。注册送 $10 体验金，够跑通流程不用先付。

这周自己和几个朋友每天用，目前没掉线。但中转这种东西本质就是聚合，跑路 / 上游风控 / 价格变动都是常态，所以单次充值我自己建议 ¥500 以内，小额多次。

哪位也被官方 API 封过 / 断流过 / 嫌贵，可以试一下，bug 邮件 support@claude-api.org 或者评论 @ 我，我尽量当晚改。

主站 claude-api.org ，文档 doc.claude-api.org 。
