# 再穷不能穷 AI，再省不能省 token： Hermes 接管了我的 Mac、NAS、HK 服务器

一开始是腾讯云 OpenClaw ，后面换成 Hermes ，这两天迁移到了本地电脑，接的 DeepSeek API 。
Mac：M4 、10 核、10 核、32G 、1T 。
NAS：威联通 TS-464C2 ，内存 8G ，机械 2T+4T+4T+16T 。其中，两个 4T 是机器自带的，2T 是之前播放器用的普通盘，16T 是 PDD 淘的东芝企业级氦气盘。有个固态 2T 用作移动硬盘，考虑要不要加进去。等价格平稳了再加个 8G 内存。
HK 轻量服务器：2 核+8G+80GB ，一个月 120 ，准备换个便宜的。一开始主要是为了方便搭建 Hermes ，换过新加坡的发现速度不行，后面准备换个便宜的，或者就不使用了。
DeepSeek API：API 这块先后使用过 GLM 、MINIMAX ，以及腾讯的 token 套餐，最终选择了 DeepSeek ，缓存命中率高，大部分 flash ，小部分 pro ，对于主要用于日常办公、爱好型开发的人，一天几块钱。
作为文科生，Hermes 对我帮助太大了，比如配置服务器，优化电脑开发环境，提升 NAS 使用效率，以及搭建本地知识库，辅助开发项目等，简直就是数字时代的个人智慧大管家。
后面继续 优化 Hermes ，比如再加些 skill ，比如那个知名的 CLAUDE.md 等，平时使用也不断整理记忆等。
仅仅是数据整合这块，感觉要做的事情特别多。比如知识库的各种写作，书签的整理，豆瓣个人影视数据的利用等。
再就是辅助开发，比如  loveable 、trae 、workbuddy 、DeepSeek TUI  ，比如 GitHub 各种 star 的利用。
还有关于数据的老问题，备份同步，技能记忆留存等。
