# 使用 Python tk 实现一个自由奔放的智能体，能够实现“自我进化”，可玩性挺高的 :)

基于 tk, 非常小巧 :)
项目的 GUI 框架和最初的 class OnlineToolSession 是豆包生成的，提供手动实现的 toolkit_save() 和 toolkit_reload() 两个工具后，其他工具都是自我进化生成的，GUI 的更新也是通过 llm 更新代码。
python 项目打包依赖文件的创建，git commit 统统都可以通过 llm 调用大模型搞定；
模型主要使用了 qwen3.6-plus, glm5
项目通过 https://github.com/sunkwei/tea_agent 发布
