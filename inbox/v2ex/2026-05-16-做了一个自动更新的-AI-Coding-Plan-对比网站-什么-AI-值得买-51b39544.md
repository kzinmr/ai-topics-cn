# 做了一个自动更新的 AI Coding Plan 对比网站：什么 AI 值得买

网址： https://ai.dal.ao

起因是 GitHub Copilot 逐渐转向按量付费，五一假期我开始研究各种 Coding Plan 。过程中看到群友整理的飞书表格很有用，就想着做一个可以自动更新数据的网站，方便横向对比各家套餐。正好也有个地方能把小米送的 AI Token 用掉
产品的信息是通过爬虫获取内容后交给 AI 做数据格式化和总结实现的。下面的截图是以阿里云百炼 Token Plan 为例的爬虫输出：


目前支持的信息
网站目前会自动整理这些内容：

各档位价格
支持的模型
速率或用量限制（如果官方有公开说明）
API 兼容性
Artificial Analysis 上的模型基准跑分数据
CODPL 的产品 AI 服务速率数据


几个比较有用的页面
产品大表格： https://ai.dal.ao/product/table

适合直接横向比较各家套餐。
产品目录： https://ai.dal.ao/products

适合按产品或厂商浏览。
模型家族： https://ai.dal.ao/model-families

适合查看模型归属、跑分和相关信息。

其他还没彻底做完的内容

模型测速：做这个网站时发现，CODPL 的 Coding Plan Benchmark 是一个很有价值的资源。即使是同一个模型，不同厂商因为算力、调度和用户规模不同，实际服务体验也会差很多（其实就是常说的超售）。目前 CODPL 的数据还不算特别全，所以也做了个自动化测速工具，准备把自己手上的几个套餐先测起来。目前已经半完工了，还在完善细节。
销售状态：后续会给售罄、暂停销售或限量开放的套餐加标记。这个是开发时漏掉的设计。
