# [开源工具]做了一款开源的 Windows 输入法

背景
一直以来都想要做一款开源的同时兼顾易用性、美观性的 Windows 端的输入法，在 Coding Agent 的加速下，项目越来越完善了。
GAP 了两年多，女朋友提前结束了我们的 GAP 计划来到深圳工作，我也重新来到深圳找工作，赶着这个时间点，完成了制作输入法软件的这个执念，虽然目前还有很多不完善的地方，但是就这两个月 AI 辅助编程的过程中，我觉得未来在功能性上超过搜狗完全不成问题，至于在广告插入方面想要走到搜狗的前面，那一定是一个不可能事件。
简介
一款开源的自由 Windows 输入法：水杉输入法。
仓库：https://github.com/metasequoiaime/MetasequoiaImeTsf
功能简介

开箱即用。
支持全拼、双拼、五笔 86 。
拼音方案支持辅助码。
支持谷歌云联想。
支持 DeepSeek AI 联想。
支持词库管理、批量导入、导出。
支持手写识别。
支持快捷短语。
