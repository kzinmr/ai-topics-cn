# [开源] 私有简历 PResume - 一个开源、免费、可自行部署的私有简历系统，主打保护隐私。

私有简历 PResume
PResume （私有简历） 是一个开源、免费、可自行部署的私有简历系统，主打保护隐私。
你的简历属于你本人。PResume 让你在自己的服务器上拥有并掌控全部数据，不依赖任何第三方平台，不收集、不出售、不外泄你的个人信息。

特性

隐私优先：所有简历数据存储在你的私有数据库中，不经过任何第三方服务。
自托管：一条命令即可部署到你自己的服务器或私有云。
开源免费：完整源代码开放，永久免费使用。
导出友好：支持将简历导出为 PDF 等常见格式。


快速开始
环境要求

Ruby 3.4+
PostgreSQL
支持 Docker 部署（推荐）

本地运行
bin/setup
bin/dev

Docker 部署
docker build -t presume .
docker run -d -p 80:80 -e RAILS_MASTER_KEY=<config/master.key> --name presume presume

使用 Kamal 进行生产环境部署，相关配置见 config/deploy.yml。
数据库
开发、测试与生产数据库名称分别为：

presume_development
presume_test
presume_production（含 presume_production_cache / presume_production_queue）

许可证
