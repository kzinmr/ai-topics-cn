# 跟着 DSH 发布，今晚开源了三个小东西

官方 DSH 今天一开，我这边也跟着折腾了一晚上。不是另造一个“原厂 Harness”，主要是补几个自己真想用的缺口。
最先能玩的还是 GUI：用 Tauri 2 把官方 dsh web 原样放进桌面壳，补了工作区选择、最近项目、主题/中英、钥匙串和托盘。它会在项目目录启动官方 runtime ，只接 127.0.0.1 ，再把页面嵌进窗口。目前源码 CI 绿，但还没发二进制，得自己 build 。
https://github.com/bobleer/deepseek-harness-gui
另一个是 Plugin MCP ，想解决的是“别的 agent 怎么发现、检查、安装、运行 DSH 插件”。目录检索默认只读，安装和 runtime 都要显式开开关。CI 也是绿的，不过 npm 现在还是 E404 ，所以别照 README 跑 npx ，现阶段只看 GitHub 源码。
https://github.com/bobleer/deepseek-harness-plugin-mcp
第三个 Rust 版只是很早期的 runtime code drop 。当前 CI 卡在 cargo fmt ，默认分支和 README 的 quickstart 也有不一致，先别当成可用替代品，我放出来主要是想让架构讨论有代码可看。
https://github.com/bobleer/deepseek-harness-rust
利益相关：这些都是我参与的 BitFun 团队衍生出来的。三个仓刚开全是 0 star ，GUI / MCP 方向你觉得有用的话，欢迎去点颗 star 或直接提 issue ，真实踩坑比客套支持更有用。
