# 我做了一个可以免费使用的 GPT-image-2 生图网站，也接了 Grok 图片/视频

最近自己折腾了一个在线生图工具，主要是想把 GPT-image-2 、Grok 图片和 Grok 视频这些模型放到一个页面里，平时测试提示词、做参考图、生成一些海报/头像/封面会方便一点。
网站地址：https://grok.17nas.com/
目前网站可以直接免费试用，不过为了防止被刷，每天会有一点额度限制。注册登录后可以领每日额度，适合轻量体验和测试提示词。如果需要生成很多图，建议还是自己接 API 或者等后面充值功能完善。
现在支持什么

GPT-image-2 图片生成
Grok 图片生成
Grok 视频生成
参考图生图
参考图生成视频入口
图片/视频结果预览
图片结果下载到本地
会话记录本地保存
登录后云同步会话和记录
移动端也能用，不过我还在继续优化体验

我自己主要用它来做两类事情：

快速测试不同模型对同一个提示词的理解差异。
把生成好的图片继续当参考图，再做二次创作或者尝试生成视频。

使用方式
打开首页后，默认会进入一个 GPT-image-2 的示例会话。你可以直接在底部输入框里写提示词，然后选择模型、比例和张数。
比如：
一张科幻电影海报，冰封城市，远处有巨大的行星发动机，电影剧照质感，冷色调，高细节

如果想用参考图，可以先点某张结果图下面的“用作参考图生图”，图片会自动加到输入框，再继续写新的提示词。
每日额度说明
网站现在是免费试用，但不是无限量。
每天会给一点平台额度，主要是为了让大家能体验 GPT-image-2 和 Grok 图片/视频能力。图片和视频生成都会消耗额度，文字聊天目前会尽量保持免费或低门槛。
如果上游模型因为内容限制失败，页面会直接显示失败原因，不会让任务一直卡在“思考中”。
云同步和本地下载
如果只是临时体验，不登录也可以用，记录会保存在当前浏览器。
