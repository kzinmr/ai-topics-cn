# ?!广东人狂喜!?,自制蟑螂幸存者小游戏卵鞘危机 V1.0 版本发布,纯浏览器也能玩的肉鸽小游戏

大家好，我们和 AI(感谢 Claude Code 、感谢 Codex 、感谢 Copilot)合力(其实大部分时间是在做游戏策划和测试,AI 大爹还是太权威了)做的 Web Roguelite 小游戏 卵鞘危机 / Roach Survivor 在不懈的更新下现已正式推进到 V1.0 版本了。

这是一款发生在下水道里的蟑螂幸存者小游戏。你要操作一只可爱的主角蟑螂(可换皮肤)，在变异的蟑螂虫潮里不断移动、瞄准、升级、捡经验、挑战 Boss ，最后把金色卵鞘带回主菜单做局外成长。

目前 V1.0 版本包含：

3 档难度：简单、普通、困难
3 波 Boss ，困难模式为完整三阶段挑战
12 个局内 Buff ，可开局前自定义升级池
圣遗物系统、局外升级、成就系统等

操作方式：WASD / 方向键移动，鼠标瞄准，升级时选择强化/圣遗物。
手机端也能试玩，会自动开启自瞄和手机触控移动，不过因为手机端屏幕过于小了 想要完整体验还是更推荐电脑端。
