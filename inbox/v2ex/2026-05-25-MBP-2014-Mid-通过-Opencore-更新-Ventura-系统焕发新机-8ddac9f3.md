# MBP 2014 Mid 通过 Opencore 更新 Ventura 系统焕发新机

起因是想把自己的 2014-mid 的老古董 MBP （ macOS 11.7.10 ）拿来 Vibe Coding 一下，结果发现 VS Code 安装不了最新版，于是萌生出升级系统的想法，和 Claude 网页版沟通后打算升级到 macos 13 ，于是从周六晚上制作 Time Machine 备份到今天周一晚上，老古董折腾了 48 小时（减去两个不太充分的睡眠时间和今天上班时间），终于搞定了：


机器：MacBook Pro 2014 Mid
目标系统：macOS Ventura 13.7.8 (build 22H730)
工具：OpenCore Legacy Patcher (OCLP)


现在的结果就是很流畅也！有种当年 HDD 升级 SSD 的感觉，总之比它跑 macOS11 的时候流畅，现在让我深深怀疑苹果是通过系统来锁死硬件升级。
