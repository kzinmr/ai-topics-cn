# 我也做了一个可以操控手机的硬件 Agent

看到 https://www.v2ex.com/t/1230118 中 @fzuccq 分享了他的手机 Agent 硬件方案，我也来介绍一下最近做的同类型项目。    
我的方案是利用手机的 C 口转 HDMI 投屏获取屏幕、USB HID 模拟鼠标键盘进行操作。    
目前项目代码也是完全开源的状态： https://github.com/AidenAI-IO/aiden-firmware 
自组硬件的成本大约在 400 元左右，核心组件如下：  

Type C HUB 转 HDMI 、USB 
Pico Zero RV1106G3 （核心处理单元）
HDMI 转 CSI 模块
8 欧 2W 扬声器
2.4g WiFi FPC 天线
HDMI 公对公转换头（用于连接 HUB 和 HDMI 转 CSI 模块）
CSI 连接软排线
ASPPRO 2.0 模块（可选，用作关键词唤醒）
按键开关（可选，唤醒的另一种方式）
