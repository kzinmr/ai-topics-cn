# 🎁 给孩子准备的儿童节小游戏 ——「谁是卧底」

这个工具最初是给家里的小朋友做的。孩子上学后认识了不少字，我想趁这个机会锻炼一下他的表达和想象能力。但市面上类似的谁是卧底 App ，要么是给大人联机玩的，需要给孩子准备手机和账号；要么塞满了广告，交互体验很差。
于是我干脆自己动手，做了一个纯粹辅助线下游戏的「发牌」工具——不需要人人都拿手机，一部设备轮流传递，面对面玩就够了。
怎么玩

设置游戏人数，点击开始
手机依次传递给每个玩家，各自查看自己的词
看完后，大家按正常谁是卧底的规则线下进行
投票结束后，回到手机上查看每位玩家的词，看看谁是卧底

游戏设置里还可以选择难度——难度越高，分配的词语越难分辨，甚至会出现一些抽象或生僻的词，挑战性拉满。
亮点

🎯 交互极简 —— 小孩子也能独立操作
📱 支持小程序 —— 微信里点开即玩
🏠 支持 PWA 安装 —— 添加到桌面，跟原生 App 一样顺手
🔒 隐私安全 —— 所有数据仅存储在本地，不上传任何云端

体验地址
网页版 👉 https://undercover-family.github.io/
小程序版本

开发过程
整个项目都是使用 vibe coding 完成的。

需求：使用 Superpower 技能帮我从一句话需求到完整的需求规格文档
设计：使用 frontend-design + https://www.designprompts.dev/sketch
开发：vite + react + zustand + tailwindcss + shadcn/ui + Hugeicons
