# 独立开发周记 178：全新机场主题上线

2026 ，0706 ～ 0712
已经连续下雨一个多月了，我在这个城市生活了四十年，也是第一次遇见这样的极端阴雨天气。
骑电动车接送孩子，雨衣其实没什么用了，小雨不用穿，大雨也就只有后脑勺和肩膀不会湿。我也是从网上看到的，电动车骑行的雨衣，不仅可以给人穿，也可以给电动车盖上用来防雨……
本周工作
极简时钟新主题
本来以为周三前就能提交新主题，没想到一直到周日下午才最终提交新版本。
推迟提交的最大阻碍还是动画性能问题，即使用上了 Fable 5 也没有解决。手里所有能用的大模型都失败了，绝望的我打开了 github ，正好发现了救命稻草，有一个类似设计的 repo 完全没有动画卡顿，于是就让 AI 参考这个 repo 重新实现了所有的动画和交互。
时钟页面有一个世界时间的信息板，包括了世界知名城市和对应的时间，第一个版本里还加入了时区，但是这样占空间太多，就最终去掉了。世界时钟每分钟 0 秒就会刷新，每次随机显示四个城市。每个小时会出现一个飞机横穿屏幕，位置和方向都是随机的，深色背景下飞机会显示机身上的指示灯（看下图），并且伴随两个音效随机出现，一个是飞机划过的声音，一个是客舱的通知音（可惜 GIF 图没有声音，感兴趣的可以下载 app 来实际体验一下）。

番茄钟和正计时页面也加入了一些有趣的交互。除了数据统计面板外，还有一个我非常喜欢的灯光联动效果，专注时顶灯会自动打开，并且伴随开关的声音和触感反馈。当然，灯光在深色和浅色模式下都是不同的，浅色的就不放图了，希望大家亲自下载去体验。
