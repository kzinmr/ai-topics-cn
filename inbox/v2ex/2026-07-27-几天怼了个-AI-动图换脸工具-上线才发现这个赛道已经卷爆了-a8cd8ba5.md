# 几天怼了个 AI 动图换脸工具，上线才发现这个赛道已经卷爆了……

说起来挺惭愧的，没怎么仔细调研就动笔开始写了。
用 ShipAny 的 TanStack 模板搭了个架子，部署在 Cloudflare 上，调了个第三方换脸 API ，几天时间就怼上线了。结果上线后去 Google 一搜才发现，Face Swap 这个赛道卷得离谱……各种 AI 换脸工具铺天盖地，免费的一大把，付费的更不用说。
不过既然做都做了，就当是全栈练手和熟悉新工具链了。

🛠️ 技术栈

全栈模板：ShipAny TanStack 模板 （含邀请码，不喜可删）
部署与数据库：Cloudflare Pages / Workers + Cloudflare D1
AI 能力：第三方 AI 人脸检测与替换 API


✨ 目前已实现的功能

多格式支持：支持 GIF / MP4 / MOV / WebM 等动图与视频格式换脸
多脸识别：单人、多人都能换（最多支持 5 张脸）
零门槛使用：免注册、无水印、免费无限次使用
全平台兼容：PC 端与手机浏览器打开即用


📉 当前进展
最近刚上线，Google 倒是收录了，但外链数还是 0，DR （ Domain Rating ）也是 0，关键词排名排到了十页开外……可谓是任重道远。

💬 想听听各位 V 友 / 站友的意见
产品刚起步，非常希望大家能踩踩、提提建议：

交互体验：使用过程中有什么觉得别扭或卡顿的地方吗？
加载速度：全球访问/生成速度感觉怎么样？
商业化思考：如果是你，会为这类工具付费吗？（比如批量处理、超清 4K 输出、更快生成通道等增值功能）
