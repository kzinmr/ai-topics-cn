# 切换了 codex 账号，发现旧对话里的项目可以继续，并且可以想用新账号的 token 量

刚开始用 codex 的时候，使用了 A 邮箱，由于没充 plus ，所以 token 只有一丁半点。
第二天，团队购买了 Codex 的 Team 套餐。绑定了我的 B 邮箱（我的常用邮箱）
由于我用 A 邮箱登陆的 Codex 里面的内容不多，我就直接在 codex 里退出账号，并登陆了 B 邮箱的 chatgpt

路径如下：
1.codex 左下角推出
2.打开 B 邮箱所在的 chrome ，用 google 账号登录 chatgpt
3.加载一下，对话可以继续，项目文档都在


发现了这个作用后，我在使用团队的 Team 套餐时，常常也不够用，这时候我就会切回 A 邮箱登录，继续白嫖一些免费的 token 。

总结以上的所需条件：

1.多个 google 账号并已注册 chatgpt
2.这些 google 账号都已经通过 Codex 电话号码验证


关于谷歌账号和手机验证码获取，

我当时是用的 dogesms 的码，起充 3 美金，一次验证码是 0.25 美金，所以我用了两个，花了 0.5 。

google 账号是当时为了买学生套餐一年份的 GEMINI Pro 所以在咸鱼买了带账号+Pro 一年套餐的，花费 138 元。

理论上而言，只要有多个 codex 账号，就可以更灵活获取流量，但是我目前只尝试过 2 个 codex 账号，我是否可以多备几个号？？不知 OpenAI 有没有这方面的措施，如果有经验的话，敬请分享。


一些 TMI
近期电脑坏了拿去送修，我在老拖拉机电脑登陆了 codex ，尽管是老帐号，依然是对话不共享的。我的老电脑第一次下载 codex ，里面空空如也。

这与我使用 claudecode 是一样的，我用 claudecode 也购买了企业套餐的两个席位，高强度工作的时候我会无缝切换账号来补充 token 。
