[分享创造] PickZ （ chrome 插件） —— 选中即翻译/总结/改写/解释的轻量 AI 悬浮助手
PickZ 做的事情很简单：在任意网页上选中文字，旁边浮出一个按钮，点击即可 翻译 / 总结 / 改写 / 解释，结果在小悬浮窗里流式输出，复制、重试都在手边。
商店链接： https://chromewebstore.google.com/detail/pickz-ai-悬浮助手/nkhambeanbcflohmbgiebhjhdplhejpp
为什么做这个
平时读英文文档、技术博客，最烦来回切换翻译工具。沉浸式翻译这类方案主打整页对照，但很多时候我只想"看懂这一段"，甚至想让它给我解释某个概念。于是做了这个"选中即用"的小工具，主打零打断。
功能

选中即用：选中文 → 悬浮按钮 → 翻译 / 总结 / 改写 / 解释，四选一
单词语典模式：选中单个英文单词，直接给出词典条目（音标 / 词性 / 例句 / 搭配 / 同反义词），不用再开词典 App
页面级操作：右键"总结此页 / 翻译此页"，自动提取正文，不用手动复制全文
快捷键：Ctrl+Shift+K 直接唤出悬浮窗
外观：跟随系统 / 亮 / 暗主题，字体大小、悬浮窗宽度可调，窗口位置跟随选中处
流式输出 + 复制 / 重试按钮

模型与费用

内置 DeepSeek V4 Flash，免费 20 次/天（匿名自动注册，无需登录）
BYOK：设置里填 DeepSeek 或 OpenRouter API Key ，走你自己的配额，无每日限制，零成本
GPT-4o-mini / GPT-4o / Claude Haiku 等模型（ Pro 档，逐步开放）
支持自定义 Base URL
