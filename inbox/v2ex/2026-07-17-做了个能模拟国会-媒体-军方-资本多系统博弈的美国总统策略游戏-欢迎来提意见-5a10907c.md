# 做了个能模拟国会、媒体、军方、资本多系统博弈的美国总统策略游戏，欢迎来提意见

最近把一个政治策略模拟游戏的 Demo 上线了 Steam ，叫《金权帝国》（ Electoral Empire ）。核心玩法是扮演美国总统，同时管理国会、媒体、军方、资本、舆论等多个相互强耦合的系统，观察不同决策在长期产生的连锁反应。
游戏想做的核心
我设计了大量相互影响的反馈回路，主要包括：

国会卡牌战与议员拉拢
媒体宣传与舆论反噬机制
军方忠诚度与行动选项
资本游说和经济政策的相互制约
情报、股市、国际关系等多层系统

我想让玩家感受到：短期内看似合理的决策，在长期可能会引发系统性的连锁后果，而不是简单的善恶二元选择。
技术实现与挑战
因为系统之间耦合度很高，任何状态变化都可能引发大范围连锁反应，所以我花了不少精力在模拟的确定性上。
目前的主要技术尝试包括：

自定义确定性双缓冲状态引擎，保证事件更新顺序和状态变更的可复现性
所有随机事件都通过带种子的确定性随机源生成
前端使用 Electron + React + TypeScript + ReactFlow + Konva 做可视化
本地运行 Ollama + Qwen GGUF 模型驱动部分 NPC 决策（完全 on-device ）

最大的难点在于：如何在保持系统复杂性和真实感的同时，维持整体模拟的确定性。尤其是当本地 LLM 参与决策时，如何在不破坏可复现性的前提下让行为看起来合理，目前还在持续调整。
欢迎有做过确定性模拟、复杂状态机、或者本地 LLM 应用的朋友交流经验。
