# [NanoTab] vibe 了一款 mac 窗口切换工具并分享一下我的窗口管理方案

NanoTab
NanoTab 是一款面向键盘用户的 macOS 窗口切换器：通过窗口图标、标题和数字编号，快速定位并直达任意窗口。它保留同一应用的独立窗口与最小化窗口，让多桌面、多窗口工作流更顺手。
开发动机：
在我日常使用窗口切换时，往往需要通过图标加上标题来定位窗口，在此基础上我希望能通过数字键盘快速高效的直达窗口，看了下市面上常见的 mac 窗口切换工具都不是我想要的样子，所以我自己 vibe 了一个并分享一下我的使用经验。
基础功能：



快捷键
操作




↑ / ↓ 或 K / J
选择上一个或下一个窗口


← / → 或 H / L
切换上一页或下一页


Return
切换到所选窗口


1–9
切换到对应编号的窗口


M
最小化所选窗口(cmd+m)


Backspace
关闭所选窗口(cmd+w)


长按 Q
退出所选窗口所属应用(cmd+q)


Esc
关闭切换器

窗口布局快捷键：
在设置中开启“窗口布局快捷键”后，可将当前所选窗口快速摆放至屏幕对应位置：



快捷键
位置

S / D / F
左半屏 / 全屏 / 右半屏


X / C / V
左下 / 下半屏 / 右下

经验分享：
在平时工作，我会分出四个虚拟桌面，桌面 1 用来放聊天、音乐等应用；桌面 2 放浏览器；桌面 3 放 ai 工具；桌面 4 放代码编辑器。通过 karabiner 将caps + 1-4变成ctrl + 1-4来方便切换虚拟桌面，右边的 cmd 键绑定为opt+tab，这样就可以更快速的唤醒 NanoTab 来切换窗口，经此设计可以尽可能减少手部移动来进行操作。
