# [招聘] 生物医药 AI｜资深 AI 全栈工程师（LLM/RAG/Agent）|35～ 55K｜北京/上海 |

1.关于岗位
我们正在寻找一位以软件工程和后端开发能力为核心，同时具备 AI 应用开发经验的资深 AI 全栈工程师。你将负责企业级 AI Agent 产品的架构设计、研发落地与持续演进，与优秀的工程团队共同打造面向真实业务场景的下一代 AI 产品。


2.岗位职责
	#1 负责 AI Agent 系统的架构设计、开发与持续优化，构建高性能、高可用、高可靠的 AI 应用。
	#2 负责大语言模型（ LLM ）相关应用开发，包括 Agent 、RAG （检索增强生成）、Workflow 、Tool Calling 等核心能力建设。
	#3 负责 AI 产品前后端开发，完成 API 服务、知识库、向量数据库、多模型路由、缓存、任务调度及 Web 应用等核心模块的设计、开发与优化。
	#4 持续优化系统性能，包括并发处理、数据库访问、缓存机制、异步任务、资源调度及成本控制，不断提升系统稳定性、运行效率及用户体验。
	#5 与产品、算法、前端及数据团队紧密协作，共同推进 AI 产品研发与落地，解决复杂技术问题，推动业务持续创新。
	#6 跟踪 AI 与软件工程领域的前沿技术，持续优化系统架构与研发流程，推动技术创新和工程实践落地。


3.任职要求
	#1 本科及以上学历，计算机、软件工程、人工智能等相关专业，3 年及以上开发经验；优先考虑毕业于国内双一流高校（ 985/211 ）或海外知名院校的候选人，特别优秀者可适当放宽。
	#2 具备扎实的软件工程能力和后端开发基础，熟练掌握 Python 、Java 、Go 、C++、Rust 等至少一种主流后端开发语言，熟悉 FastAPI 、Django 、Flask 、Spring Boot 、Gin 等至少一种主流后端开发框架；具备一定的前端开发能力，能够独立完成 AI 产品前后端协同开发。
