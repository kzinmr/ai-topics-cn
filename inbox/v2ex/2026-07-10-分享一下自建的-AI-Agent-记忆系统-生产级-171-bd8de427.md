# 分享一下自建的 AI Agent 记忆系统——生产级， 171

问题很简单：AI 智能体记不住事。每次新会话都是"陌生人"。

解决思路也不复杂：外挂一个 sidecar 进程，专门负责记忆。

用 gbrain （知识图谱）存概念关系
用 Hindsight （向量记忆）存事实
用 FTS5 做全文检索
三层混排召回，每天跑维护/压缩/健康检查
装好后几乎无感，Agent 自动受益

🔗 https://github.com/mage0535/hermes-memory-installer
目前已经迭代到 v3.5.2 ，支持多智能体隔离、DeepSeek/OpenAI 多种 embedding 模型可选、dashboard 可视化运维。
配合 KMM （ Knowledge-and-Memory-Management ）插件采集知识，支持 Scrapling （绕过 Cloudflare ）、抖音视频采集、40+ 采集工具。
全 MIT 开源，欢迎 star / fork / 提 issue 。
