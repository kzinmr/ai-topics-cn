# 用 Claude Code 写小说、拍短片和科幻短篇《存续》

我自己用 Codex 和 Claude Code 也写了蛮多项目了,但感觉点子越来越稀缺——毕竟同样的软件,有一个好用的就够了。
于是我尝试用 Claude Code 来写小说、创作剧本。毕竟作品和创意,只要足够好,大家也不会拒绝另外一个新故事。尝试下来,Claude 的文字能力蛮好的,只不过有一些奇怪的翻译腔,比如 carry it 容易变成"帮你扛"、got you 变成"接住你",其他还挺好的。于是有了小说《存续》:
📖 小说《存续》(豆瓣阅读):https://read.douban.com/ebook/747504749/
然后结合 Seedance 2.0 和 GPT Image 2.0,就可以去拍短片了。GPT Image 2.0 的艺术风格非常多,可选的范围很大。这个短片的剧本、分集 prompt 和参考图我也都开源了,感兴趣的可以去看看、follow:
🛠 《存续》创作仓库 —— 剧本 + 分集 prompt + 参考图(GitHub):https://github.com/code4craft/drama_survive
