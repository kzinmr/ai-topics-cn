# 专科大二，喜欢底层开发(?)，但有点迷茫想听听建议...

我是专科 大二的学生，因为比赛拿奖有个专业课免试资格，所以升本能去本省计算机专业里最好的本科
本来是留校实习的，但因为种种问题（没有处理这种事的经验），现在被流放到市场了。
我现在感觉到 AI Agent 对 CRUD 写胶水真没什么意思了，我个人很喜欢计算机，10 年前就注册了 Github ，最早是用 Java 写一些 Android 小应用发到当时的酷安市场，几 w 的下载量，谈不上厉害，但那时候的我也挺开心的。
之后接触 Webdev ，最开始 Vue->Go ，到现在 AI agent 最喜欢的 Nextjs+tailwindcss
我感觉应用层变来变去，你很难在其中找到一个属于自己的位置，我最早接触 Webdev 的时候 jQuery+PHP 特别火，现在已经查无此人了
去年 25 年 7 月，我开始接触嵌入式，我做了一个智能车
项目的详细可以看我写的一篇博客文章：https://lycois.org/cn/blog/2025/rasp-robot-car/cn

当时我没有用 AI Agent 写代码，真的就是闷头学，但其实只学了点皮毛懂点嵌入式基础的通信协议，GPIO, I2C, SPI ，串口通信什么的，学了点 gdb 调试，懂了什么是 CPU 中断，CPU 时钟，
再学学调 PID ，看了看增量式 PID ，位置式 PID 。
然后让 AI agnet 用 Nextjs 搓了个可视化的控制面板，控制面板与树莓派用 WebSocket 连了一下，用 mjpg 图传。
然后在电脑搭了个简单的中间曾，用 YoloV8 去做目标检测，整个流程就变得稍稍有点复杂：STM32->树莓派 -> YoloV8  flask -> Nextjs
整个项目耗资 800¥，我的感受是在资源极度限制的情况下，其实也很有意思。
