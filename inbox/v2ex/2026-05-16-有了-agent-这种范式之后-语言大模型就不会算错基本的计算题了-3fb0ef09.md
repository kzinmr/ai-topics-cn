# 有了 agent 这种范式之后，语言大模型就不会算错基本的计算题了

以前都说 LLM 是推理下一个字符，所以有可能算错 10+11 这种最基本的计算题
现在似乎不会了，agent 的逻辑之下，LLM 会发现这是一个计算题，所以会当场写一个脚本再来算，就不会算错了
很多以前纯靠预测字符的方案难以解决的问题现在似乎都被解决了（至少不会再犯离谱的错误
