# [纪念碑] 想听听大家在 AI 时代降临之前只靠自己做到的有趣的事情

昨天突然发现，自己一年多之前给gpu.js提的 pull request 被合并了，突然很感慨，
那个时候我用 AI 还比较少，在一个陌生的开源项目中，为了找到这么小的一个问题，我当时慢慢排查，陆陆续续花了好几天。
而在今天，恐怕只需要花几毛钱甚至几分钱，交给大模型，五分钟就会搞定这一切。
可以想象，如果一个沉浸在 vibe coding 里、从未体验过"古法编程"的新时代开发者，大概连stackoverflow这个曾经如此辉煌的网站都不会知道，因为很多一般性的技术问题都会被大模型轻松解决掉。
这样的新时代的开发，大概也不再会像这样对技术进行激烈的“讨论”。例如这个帖子
所以我想在这里立一个纪念碑，我想听一听各位在 AI 时代降临之前，只靠自己就做到的有趣的事情，那些值得你骄傲的事情。
从出生就沐浴在 AI 时代的开发者，未来看到我们这个帖子，一定也会有不同的感受。
我先来分享：
在 2019 年，我第一次成功地给开源项目贡献了一个pull request
那还是 vue2 的时代，我优化了 element-ui 的 tree 组件的性能。
当时我在想，自己真的能给这么大的项目做贡献吗？在这样的自我怀疑中，我战战兢兢的提交了 pull request 。
经过一番波折，最终代码被真的合并了。后来发布版本的时候，看到自己在贡献者名单里，到今天都能回忆起当时激动的心情。
现在轮到各位了，在这个独一无二、新旧时代交织在一起的背景下的过来人，分享你的故事。
