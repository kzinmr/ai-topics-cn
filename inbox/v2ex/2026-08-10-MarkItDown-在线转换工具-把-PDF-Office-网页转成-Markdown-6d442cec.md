# MarkItDown 在线转换工具：把 PDF、Office、网页转成 Markdown

最近把 MarkItDown 的常用转换流程做成了一个在线工作台，适合把 PDF 、Word 、PPT 、Excel 、HTML/URL 、图片和音频等资料整理成 Markdown ，方便后续放进 RAG 、知识库或长上下文模型里 review 。
入口：MarkItDown 在线转换工具
这个站不是 Microsoft 官方项目，而是围绕开源 MarkItDown 工作流做的 hosted layer 。现在默认有游客免费转换次数，登录后也有更多免费次数；后面主要想继续把 API 、MCP 、批量转换和格式 QA 做扎实。
