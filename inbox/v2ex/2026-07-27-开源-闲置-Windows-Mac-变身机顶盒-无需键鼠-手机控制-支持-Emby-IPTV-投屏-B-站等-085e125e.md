# [开源] 闲置 Windows/Mac 变身机顶盒（无需键鼠）手机控制（支持 Emby/IPTV/投屏/B 站等）

背景
家里有一台闲置的 Mac mini M1，还有一台 N100 小主机，我平时主要跑下载和 Docker ，一直想着榨干他们俩的性能。如果用来放蓝光原盘电影，这两个机器 CPU 肯定都绰绰有余，毕竟都是走硬件解码，就是放电影有点麻烦，准备一个空中飞鼠总感觉不太优雅。
为了正经看电视，我还买了 Apple TV，搭配 Emby 库，用免费的网易爆米花 App 其实已经挺顺手了。有几个美中不足的地方：

我有时候看剧，会频繁滑动进度条和切换倍速，用遥控器操作还是稍微有点麻烦。
看国内的流媒体费劲，要么投屏没有倍速和弹幕，要么就是安装一些无法上架的第三方 App ，而且它还让我升级电视专用会员😅

怎么折腾都差点意思，那就只能自己动手了
TinyPlay
把闲置的 Windows + macOS 小主机变成电视盒子 无需键鼠的情况下，躺在沙发上用手机优雅的操控
TinyPlay 不追求把电脑变成配置很重的全能媒体中心，只是希望让闲置的 NUC ，开箱即用的转变成一个机顶盒/电视盒子/HTPC
功能介绍

Emby / Jellyfin / Plex
本地文件、WebDAV 、SMB 、NFS
IPTV 直播源
DLNA 投屏接收器（支持倍速）
网页浏览器访问 B 站 / 爱优腾 / 抖音精选 或者其他自定义网址

手机端扫码打开遥控器后，可以选片、快进快退、拖动进度、切换音轨/字幕、调整倍速。
播放引擎
使用了 mpv （ IINA 同款引擎），色彩管线选择了 gpu-next （对杜比视界更友好）。


网页浏览器这块借鉴了 Chrome 扩展 Vimium 的思路：页面上可点击的元素会标记为短字符，手机输入字符即可点选，完全无需键鼠。
