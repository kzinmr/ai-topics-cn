# 虽说 vibe coding 遍地走，但自己从零手搓完一个完整的 App，感觉还是不一样

最近 AI 编程、vibe coding 的话题有多火大家都知道。虽说现在靠 prompt 堆出一个应用已经快变成基本操作了，但当我自己真正从零开始，靠着 vibe coding 把一个能完美解决自己切身痛点的 Android App 跑通、打包并开源出来的时候，那种满足感和以前给公司拧螺丝，还是完全不一样的。
💡 为什么想写这个 App ？
家里有娃的 V 友可能深有体会。现在给孩子报个课外班、兴趣班实在是太心累了：

数据极度分散： 不同机构的规则五花八门（有按课时包算的、有周期卡的、还有寒暑假集训的）。请假、补课、消课的数据散落在各种机构小程序、微信群通知、老师的 Excel 表格和家长的记忆里，每次对账都头大。
缺乏家长视角的工具： 市面上多的是给培训机构用的管理系统，但没有一个是纯粹站在家长日常记录和对账视角来做的。
隐私焦虑： 孩子的上课照片、付款截图、比赛奖状，我实在不想默认上传到某些不知名小公司的云端服务器上。

🛠️ 于是，我用 vibe coding 搓出了「课小记」
一句话定位就是：手机优先、本地数据优先的家庭课外记录本和孩子成长档案。
为了解决我自己的痛点，我给它设计了这几个核心能力：

纯本地，数据可控：无需登录，所有数据、照片全部保存在本地。支持通过 WebDAV （比如坚果云）自行备份、恢复，或者在家庭成员之间同步。
死磕复杂的购课规则： 专门适配了课时包、周期卡、寒暑假班、集训课、赠课包等各种复杂的权益形态。
3 秒极速记上课： 首页自动生成近期的待处理课程，家长在接娃下课的路上，点一下“已上课/请假/缺课”就能完成销课流水。
多维度账本与成长线： 自动统计时间投入、金钱投入。同时把孩子的证书、比赛、照片串成一条清晰的成长时间线。
