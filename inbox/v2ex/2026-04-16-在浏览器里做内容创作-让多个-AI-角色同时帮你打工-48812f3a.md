# 在浏览器里做内容创作，让多个 AI 角色同时帮你打工

做内容创作的时候喜欢边写边和 AI 聊，但来回切编辑器、浏览器、终端，思路总是断。想找个工具让这个过程顺一点，但要不要求本地装一堆东西，要不云端处理又不放心数据安全。
所以我自己写了一个：CreatorWeave ，在浏览器里跑，你的本地文件只有你明确授权的文件夹才能访问，不会乱翻。
👉 在线体验： https://creatorweave.eo2suite.cn/ ｜ GitHub： https://github.com/nutstore/creatorweave
⚠️ 建议用 Chrome 打开，部分 API 在其他浏览器不支持或被阉割
能做什么：


打开网页就能用，不用装任何 IDE 或配置环境


本地文件操作在本地进行，浏览器沙盒保护，只有你授权的文件夹可以访问


多工作区并行——类比 git worktree ，但不用懂 git ，多个创作分支同时跑


多智能体协作——可以创建不同角色的 AI （比如"主笔"、"编辑"、"资料整理"），让它们配合完成复杂任务
