# 开源] Late Eastern Han Dynasty — 用 React + Konva 做的节点式三国大战略，寻同好

先放链接： https://github.com/CtxPilot/Late-Eastern-Han-Dynasty
这个项目是我一个人在做，先交代背景：我今年 40+，计算机硬件出身，不是程序员，代码主要靠 AI （ GLM 、Kimi ）辅助 + 自己啃文档。起因纯粹是爱好——从小读三国，一直想做一款不是光荣换皮的三国策略游戏。
目前进度：
✅ 节点式州郡地图（ Konva 渲染，可点击、缩放、势力色动态变化）
✅ 50+ 武将数据系统 + 抽象剪纸风格头像（ AI 生成 + 后期标准化）
✅ 基础回合制框架
🔄 历史事件链系统（ 189-208 年时间轴）
🔄 外交博弈系统（关系值 + 信誉 + 囚徒困境 AI ）
⏳ 自动战斗结算
技术栈：React 18 + TypeScript + Vite + Konva.js + Zustand + Tailwind
我在找这样的人：
前端开发者：熟悉 React/TypeScript ，帮忙做 UI 面板（目前面板是 React HTML 浮层 + Konva 游戏层混合架构，需要优化层级和交互）
游戏逻辑开发者：喜欢策略游戏，能把设计文档（事件系统、外交系统）翻译成代码
三国历史爱好者：帮忙审事件设计、武将数据、地理考据
这不是商业项目（至少目前不是），没有工资，但：
设计文档已经写好了，你不需要从零想机制
代码规范有 AI 辅助维护，不会让你接手一团乱麻
如果未来上架 Steam/itch.io ，贡献者名单会出现在致谢里
