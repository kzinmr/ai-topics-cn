# 做了个 App：把 AI 生成的 HTML 小工具直接放进手机运行，求拍砖

做了个手机端 HTML 运行器，把 AI 生成的小工具直接放进手机用
这阵子经常用 AI 做些小工具：计算器、表格处理、数据面板、小游戏、计时器、临时表单……生成很快，最后通常就是一个 HTML 文件。
麻烦出现在手机上。要么临时部署，找个地方托管；要么每次去文件里翻，而且手机浏览器也不支持直接打开运行 HTML 。
很多东西只给自己用，专门配服务器、域名，再发布也很麻烦。
要开发成原生 App ，走打包编译，处理跨平台，也不值当。
现在的 HTML 其实已经能做很多事了。图表、文档、本地存储、图片处理、小游戏都能实现。对不少轻量、个人化的需求来说，一个静态 HTML 就够用。
缺的是一个方便放进手机、随时打开的入口。
于是我做了「 Vibe 小匣」。

它能做什么
从聊天软件、文件 App 或云盘拿到 HTML / ZIP 后，可以直接分享到 Vibe 小匣：

自动解压并识别 HTML 入口
在手机里直接运行
保存到“我的应用”，以后继续打开
查看目录、README 、源码和运行日志



Vibe 小匣不限定应用类型，只要能在普通浏览器里直接运行，就可以导入。
也可以只看源码
收到一份源码 ZIP 时，有时候并不想运行，只是想看看里面写了什么。
Vibe 小匣可以快速浏览文件目录，查看 HTML 、CSS 、JavaScript 、JSON 、Markdown 等文件。

实现和边界
导入的项目保存在本机，每个项目有独立目录和运行数据，规避了数据泄露问题。
运行 HTML 容器尽量贴近标准 Web 行为，不要求导入的 HTML 接入专用 API 。
当前主要支持静态 HTML 、CSS 和 JavaScript 。已经构建好的 React 、Vue 静态产物也可以导入。
