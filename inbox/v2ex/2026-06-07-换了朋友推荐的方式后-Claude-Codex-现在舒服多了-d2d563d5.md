# 换了朋友推荐的方式后， Claude + Codex 现在舒服多了

前天发了个吐槽访问问题的帖子，没想到回帖还不少，看来被这玩意儿折腾的老哥真多。
我自己从四月底开始就把 Claude Code 和 Codex 当主力用，两个多月下来做了好几个项目。效率是上来了，但之前稳定性把我搞得够呛。高峰期老卡，夜里想干活的时候突然抽风，切换模型也麻烦，自己之前折腾了好几次，浪费不少时间，效果还一般。
后来朋友看我天天抱怨，就给我推荐了一个方式让我试试。我换过去快三周了，现在感觉顺手多了。几个模型统一管着，切换快，高峰期和深夜也稳很多，token 跑得猛但最后算钱没多多少，省心省力不少。
现在写代码的时候明显轻松多了，不用老是提心吊胆。
