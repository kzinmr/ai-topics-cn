# 多宽带求推荐路由器或者方案

1 条联通 300M 、1 条联通 500M （其实是两个账号，共用一个 2.5G 猫棒）汇聚后测速有 1200Mbps 左右
1 条移动 500M （后期可能升级 1000M ）
其中，联通是公私网混用的（也就是可以多次拨号获得公网 ip ），联通的公网 ip 是我在外面主要的访问入口（ NAS 等资源）
目前是接入到服务器中的 ikuai 虚拟机使用，ikuai 有拨号异常 ip 筛选这个功能挺好的，可以直接帮我获取联通的公网 ip 。但是爱快免费版只能一条 v6 ，且其他功能有受限。
现想将路由功能从服务器中剥离出来独立运行，但是转了一圈都没发现有很合适的路由器，因此求各位 V 友推荐一下。
1 、要实现拨号异常 ip 筛选功能。（即联通拨号直到公网 ip 为止）
2 、分流。（移动有电视资源，分流走移动线路可以任意设备播放）
