# 第一次 claude 封号经验

公司注册了一批号，都是海外真实住宅家宽环境注册，每个号都是独立动态 ip 注册，找海外合作伙伴注册的，ip 质量分满分

然后拿回国内使用，就正常挂着，用住宅 ip 节点，关闭定位，每天上去发两条消息，没有用指纹浏览器，没有改时区，就挂了个代理，其他什么都没做防护，1 个月下来所有的号都存活。

重点来了，移交了一个账号给某申请使用的同事，为其配置了与挂机机器相同的节点，ip 没有跳，不到半小时后同事通知封号。问他干了什么，他说就让它分析了个代码什么都没干。

我个人倾向于封号并非新设备登录，更不是跳 ip ，因为我自己的账号登录了 8 个设备也没有任何问题。我个人推测是环境问题，我挂机那台电脑没有公司的 DLP 软件，而同事的那台有，所以我个人认为尽量不要在一些安装有在第三方视角像“流氓软件、病毒”的软件，尤其是一些具备权限很高的软件
