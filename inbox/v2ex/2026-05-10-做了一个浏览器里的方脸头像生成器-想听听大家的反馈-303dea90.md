# 做了一个浏览器里的方脸头像生成器，想听听大家的反馈

最近做了一个小工具：
https://squareface-generator.org/
它是一个在线的 Square Face Generator ，主要用来生成比较可爱的方脸头像、PFP 、社交平台头像，适合 Discord 、X 、YouTube 、TikTok 、论坛、游戏账号之类的场景。
做这个工具的原因比较简单：以前有很多类似的方脸头像生成器，但不少都是 Flash 时代的产品，或者体验比较旧，在手机端和现代浏览器里用起来不太方便。我想做一个更轻量的版本，直接在浏览器里打开就能用，不需要注册、不需要安装 App ，也不需要写 AI prompt 。
目前主要功能有：
在浏览器里直接生成头像
支持随机生成方脸头像
可以调整脸型、头发、眼睛、嘴巴、衣服、配饰、背景等元素
支持 classic / pixel / original 这类风格
可以导出 PNG 图片
可以生成分享链接
有一个公开 gallery ，可以看其他生成结果找灵感
不依赖 Flash ，也不需要安装插件
技术上主要是用 HTML5 Canvas 来做头像绘制。头像本质上是多个图层组合，比如背景、脸、头发、眼睛、嘴巴、衣服、配饰等。每次用户切换某个部件时，就重新绘制 canvas ，最后再导出 PNG 。
做的过程中发现，头像生成器看起来很简单，但实际有不少细节：
比如图层顺序很重要。头发、帽子、眼镜、衣服这些元素如果层级不对，生成出来就会很奇怪。
随机生成也不是完全随机就行。不同部件之间需要保持一定的协调性，不然很容易出现颜色冲突、风格不统一、配饰和发型不匹配的问题。
另外，移动端体验也比想象中麻烦。因为头像编辑器需要有预览区、部件选择区、下载按钮，如果布局没处理好，手机上会显得很拥挤。
我现在的思路是先把核心体验做轻：
打开网站 → 随机生成 → 微调部件 → 下载 PNG 。
