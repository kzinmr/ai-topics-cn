# 做了一个 Video to Prompt 工具：上传视频，自动拆成逐镜头 Prompt

兄弟们，好久没发帖了，最近一直在更新我们的新产品功能，最新我们优化了一下视频脚本解构功能，也就是视频转提示词，可以用于视频二创的脚本解构或者 AI 视频生成的提示词反推：
尤其是在拆解一些电商带货视频时比较好用，我们的用户反馈都还不错，欢迎大家试用一下 给点建议，注册送积分哈，不够用的朋友可以留言多送点积分
最近在用 Veo 、Kling 、Runway 和 Sora 做视频时，
经常遇到一个问题：
看到一段不错的参考视频，知道它的节奏、运镜和画
面感觉都对，但很难准确描述，更别说拆成可以复用
的 Prompt 。
所以我们做了一个 Video to Prompt 工具。
上传一段视频后，它会自动识别镜头变化，并逐镜头
分析：

镜头时长与景别
场景和主体动作
摄像机运动
构图、光线与色调
对白、环境音和音效
镜头转场
每个镜头对应的生成 Prompt

除了逐镜头结果，还会生成完整 Storyboard
Prompt ，并整理成适合 Veo 、Kling 、Runway 、Sora
等模型使用的格式。
目前支持：

上传 MP4 、MOV 、WEBM
粘贴公开可访问的视频直链
每次分析 1–100 个镜头
音频和对白分析
逐镜头参考截图
一键复制完整 Prompt
导出带截图的 Excel Storyboard
未登录用户每天可以免费试用

我们也放了 4 个真实解析案例，可以直接切换查
看：

Product Showcase
Social Media Style
Food Close-up

需要提前说明：目前支持的是视频文件和公开直链，
