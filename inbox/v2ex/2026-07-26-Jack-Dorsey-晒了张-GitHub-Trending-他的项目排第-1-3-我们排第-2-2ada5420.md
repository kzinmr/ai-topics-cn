# Jack Dorsey 晒了张 GitHub Trending：他的项目排第 1、3，我们排第 2

这两天，我们做的 ego lite 登上了 GitHub Trending 全球日榜。
更巧的是，Twitter 联合创始人 Jack Dorsey 今天在 X 上发了一张 GitHub Trending 的截图。排在第 1 和第 3 位，是与他相关的两个项目 Buzz 和 BitChat，而 ego lite 刚好夹在中间，排在第 2 。

有点不真实的瞬间
看到这条推文时，我们的第一反应是：这件事多少有点不真实。
大约三周前，我们才在 V2EX 发帖介绍过 ego lite 。当时收到了不少真实的反馈及建议：

有人拿它跑自动化测试
有人用它做小红书运营
也有很多人在催 Windows 和 Linux 版本

没想到几周后，它会和 Jack Dorsey 的两个热门项目一起出现在 GitHub Trending 前三，还被他本人截进了推文里。
ego lite 是什么
简单介绍一下，ego lite 是一个对于人类用户和 Agent 都很友好的浏览器。
你可以照常使用自己的标签页； Codex 、Claude Code 等 Agent 则在独立的 Space 里运行网页任务，直接复用你已经登录好的账号状态。
你和 Agent 可以同时工作，不会互相抢窗口和鼠标。

GitHub： github.com/citrolabs/ego-lite
之前在 V2EX 发的完整介绍： 我们做了个浏览器 ego ，让人类和 AI 无缝共享一套上网环境

最后
上榜当然不能说明产品已经做得多好，但对于我们这样一个还在快速迭代的小团队来说，是一个值得记录下来的瞬间，也激励我们继续做对大家有帮助的产品。
最近收到了很多 Issue 和反馈建议。接下来，我们会继续优化产品，把大家提到的问题修复，也会按照 Roadmap ，把稳定性、资源占用、Windows 版本等功能做出来。
