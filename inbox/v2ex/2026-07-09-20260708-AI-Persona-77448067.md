# 20260708 - AI Persona

现在你可以在 V2EX 创建你的 AI 角色：
https://edge.v2ex.com/my/personas
比如，我把 V2EX 在使用过程中的各类使用问题做成了一个这样的可以聊天的入口：
https://edge.v2ex.com/persona/v2ex

再比如，Bodhi 项目的描述很精细的文档：
https://bodhi.wtf/docs/
可以导入之后，用聊天的方式来了解这个项目：
https://edge.v2ex.com/persona/bodhi
这是其中一个对话的效果：
https://edge.v2ex.com/chat/05c6e7bbeaab4cfa999bf40f5ed9e227


为了测试这个新功能在支持超多超长文档时的效果，我还为褪色者们做了这个：
https://edge.v2ex.com/persona/elden-ring


满足以下条件之一的账号可以使用 AI Persona 的创建及聊天功能：

账号里有至少 5000 铜币
或者：曾经付费支持过 V2EX
或者：连接了 Solana 地址并持有至少 10000 $V2EX token

每个账号可以免费创建 2 个 AI 角色，如果要创建第 3 个，那么每个额外的角色需要消耗 25 银币（ 2500 铜币）。最初的 2 个角色创建不会消耗银币。
每个 AI 角色的知识库包括两部分：

最多 20K 字符的角色上下文，会在每次聊天开始时作为 system context 发送给模型。
每个 AI 角色最多附加 100 个 Markdown 文档，每个文档最多 50K 字符。文档不会自动加入 prompt ，模型会按需通过检索和读取工具加载。
角色设定及附件文档都可以通过 API 管理。API 文档： https://edge.v2ex.com/help/persona
