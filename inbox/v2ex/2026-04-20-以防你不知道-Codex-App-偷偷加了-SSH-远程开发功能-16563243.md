# 以防你不知道 Codex App 偷偷加了 SSH 远程开发功能

更新 Codex App 到最新，远程机的 Codex 版本在 0.121 以上
在配置文件 ~/.codex/config.toml 中加入
[features]
remote_connections = true

重启 App 就可以在设置中找到 Connections 配置项了
用了一天，感觉还可以
