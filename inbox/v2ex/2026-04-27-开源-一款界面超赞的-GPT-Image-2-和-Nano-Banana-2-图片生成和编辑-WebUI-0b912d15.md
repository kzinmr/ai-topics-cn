# [开源] 一款界面超赞的 GPT Image 2 和 Nano Banana 2 图片生成和编辑 WebUI

Peinture(派奇智图)是一款专注于图片生成、编辑和管理的 WebUI 。


项目早期通过接入 Hugging Face、Gitee AI、Model Scope 和 A4F 的平台的免费 API 实现“白嫖”平台算力来无限生成图片。
最近，我在这个项目的基础上，正式支持 GPT Image 2 和 Nano Banana 2 图片生成。您可以通过 设置-服务商 接入 OpenAI 或 Google 等服务商来实现图片生成和编辑服务。编辑模型可以在 设置-模型-编辑模型 中进行选择。
更多项目介绍您可以通过项目 README 进行了解。
项目开源地址：https://github.com/Amery2010/peinture
