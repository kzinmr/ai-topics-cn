# 做了个开源 AI Agent 管理工具，想听听大家意见

大家好，我最近做了 Clawke ，一个开源的 AI Agent 管理工具。
它原生支持 OpenClaw / Hermes / Nanobot 这类 Agent ，也支持 iOS 、Android 、macOS 、Windows 和 Linux 。
做这个项目的原因是：现在很多 Agent 工具还是像终端或普通聊天软件。简单对话没问题，但一旦 Agent 需要执行审批、工具调用、任务管理、技能配置、文件返回、运行状态展示，用纯聊天窗口就会变得很别扭。
Clawke 的思路是用原生客户端管理 Agent：审批、工具调用、任务、技能、媒体、网关状态都尽量做成原生交互，而不是让用户输入文本命令。
开源地址：
https://github.com/clawke/clawke
Product Hunt：
https://www.producthunt.com/products/clawke?launch=clawke
想请教大家：如果 AI Agent 以后真的会长期运行、调用工具、管理任务，你觉得客户端应该比聊天软件多做哪些能力？哪些交互是必须原生化的？
