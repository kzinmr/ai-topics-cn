# 文科生 vibe coding 了一个定制 kindle 词典的工具。欢迎试用+提意见。

项目地址： https://kindledict.vercel.app/ 
项目解决的痛点：
电子书内置的词典或者自己下载的通用词典，无法根据当前书籍的内容从剧情维度去解释某些专有词汇（人名、地名、某个领域的专业术语、只出现在这本书里的独特世界观术语等等）。这是我日常阅读最大的痛点。于是想着自己用 AI 自己做一个根据书籍内容定制一份专属于这本书的词典。
需要用自己的 api ；
需要另外下载 kindle previewer 来最终导出兼容 kindle 格式的词典，这个工具的作用只是根据内容生成定制词条。
