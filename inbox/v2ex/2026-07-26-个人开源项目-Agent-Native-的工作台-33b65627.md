# [个人开源项目] Agent-Native 的工作台。

大家好，我基于 claude agent sdk 构建了一个自托管的 Agent 工作台——muselab 。目前已经迭代了几个版本，自己也使用了一段时间了。

背景是日常使用 Agent 时遇到的几类问题：

同时处理多个项目，需要来回切换窗口；
Agent 在后台执行任务时，没有一个统一的状态入口；
离开电脑后，不方便查看进度或继续对话；
Agent 生成的 Markdown 、HTML 报告，需要额外打开其他工具预览；

所以我把文件管理、内容预览、AI 对话整合到了一个工作台里，并且做了多工作目录、任务管理中心等专门为了 Agent 的优化。
目前支持的能力
1 ．基于 Claude Agent SDK 构建
Agent harness 基本沿用 Claude Code 的能力，包括文件操作、终端执行、MCP 和 Skills 等。
本机已有的 Claude Code Skills 、Memory 、MCP 配置也可以直接复用，不需要重新维护一套 Agent 环境。
2 ．接入多种模型
Claude 可通过 OAuth 使用现有订阅；
Codex 可通过 Codex Gateway 接入；
支持所有 anthoropic-compatible API ，例如 Kimi 、GLM 、Deepseek ；
3 ．多工作目录
在 Agent 场景里，工作目录不只是文件路径，还包含项目级的完整 Agent 上下文，例如：
~/.claude/ 下的全局配置；
项目内 .claude/ 下的规则、Skills 和 Memory ；
