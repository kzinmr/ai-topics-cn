# 做了个 macOS 菜单栏小工具，把 Codex 周额度拆成每天额度看

大家好，我最近给自己做了一个小工具：Codex Quota Calendar 。
起因很简单：身边几个朋友用 Codex 的时候，经常两三天就把一周额度用得差不多，后面几天突然变得很克制，甚至没什么活能干。Codex 本身有周额度，也有 5 小时窗口额度，但我自己更想看的其实是一个更朴素的问题：

今天这一份平均额度，我用了多少？

所以我把它做成了一个 macOS 菜单栏日历。它会把本周剩余额度摊到每天，看今天的平均份额、周额度剩余、5 小时窗口状态，以及按最近本地记录估算当前使用速度。

我自己的使用场景大概是：

今天是工作日，就按剩下的天数平均用，不要上午一兴奋把额度打穿。
如果周三要出去玩，基本不用 Codex ，就手动调整剩余可用天数，让后面的额度重新摊平。
不追求“省着不用”，而是更有感知地把额度用完。
周额度和 5 小时窗口都看一眼，避免只看一个百分比导致节奏失控。

目前功能比较克制：

SwiftUI 写的 macOS 菜单栏 app 。
今日份额圆环和本周可用日卡片。
周额度和 5 小时窗口统计。
本地滚动历史记录，用来让速度和预计用完时间更平稳。
10 分钟刷新一次。
12 种界面语言。
已经打了 Developer ID 签名、公证并 staple 的 DMG ，可以直接拖到 Applications 。

隐私这块也按我自己能接受的方式做：没有服务器，没有分析统计，不做第三方追踪；只读取本机 Codex 授权信息，token 和额度历史都只留在本机。它不是 OpenAI 官方工具，只是我自己做的一个本地小工具。
