# 新站上线几天， GSC 有 195 次曝光但 0 点击，分享一下我的排查过程

最近做了一个关于 DeepSeek Harness 的英文站：
DeepSeek Harness Guide
站点上线后很快被 Google 收录了，GSC 也开始出现搜索词。截至目前有 195 次曝光，但点击数还是 0 。
一开始看到“有曝光、没点击”，我有点怀疑是不是页面、TDK 或收录出了问题，于是把 GSC 数据和实际 SERP 排名一起看了一遍。最后发现，对于一个刚上线的新站，这个结果其实很正常。
简单分享一下排查过程，也想听听大家做新站时的数据表现。
一、先看 GSC 数据
目前的数据大致是：

总曝光：195
总点击：0
覆盖国家：19 个
美国曝光：89 次，占 46%
桌面端曝光：166
移动端曝光：29
deepseek harness github 平均排名 8.5
deepseek harness 平均排名 29.5

这个站面向开发者，所以桌面端曝光明显高于移动端比较合理。美国占比接近一半，也说明 Google 初步识别到了目标市场。
比较容易让人误判的是“平均排名 8.5”。
我实际搜索时，并没有在稳定的前十名里看到自己的站。新站的排名会受到地区、时间、个性化结果和 Google 测试流量的影响。GSC 展示的是所有曝光的平均位置，并不代表页面已经稳定排在第 8 名。
二、为什么有曝光却没有点击
排查下来，主要有三个原因。
1. 排名还不够靠前
曝光最多的核心词 deepseek harness，平均排名只有 29.5 ，基本在第三页。
第三页的自然点击率接近于零，即使产生几十次曝光，没有点击也很正常。
另一个词 deepseek harness github 虽然平均排名是 8.5 ，但目前只有十几次曝光。假设第 8 到第 10 名的点击率为 1% 到 2%，预期点击数也只有 0.1 到 0.3 次。
