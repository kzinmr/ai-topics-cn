# 人生苦短，我用 Open Design

昨天下午抽空把 Codex CLI 装上，通过 CC Switch 把 TokenGo 里的 GPT-5.5 配置进去，再用 Open Design 跑了一轮原型。整套链路花了大概一小时，输出的原型水平和 Claude Opus 4.7 已经不分上下。
我这套使用链路是这样的。
第一节点是 Codex CLI 。OpenAI 官方的 coding CLI ，npm 全局装一下就行，配置过程没什么坑。
第二节点是 CC Switch 。轻量的模型切换工具，原本是给 Claude Code 用的，现在被很多人用来跨 CLI 管理多个 endpoint 。我用它给 Codex 注入自定义的 baseUrl 和 API key 。
第三节点是 OpenAI 转发。把 GPT-5.5 接到 CC Switch 里。中转的价值在于成本可控、省去外卡这一步、网络条件也不用单独安排。这条链路任何一个中转服务理论上都能替代，关键是要有这一层。
第四节点是 Open Design 。pnpm tools-dev 起服务，浏览器打开后会自动识别我 PATH 上的 Codex 。Skill 默认选了 web-prototype ，设计系统选了 Neutral Modern 。
https://open-design.ai
