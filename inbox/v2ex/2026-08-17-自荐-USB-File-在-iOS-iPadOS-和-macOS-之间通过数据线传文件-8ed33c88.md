# [自荐] USB File 在 iOS/iPadOS 和 macOS 之间通过数据线传文件

tl;dr
USB File 主页 https://apps.ihave.website/usbfile
USB File
因为工作原因，有时我需要往 iPhone 发送一些文件再分享给手机上别的软件，我所在的网络环境比较复杂 AirDrop 常常搜索不到我的设备，当时我就想开发一个工具能直接使用数据线把文件传输到 iPhone 。
忍无可忍后我开发了 USB File 用于 iOS/iPadOS 和 macOS 文件的双向传输。
软件我经常在用，每当我用到的时候我都会想软件真的帮我了大忙解决了我问题，所以我想分享出来用来解决类似的问题。
使用者需要在 macOS 和 iOS 上各安装 USB File 客户端，之后就可以在电脑和手机之间通过 USB 线传输文件（有点儿类似 Android File Transfer ）。
USB File 机制上十分干净，没有网络请求权限、没有后台权限用完即走。
USB File 主页在: https://apps.ihave.website/usbfile
iOS 客户端 AppStore 链接在: https://apps.apple.com/app/usb-file/id6795836260
