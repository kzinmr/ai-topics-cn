# 分享一个自己 AICoding 做的 Apple 原生 App： eDots —— 用来收集和重新遇见生活里的点点滴滴

我最近在做一个 Apple 平台上的个人工具，叫 eDots。

它的核心想法很简单：很多内容还没大到需要变成一篇笔记、一个文档、一个项目，但又不想丢在聊天框、相册、备忘录和待办里。
我把这些东西叫做 Dots：
一句想法、一个链接、一张图片、一个地点、一个待办、一段 quote ，都可以先被收下来。
eDots 不是想做另一个 Notion ，也不是重型笔记软件。它更像一个「轻量 Collection + 卡片」工具：

用 Collection 管理不同主题，比如书摘、灵感、旅行地点、待办清单、作品想法
每个 Dot 可以有 Markdown 、标签、封面图、链接、地点、评论、计数器
Collection 支持列表、卡片、日历、地图等不同查看方式
有随机抽取和每日 Widget ，适合把过去收集的内容重新翻出来
数据走 Apple 原生体验：Core Data + iCloud/CloudKit ，同步、Widget 、导入导出都尽量做完整

我自己做它的原因是：很多工具都在鼓励「收藏」，但很少帮助我重新遇见过去的东西。
eDots 更想解决的是：如何把那些碎片保存下来，又让它们在未来某一天重新焕发活力 ~
现在还是独立开发阶段，想在 V2EX 听听真实反馈，欢迎大家「把玩」，尤其是：

你们平时会怎么处理这种「太小不能成文、但又不想丢掉」的信息？
随机回看 / 每日 Widget 这种机制，对你有用吗？
这个方向更应该靠近笔记、任务、相册，还是保持一个独立的「 dots 」形态？
