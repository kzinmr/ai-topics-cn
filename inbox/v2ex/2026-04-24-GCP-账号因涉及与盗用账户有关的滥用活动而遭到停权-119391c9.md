# GCP 账号因涉及与盗用账户有关的滥用活动而遭到停权

GCP 账号被暂停经历记录
背景

绑卡情况：GCP 账号绑定了国内发行的万事达信用卡
订阅服务：购买了 Google AI Ultra 订阅
福利领取：利用 Ultra 订阅每月领取 $100 赠金
领取时长：成功领取了 2 个月
使用方式：仅开通了 Vertex AI 和 Google AI Studio
Key 用途：将 AI Studio 生成的 API Key 绑定在 New API 上，供自己的 Claude Code 使用

结果
账号被暂停，无法继续使用。
GCP 官方给出的暂停原因

说明：您的组织可能不慎在公开来源或网站发布了上述服务账户的凭证或 API 密钥，导致第三方得以利用这类信息在您的项目启动资源，因此项目 ai-*** (id: project-***) 遭到停权。

分析与推测



可能原因
分析




API Key 泄露
GCP 检测到 API Key 被用于第三方代理（ New API ），可能被判定为凭证暴露


异常流量模式
Claude Code 的调用模式与正常 AI Studio 用户不同，触发了风控


违反 ToS
将 AI Studio 的赠金 Key 用于商业级负载（ Claude Code 工作流）可能违反条款


国内卡风控
国内万事达卡 + 薅赠金行为，可能被 Google 风控系统标记

经验教训

避免高频生产级调用：Claude Code 这类工具会产生大量连续请求，特征明显
