# 吐槽一下 L 站的注册

很难想象一个程序员，没有测试或考虑过实际用户注册的流程。

linux.do 已经被墙，GitHub almost 被墙，linuxdo.org 却强制要求国内 IP 访问否则 block 。这意味着，你首先要代理打开 linux.do 置顶的帖子，然后直连帖子里的邀请链接，再代理访问🔗GitHub 账号注册。如果你不特意在 clash 中手写一个- DOMAIN-SUFFIX,linuxdo.org,DIRECT，这个流程几乎是不可能跑通的。
置顶帖子里不写具体开放日期，写明天，实际上是昨晚发的，也就是今天中午 12 点开放注册，这里很明显误导了一些人。
等你手写完 clash 配置，通过验证，却发现还是不行：服务开放时间为 20:00->08:00 。这就有点僵硬了。
另外理论上最简路径，即用 GitHub 账号登录那里，也没适配，不管是否满 5 年都会提示仅支持邀请注册。

L 站管理：有这么多问题，也没见人反馈啊（ bushi ）。
