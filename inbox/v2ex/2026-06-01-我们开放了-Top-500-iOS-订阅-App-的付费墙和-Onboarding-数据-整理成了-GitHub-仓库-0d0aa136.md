# 我们开放了 Top 500 iOS 订阅 App 的付费墙和 Onboarding 数据，整理成了 GitHub 仓库

我们最近把 PaywallPro 的一部分 iOS 订阅付费墙数据整理成了公开 GitHub 仓库。
这次开放的是 Top 500 iOS 订阅 App 的公开数据集，包含：

付费墙截图
Onboarding 预览
定价模型
付费墙模式
部分 MRR / ARPU / RPD 等变现信号
可机器读取的 Markdown 文件

这个仓库主要给几类人用：

做订阅 App 的开发者
做 AI 工具和出海产品的团队
产品经理和增长同学
想研究 paywall / pricing / onboarding 的设计师

后续我们会每周继续新增 50 个 App ，也会考虑做成 Skills ，让大家可以直接调用参考。
GitHub：
https://github.com/paywallpro/paywall-gallery
欢迎大家提 Issue ，告诉我们你最想看哪个 App 的付费墙。
