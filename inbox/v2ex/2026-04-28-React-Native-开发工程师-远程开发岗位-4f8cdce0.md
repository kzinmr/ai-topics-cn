# React Native 开发工程师（远程开发岗位）

职位概述
我们正在寻找 React Native 工程师，参与实际业务系统及移动端应用的开发与维护。你将以远程办公的形式加入项目，按实际工时结算薪资，合作方式灵活，适合自由职业者或希望长期远程合作的开发者。
该岗位主要负责基于 React Native 的 iOS / Android 应用开发，同时需要具备良好的工程化能力，能够独立完成业务功能开发、性能优化及跨团队协作。
工作内容

参与移动端应用程序的设计、开发和维护，确保应用的高性能、稳定性和可维护性
使用 React Native 开发高效、可复用的跨平台组件，确保代码结构清晰、一致
与后端开发人员协作，完成 API 集成、数据交互及业务逻辑实现
根据业务需求独立完成功能开发、问题排查及性能优化
编写逻辑清晰、结构规范的代码，参与代码审查，确保代码质量
处理 iOS / Android 平台差异问题，优化不同设备下的兼容性与用户体验
配合项目需求完成版本发布、调试及相关工程配置工作

任职要求

本科及以上学历，计算机科学或相关专业
至少 3 年以上前端或移动端开发经验
熟练掌握但不限于：React Native / JavaScript 或 TypeScript / Expo
移动端状态管理方案（ Redux / Zustand / Context 等）
熟悉移动端开发流程，包括调试、打包、发布（ iOS / Android ）
熟悉 API 对接、异步处理及常见移动端性能优化方案
能阅读英文技术文档、Issue 、报错信息，并可撰写基础英文技术文档
具备良好的自我管理能力，能够适应远程协作
对代码质量负责，有持续学习和改进意识

加分项（非必须）

有远程工作或自由职业经验
有 Expo / 原生模块（ iOS / Android ）开发经验
