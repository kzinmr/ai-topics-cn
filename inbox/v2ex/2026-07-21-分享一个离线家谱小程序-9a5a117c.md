# 分享一个离线家谱小程序

最近大家都在聊 vibe coding ，我也想实际尝试一下，于是做了这款家谱微信小程序。

所有家谱数据仅存储在本地，不需要注册，也不会上传到服务器。

技术栈：Taro + React 。

代码全部由大模型生成。其中，家谱画布和布局功能主要由 Fable 5 、GPT-5.6 完成，其余部分主要由 GPT-5.5 完成。
因为一直断断续续地摸鱼，这个项目的时间跨度有点久。根据账单估算，模型调用大概花了 300 ～ 500 元。

# 为什么要做

参加爷爷奶奶的寿宴时，我才第一次知道，原来他们有这么多兄弟姐妹，其中很多人我从来都没有见过。

后来我又发现，自己甚至连姥姥、姥爷的名字都不知道。至于爷爷奶奶、姥姥姥爷的父母叫什么，我也从未了解过。
