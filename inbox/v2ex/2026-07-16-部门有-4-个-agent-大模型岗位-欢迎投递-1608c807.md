# 部门有 4 个 agent 大模型岗位，欢迎投递

一、Agent 系统架构开发
基于 LangGraph 、LangChain 、LlamaIndex 搭建生产级有状态 Agent 工作流，落地 ReAct 、Plan-and-Execute 、Multi-Agent 等主流架构。设计多智能体协作体系，实现任务委派、权限移交、群组协同，基于 MCP 、A2A 协议完成工具统一接入与跨 Agent 通信。搭建 Agent 持久化执行、人在回路、异常重试、故障恢复等生产能力，提升复杂场景任务执行准确率与系统稳定性。
二、生产级 RAG 体系建设
搭建端到端生产级 RAG 流水线，实现非结构化文档解析、向量化构建、混合检索（向量+BM25+重排序）、查询优化、上下文压缩及 Agentic 自主检索能力。落地 GraphRAG 方案，结合知识图谱实现实体关联与多跳推理，负责领域知识库迭代、索引治理及性能优化。
三、提示工程与业务落地
负责大小模型提示词设计、迭代与版本管理，通过 A/B 测试持续优化模型输出效果，深耕主流开源大模型能力边界。跟进前沿 AI 技术并完成工程化落地，对接跨团队协作，将 Agent 能力封装标准化 API 赋能业务。负责技术文档输出，参与需求评审、项目立项与技术方案规划。
任职要求
本科及以上学历，计算机、软件工程等相关专业，3-5 年 AI 应用/后端研发经验，具备 AI Agent 、LLM 项目从 0 到 1 完整落地经验。
熟练掌握 Python/Java/Go 任意一门后端语言，具备扎实编码能力与工程化思维。
深刻理解 LLM 应用原理，熟练运用 LangChain 、LangGraph 、LlamaIndex 等框架，掌握多智能体协作、MCP/A2A 协议核心技术，具备复杂 Agent 系统开发经验。
