# 公司买了 token，同事偷偷把 key 给别人用

公司现在就剩 3 个开发，2 后端 + 1 前端。
前段时间公司买了腾讯云一个 300 块、3.2 亿 Token 的套餐。

按正常情况，3 个人日常办公和开发，其实完全够用。
但这两天 Token 消耗突然暴涨，短时间内直接用了接近 1 亿。

更奇怪的是，我们公司 10 点才上班，
但 Token 的消耗记录从早上 9:05 就开始了。

昨天到今天，我们其实一直在处理别的事情，根本没怎么开发。
所以我怀疑，很可能是有人把公司的 Token 拿给外部的人用了。

我还试探性地提了一句：
“最近 Token 消耗得有点快啊。”

其中一个人直接说不知道，
另一个人则一直在夸 AI 功能多强、多好用，扯了一堆别的。

我现在基本实锤就是他。
