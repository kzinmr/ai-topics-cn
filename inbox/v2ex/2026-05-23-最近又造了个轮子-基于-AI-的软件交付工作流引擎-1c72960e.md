# 最近又造了个轮子，基于 AI 的软件交付工作流引擎

这是一个 AI 原生的软件交付工作流引擎，能把 PRD （产品需求文档）直接变成真正可上线的代码和 Pull Request 。
它不是简单的一次性让 AI 聊聊天生成代码，而是把整个开发流程做成结构化、可暂停恢复、可审计的工作流：需求解析、任务拆分、AI 实现、TDD 测试、代码 Review ，最后自动创建 PR 。
