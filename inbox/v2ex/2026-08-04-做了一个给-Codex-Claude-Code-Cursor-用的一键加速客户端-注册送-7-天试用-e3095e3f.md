# 做了一个给 Codex / Claude Code / Cursor 用的一键加速客户端，注册送 7 天试用

大家好，我是 Speed AI 的开发者。
先说明：这是产品推广帖，按社区规则发在「推广」节点。
为什么做 Speed AI
我们在使用 Codex 、Claude Code 、Cursor 等 AI 编程工具时，反复遇到过这些问题：

浏览器里能正常打开 AI 网站，但终端里的 CLI 一直超时或显示 offline
OAuth 登录跳转后卡住，或者换网络后又要重新验证
Agent 跑长任务时连接中断，前面的等待和上下文都浪费了
GitHub 、npm 、PyPI 、Docker 、Hugging Face 等开发链路需要分别折腾代理配置
普通网络工具能解决“访问”，但不太关心 AI 交互、登录和大文件下载是不是混在同一个出口

所以我们做了 Speed AI：一个面向国内 AI 用户和开发者的 macOS / Windows 桌面客户端，希望把这些配置收成一个简单的一键开关。
目前能做什么

支持 macOS 和 Windows
一键开启 AI 与开发工具网络优化，不相关的国内流量保持原网络
针对 Codex 、Claude Code 、Cursor 、ChatGPT 、Claude 、Gemini 等交互请求优化连接
将 AI 交互与 npm 、PyPI 、Docker 、Hugging Face 、GitHub Release 等下载流量分开处理
覆盖 Google 、GitHub 、Microsoft 等常见登录验证链路
提供基础连接诊断，帮助判断问题出在网络、DNS 、TLS 、HTTP 还是服务端
