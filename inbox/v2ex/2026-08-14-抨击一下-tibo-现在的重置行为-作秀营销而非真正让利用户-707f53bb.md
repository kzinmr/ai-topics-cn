# 抨击一下 tibo 现在的重置行为：作秀营销而非真正让利用户

回顾一下 tibo 最近的几次重置，上上上次重置，没记错的话，正好是更早一次重置的一周后，也就是说本来就自然重置了，马上又再重置一次，大多数用户都还没消耗什么 token 就迎来了重置。
上上次重置则是在 8.12 附近，而最后一张重置卡是 8.13 凌晨到期，上上次重置实际上变相削弱了最后一张重置卡的价值。
最新一次重置则是今天上午十点多的时候，距离上次重置卡到期不超过十二个小时。
可以看到，tibo 的最近几次手动重置时间，都和自然重置时间非常接近，尤其是在没有预告重置的情况下，对普通用户而言并没有太大价值。
轻度用户这里就不考虑了，我们这里把中度用户分成三类（一个重度用户简单等同于多个中度用户）：

每天平均用 14% 左右，均匀地用完周 token ；对这一类用户，tibo 的最近的重置行为没有任何好处，当然也没什么坏处；
一重置就把 token 用完，对这类用户而言，tibo 的重置让他们大赚特赚；
前面三四天少用一点，等重置时间快到了，再重度使用，tibo 最近几次的重置行为其实是让他们吃亏的，总 token 用量反而比以前低了。

v2ex 其实有用户也发帖说对于 tibo 最近几次重置行为感到不舒服，结果还被人喷“升米恩，斗米仇”，这可不只是给得少了，而是切切实实损害了第三类用户的利益。
此外，这种重置行为还有一个问题，就是会打乱自己的工作节奏，比如说假如我原先正好是每周一重置，这两周的工作，我得在本周四周五和下周一周二周三完成，按原先的计划，可能是周四周五用掉 80% 左右的 token ；下周一重置了，周一周二周三再用 80% 的 token ，剩下的 token 量留着机动，tibo 在周四早上突然重置了，那完蛋了，我本来预期在两个重置周期里面完成的任务，要变成在一个重置周期里面完成了，token 就不够用了。
