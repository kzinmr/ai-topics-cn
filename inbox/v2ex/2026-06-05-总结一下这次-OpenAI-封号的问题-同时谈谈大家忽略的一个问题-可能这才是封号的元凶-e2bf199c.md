# 总结一下这次 OpenAI 封号的问题，同时谈谈大家忽略的一个问题（可能这才是封号的元凶）

总结一下这次封号大家探讨的问题：

礼品卡（可能性不大）：要封也是 Apple 先封；
IP （可能性中）：万人骑的 IP 也有不封号的；
机房/家寬（可能性小）：因为有很多大公司公司内部网络的外网访问都是要过自己的 VPS 的，我之前在一家跨国药企做销售，填报表的时候都必须连公司在美国总部的 VPN 才能接上系统（ 2002 年）；
土区（可能性小）：你有没有在 Apple 的网页上把账号地址调到土区？


在我看来真正的原因是：DNS 泄漏，你不要以为自己能翻墙了就没问题。

你们用的什么代理软件来翻墙的，有没有配置好防 DNS 泄漏？我用的软路 Clash.yaml 配置文件修改了很多次，也才能防到 95% 左右。
DoNotTrack 也没有开
系统时间
系统语言


怎么办？

自己先检查一下翻墙环境，下面几个网址测测，看能看到多少🇨🇳

https://ipleak.net/
https://whoer.net/zh#
https://browserleaks.com/dns

如果五星红旗太多，自己想办法调整环境吧，

欢迎大家一起讨论解决办法，不要再这样提心吊胆了
