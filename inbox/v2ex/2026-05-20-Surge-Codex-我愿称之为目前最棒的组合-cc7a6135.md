# Surge + Codex 我愿称之为目前最棒的组合

叠甲：我知道内网穿透/组网有非常多免费的方案，但是日常工况确实喜欢配置最方便的方案。Surge 的价格不作评价，我个人认为它值这个价格。

Codex 近期推出了能在移动端 ChatGPT 上进行对话的功能，不过此功能需要两台设备在局域网下，或通过 SSH 连接。
试了一下 Surge Ponte 可以直接连接，并且对话都直接显示（不过无法实现局域网下跟 Codex App 同步对话的效果，需要重启 Codex App 后才会显示最新对话）
Mac 上只需要安装 Codex cli 和打开远程登录即可。
顺带一提，这个 Surge Ponte 拿来访问 Mac 上的 Emby 服务器也是非常好用！
