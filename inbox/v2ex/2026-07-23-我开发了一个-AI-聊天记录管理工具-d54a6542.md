# 我开发了一个 AI 聊天记录管理工具

https://swob.app/
https://github.com/IvyYang1999/swob

支持 claude 、codex 、cursor 等多种 Agent
查看聊天记录并 resume 会话
全局快捷键，快速搜索切换会话
多维度 token 统计与洞察
支持划线笔记
支持可视化呈现 AI 使用规律
支持全局 Agent ，可以问：我昨天用 AI 做了啥？这种问题。
支持多种主题配色
支持跨设备 ssh resume 会话
提供 CLI ，可以让 AI 帮你全局检索会话
会话自动创建实时更新的 md transcript ，可导出
支持全局搜索
