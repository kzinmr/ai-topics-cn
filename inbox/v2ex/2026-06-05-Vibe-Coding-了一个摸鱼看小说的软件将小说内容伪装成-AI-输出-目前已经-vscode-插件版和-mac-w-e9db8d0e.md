# Vibe Coding 了一个摸鱼看小说的软件将小说内容伪装成 AI 输出， 目前已经 vscode 插件版和 mac win 客户端

上两天突然奇想大家每天都在 vibe coding 中途等待 AI 输出的时候玩手机， 在工位偶尔玩玩还行， 但是天天玩影响也不好， 所有做了这这个产品， 目前客户端是模仿豆包的主题，vscode 是 cc 风格的
https://github.com/wuuhw/fish-reader-vscode
https://github.com/wuuhw/fish-reader-client
后续计划支持网页识别， 客户端因为是 rust 的直接 webview 爬取输出的网址 ，vscode 的话计算装一个 puppeteer 吧， 目前笔趣阁类型的网站用  Readability-lite 方式已经跑通了， 还要在做一个用户行为录制来解决一些 通用规则搞不定的网站。
