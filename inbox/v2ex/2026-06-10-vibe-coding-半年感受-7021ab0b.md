# vibe coding 半年感受

从去年年底到现在，付费产品和各家的 API 多多少少也都用过了。
目前在用的产品有：Codex 、Claude + Token Plan 。Token Plan 有小米和阿里云的 Token
Plan 。
从一开始的只会问答，到后面的 Rules 、Agent 、Skills ，再到后面的 Plan
Mode 、Spec ，各种概念层出不穷。
到现在，最常用的模式是：每次先对话梳理需求，梳理完后让 AI 总结一下需求和修改点（类似于 Plan ，但不用一下子直接去看几百字的 mk 文档），然后没问题就开始执行。
个人感受：

提效：一个功能或者需求从设想到 95% 的完成度差不多只需要 1 小时。
2.累：在这一个小时内需要完成之前半天或者两到三天的需求设计，脑子有点转不过来。
厌倦：以前的时候 Coding 会有成就感，会有种拼尽全力总算把一个问题给解决的爽快感，现在没有了。
焦虑，大家好像都在用 ai 赚钱，解决自己日常中的痛点，而我像是守着金锄头却不知如何挖金子
