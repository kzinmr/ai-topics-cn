# 做了一个把电商/门店需求转成 Image2 广告图 Prompt 的小工具，想听听大家意见

最近做了个小项目，叫 Image2 Ads Studio 。
GitHub：
https://github.com/kwistzzqq-byte/image2-ads-studio
它不是一个 Prompt 合集，也不是完整的 AI 画图网站。
是用 OpenAI 把用户很口语化的商业需求，整理成适合 Image2 生广告图的 Prompt 。
起因是我最近在试 AI 广告图、电商主图、门店宣传图的时候，发现一个问题：
很多客户其实不会写 Prompt 。
他们会说：
“帮我做一张奶茶海报。”
“产品图做得高级一点。”
“我要一张电商主图。”
“参考这个风格，但不要太像。”
“门店活动要发朋友圈。”
这些需求听起来简单，但真要生成一张比较稳定高级的广告图，需要补很多东西：行业、尺寸、构图、产品位置、光线、材质、背景、文字区域、参考图使用方式等等。
所以我做了这个工具。
现在的流程大概是：
输入一句商业需求 → 解析用途和行业 → 匹配广告模板 → 用 OpenAI 改写 Prompt → 输出给 Image2 测试。
目前主要覆盖这些方向：
电商主图；
产品广告图；
品牌海报；
门店宣传图；
门头店招；
易拉宝；
活动背景板；
形象墙；
本地商家促销图；
商业摄影风格图。
当前版本还没接真实生图 API ，主要是先把 Prompt 生成这段流程跑通。
也就是说，现在是生成 Prompt ，再手动复制到 Image2 或其他生图工具里测试。
我自己觉得这个方向可能比单纯收纳 image2 Prompt 的仓库更实用一点。
现在项目还比较早期，很多地方肯定不完善。
发到 V2EX 主要是想问问大家：
这种 OpenAI + Image2 的广告图 Prompt Agent 有没有意义？
如果你做电商、设计、代运营、本地门店宣传，会不会用到类似东西？
