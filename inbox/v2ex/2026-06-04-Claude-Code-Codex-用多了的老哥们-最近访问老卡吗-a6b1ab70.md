# Claude Code + Codex 用多了的老哥们，最近访问老卡吗？

哎，最近老刷到 V2EX 有人聊 Claude Code 和 Codex ，我自己也是天天重度用，一天扔好几十个任务，写代码改 bug 做架构，效率是真的高。
不过用多了就烦了，高峰期卡得要死，有时候直接抽风，号还老是被搞，换号麻烦得要命。想同时用 Claude 、Codex 、Grok 的时候切来切去头都大了。
论坛里有人自己养号，有人用中转，大家说法都不一样。
想问问同样重度用的老哥：
你们现在都是怎么搞定访问稳定的？自己折腾还是有啥靠谱的办法？用下来咋样啊？
我最近在用朋友介绍的一个方式，两周下来还算稳。有同样烦这个的老哥欢迎聊聊，我把我的感受也随便说说。
