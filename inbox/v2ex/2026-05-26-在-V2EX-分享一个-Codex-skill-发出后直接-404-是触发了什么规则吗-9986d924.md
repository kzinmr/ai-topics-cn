# 在 V2EX 分享一个 Codex skill，发出后直接 404，是触发了什么规则吗？

刚才想在 V2EX 分享一个自己写的小工具，结果发完之后跳转到主题页，但页面显示：
404 Topic Not Found
Redirecting in 3 seconds...
比较困惑，所以想问一下大家有没有遇到过类似情况。
背景是这样的：
我写了一个面向 Codex / agent 使用的 skill ，功能很小：当 agent 生成脚本、JSON 、Markdown 、issue 正文、release note 这类需要精确粘贴的内容时，不再让用户从 TUI 里手动选中文本复制，而是直接把干净内容放进系统剪贴板。
做这个的原因是，TUI 里复制多行代码时，经常会把左侧 gutter 、空格、边框或缩进一起带走，粘贴到别处之后还要手动清理。这个 skill 主要就是解决这个很小但很烦的问题。
我原本想发一个分享帖，包含：

项目用途说明
GitHub repo
一张演示 GIF
安装方式
一些边界条件，比如不自动复制疑似 secrets

但提交后主题页直接 404 。不是“审核中”的提示，也不是普通跳转失败，看起来像是发出来后立刻不可访问。
我不确定是哪一类规则触发了：

新项目分享里带 GitHub 链接，会不会被自动判定为推广？
标题或正文里出现 AI / Codex / skill 这类词，会不会比较容易触发风控？
帖子里带 GIF 或外链过多，会不会导致自动隐藏？
V2EX 有没有某些节点不适合发这类工具分享？
新帖如果被系统拦截，正常是 404 还是会有其他提示？

这次先不贴 repo 链接，避免这个帖子也因为同样原因被拦。
想请教一下，如果只是分享一个开源小工具，比较合适的发帖方式是什么？应该发到哪个节点？标题和正文需要避免哪些写法？
如果有站内规则或经验帖，也麻烦指个路。谢谢。
