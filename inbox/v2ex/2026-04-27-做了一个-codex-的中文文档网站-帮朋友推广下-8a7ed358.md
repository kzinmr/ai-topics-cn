# 做了一个 codex 的中文文档网站（帮朋友推广下）

先贴网址
https://www.codex-docs.com/ 
why

因为 codex 的官方网站不能切到中文，看英文很累
因为 claude 对国内相对不友好，所以 codex 大概率会成为国外模型的首选

优势

更新及时: 基本会和官网同步，相差时间不超过 1 天，写了专门的 skill 同步内容
翻译准确: 第一版进行了仔细地勘查核对，尽量保证了语句通顺，翻译准确，样式还原，如果有问题，可以直接留言开喷
最新更新: 新增了一条最新更新的内容，可以快速看到本次更新，需要看全部更新再去阅读 change log 即可

最后
因为都是为了自用和方便国内的用户查阅，有问题可以直接开喷，遇到翻译不通顺的地方，也可以提意见，都会虚心接受。

Codex CLI | 安装、终端工作流与 Cloud 任务
