# 设置打印机没有双面打印，原来是这个配置没有开启

引言
今天想打印点东西，结果说打印机离线了，然后就重新添加。
重新添加完之后发现不能双面打印，去系统设置里面找到选项，但是并没有说双面打印字样，有个有点疑惑的选项我没选，因为不知道是干啥的：Duplexer, Dup 有双的意思我知道，然后 Duplexer 我可能理解为双工了，或者多路复用，就是多个人可以同时打印，就是没想到这个就是双面打印的意思。
然后这个也是奇怪，为啥双面打印要放在打印机的设置里面，而不是放在应用程序层面，在打印的时候选择。
以下是 AI 说的:

Mac:
打印时在打印对话框里展开详细选项,勾「双面 / Two-Sided 」。
如果根本没有双面选项:「系统设置」→「打印机与扫描仪」→ 选这台 →「选项与耗材 / Options 」→ 看「双面打印器 / Duplexer 」有没有勾上,没勾就勾上,选项才会出现。

为啥 Duplexer 是双面打印的意思，来源是啥？
Duplex 是核心词根,来自拉丁语 duplex = "double / 双重"(duo 双 + plex 折叠/层)。所以 duplex 本身的意思就是"双重的、双向的"。
加后缀 -er,变成 Duplexer = "实现双重(功能)的那个装置/部件"。在打印机语境里,它特指那个能把纸自动翻面、让两面都打印的硬件单元——所以中文翻译成"双面打印单元 / 双面器"。
Multiplexing = 多路复用
Duplex = 双工
