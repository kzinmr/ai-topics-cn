# 做了一个自动更新的隔夜美股消息站🌙 geyemeigu.com

零 npm 依赖的 Node 脚本 + GitHub Actions + Cloudflare 。
流程是：定时拉行情和新闻 → LLM 生成中文导读/短评/编译 → 渲染成纯静态页 → 写进 Cloudflare KV ，Worker 从 KV 直接服务全站。
月成本 0 元（只有域名 10 刀/年）。
全静态 + CF 免费额度，LLM 用的是 grok 4.5 ,supergrok 带的额度，不单独算成本了。
全程都是 claude 完成的，包括注册域名（给了它我的 cf 全权限 api ）
