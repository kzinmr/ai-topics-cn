# 手工维护四套终端配色，我对了一遍发现 Warp 错了 8 个色槽

项目： https://github.com/huiyonghkw/hekouwang-terminal-kit （ MIT ）
产品主页： https://huiyonghkw.github.io/hekouwang-terminal-kit/index.html?lang=zh
我以前是手工维护终端配色的。iTerm2 一套、Warp 一套、bat 一套、delta 一套，换个主题就挨个改。
前段时间打开自己那个 Warp 主题，注释写着「与 iTerm2 完全一致」。不知道哪根筋不对，写了个脚本把两边 16 个 ANSI 色槽逐个比，8 个对不上。哪次改漏的不知道，错了多久也不知道，我用了大半年没看出来。
同一份颜色抄四遍，迟早会漂。这不是我不够仔细，是这事本来就容易漏。
后来我把这东西开源了，叫 OneLook （仓库名还是 hekouwang-terminal-kit ）。思路很简单：颜色只写一处，能生成的就别手写。但分档得说清楚，别像我第一版投稿那样写糊了：
开源版（ MIT ）把 iTerm2 配齐：3 套社区配色、毛玻璃、Triggers 、Shift+Enter、现代 CLI （ eza/bat/fzf 等）、doctor.sh 体检、一键卸载。脚本都在公开仓，不是试用版。
付费档（¥19.9 ）才让这份色板走出 iTerm2：Ghostty 、Warp 、macOS 自带终端，加上 bat/fzf/eza/delta/tmux/VS Code 同色生成。我量过手工 Warp 主题漂成那样，才决定用生成器推颜色，不是再抄一遍。
