# [开源] 开发了一个支持 Claude、Codex 的通知工具，挺实用

仓库地址
issues 、star ⭐
https://github.com/hellolib/agent-notify
是什么
一个面向 AI Agent 的通知配置工具； 支持将 Claude Code、Codex  Cli 事件通知推送到飞书和系统通知。
功能特性

系统通知 - 支持 macOS 、Linux 、Windows 系统通知；
飞书通知 - 支持飞书机器人消息推送、也支持一键扫码绑定飞书；
事件订阅 - Claude Code 和 Codex 的事件通知；

工作流程

快速开始
npx agent-notify

首次运行会从 GitHub Releases 下载当前 npm 包版本对应平台的二进制文件。
