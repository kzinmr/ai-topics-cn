# 个人文件传输助手「虾传」正式开源，欢迎 star

大家好，我是闪电藤的开发者，也是虾传的开发者，闪电藤在 7 月 10 号将会正式下线（虾传够稳定的话），虾传是我用 cursor 从零 vibe 开发的个人文件传输助手，以解决以下问题：

复杂网络无法传输问题：比如单向网络，A 可以给 B 传输，B 不能给 A 传输，我们的解决方案是，通过云端信令协调，让 A 从 B 请求下载；单向网络常见的场景有：windows 防火墙阻塞，WiFi 路由一个连猫一个连路由器
不方便安装客户端的场景：我们提供了网页端，客户端可以直接给网页端发文件，走 HTTP 局域网，当然网页也可以给网页传输，也是走的局域网，但只能走 webrtc
大文件断点续传：大文件传到一半突然中断，我们可以在断开的地方重新传输（注意如果某一端是 web 端的话就不支持断点续传了）
局域网完全不通的情况，我们通过 s3,webdav 等手段进行跨网传输

本产品定位是一个个人的文件传输助手，所以是围绕个人的设备之间开展的，如果是想传输给其他用户，我们离线的设备也会被识别成外部的设备，我们不登录其实就是一个 localsend 的产品
说一下开发这个项目的缘由，主要有 2 个，闪电藤存在历史原因，是基于 localsend 开发的，被不少人诟病，虽然 localsend 的开源协议允许二开重新打包上线，但口碑两极分化，另外一个就是闪电藤的代码包袱比较重，要想实现上述几个问题，非常困难，因此我们重写了一遍，并且开发了 web 版本，我们成功的实现了在公网的网页上进行局域网传输
开源地址：https://github.com/shrimpsend/shrimpsend
欢迎各位大佬不吝赐教，也欢迎各位大大 star ，更欢迎 commit （昨日刚有一位 commit ，让 iOS 版本实现了原生玻璃导航栏，非常欣喜，还是人间处处是高手啊）
