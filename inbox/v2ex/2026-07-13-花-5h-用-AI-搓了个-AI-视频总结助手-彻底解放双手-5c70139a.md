# 花 5h 用 AI 搓了个 AI 视频总结助手，彻底解放双手

作为一个平时经常在 YouTube 和 B 站刷财经、AI 、科技视频的运营，天天追更新实在太累了。经常是看多了容易忘，或者漏掉重要信息。
于是我冒出一个想法：能不能做一个 AI 视频总结助手，把看过的视频核心内容一键总结，直接自动发到我的邮箱里？这样不仅省时间，以后想复习，直接去收件箱搜索关键字就能把知识找回来，妥妥的永久个人知识库！
🛠️ 独立开发过程（我竟然一行代码都没写！）：
抱着试试看的心态，我开启了这次 5 小时的 AI 逆袭之旅：
需求对接：跟 Gemini 沟通想法，让它帮我输出完整的产品方案和 Prompt 。
代码生成 ：把 Prompt 喂给 Cursor ，直接生成前端插件代码。
后端服务：后端用 Cloudflare Worker 进行服务和加密。
AI 总结：用智谱 AI 负责视频字幕的提取、总结和翻译。
邮件投递（踩坑点🚨）：刚开始用 EMAILJS + 谷歌邮箱转发，测了几次发现被谷歌屏蔽了……连夜改用 Resend 进行邮件投递，终于丝滑通畅！
商业闭环：最后加上 PayPal 打赏链接。
上架审核：Gemini 提供审核文案+插件图标。
全程大概花了 5 小时，我一行代码都没写，AI 真的太强大了！ 2 个工作日后谷歌审核通过
🎯 最终惊艳的效果
懒人必备：打开 YouTube 或 B 站视频，点开插件，填上邮箱，点击“总结视频”按钮。不需要手动复制粘贴，不一会儿排版精美的笔记就静静躺在你的邮箱里了。
智能中英双语：不管你看的是中文、英文还是日语视频，插件会根据你的系统语言自动翻译。中文用户收到的就是纯中文邮件，英文用户收到的是纯英文邮件！
💰 真实花费账单
成本低到可以忽略不计：
Cursor 会员：20 刀
谷歌开发者认证：5 刀
Gemini 、Cloudflare 、智谱 API 、Resend：全部白嫖免费额度！
