# 分享一下最近 Vibe 的一个 Markdown 文档以及 AI Agent 会话快速分享网站

最近在用 codex 做一些分析，想要分享完整的会话内容有点麻烦，然后就基于赛博菩萨 cloudflare 做了一个方便做分享的站点。
不用登陆，支持直接发布。然后也支持设置文档的有效期，到期自动清理。目前也做了简单的 agent 接入方案： https://notelet.youcaidi.link/agents ，可以直接分享会话内容, 以完整对话内容的方式来分享，比自己手动复制方便很多。
整体网站的一些设计是参考的 telegra.ph 的设计风格，做的是极简风格。
有兴趣的也可以自己部署，全部资源都是依赖 cloudflare 来提供的。
站点地址是： https://notelet.youcaidi.link/
github 地址： https://github.com/lixwen/duanjian
