# 使用 deepseek，外接视觉模型有什么好的便宜的方案推荐

deepseek 不是多模态，在实际的使用中写 UI 确实差点意思，感觉好麻烦，特别是调 UI 的时候，感觉不好沟通。
目前实践制作 UI 的流程是让 deepseek 绘制 ascii UI 布局，确定布局之后，就整理提示词使用 gemini 的 
stitch 制作原型图，原型图确定了再回到 deepseek 里面制作界面。
实际的过程中就会遇到一些小问题，比如网站 一下 UI 细节或者按钮的大小不一致，deepseek 无法看到，文字
描述的话，deepseek 没有办法一次性搞定。
所以想求一个比较好的使用方案能解决 deepseek 做 UI 视觉上面碰到的问题。
