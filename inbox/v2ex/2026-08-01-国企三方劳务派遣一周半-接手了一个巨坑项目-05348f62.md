# 国企三方劳务派遣一周半，接手了一个巨坑项目

前文提要： https://www.v2ex.com/t/1230521?p=1#reply18
月底开部门会议，技责让我去支援 2 个同事接手的一个项目。
让 ai 读取了下项目的技术架构和数据状态转移。
是 2010 年的技术风格，本来是运行在 pc 上的 cs 架构程序，jsp->iframe 加载前端页面，然后部分页面再套一层 iframe 叠加主要的内容。
现在要把这套程序部署到服务器，来支持大量公网用户在线访问。让我想办法来做页面部分的移动端适配。排期 4 周，本月月底就要上线。
这要是 ai 时代之前让我支援，我都可以直接跑路了。
接手之后想了两套方案，一个是直接复制原有页面和 css 和 js ，另起一套，放到新文件夹下。这种就是比较糊弄，而且如果要持续迭代，那就不太合适。适合临时应付下。
另外一套方案是用 vue 或者 react 新建一套项目来开发，但是后续我本地把他们 java 项目启动后，发现页面的主要数据不是那种 get 请求的方式，而是用 iframe 来再次加载的。这就是双层 iframe 。不过我可以 v-html ，但是确实没这么搞过。
目前是开着 5.6sol 极高，来按第一套方案先做了，看看效果怎么样，主要还有一些音频播放，录音等功能要 h5 也要支持。后边测试工作也不少。
这俩同事都不会写前端，周一打算跟他们对齐一下，看他们在我来之前打算怎么搞。然后尽快把第一套方案搞的完成度再高一点，然后找技责再拍板一下。
要不是行情太差，真的想跑路了。
