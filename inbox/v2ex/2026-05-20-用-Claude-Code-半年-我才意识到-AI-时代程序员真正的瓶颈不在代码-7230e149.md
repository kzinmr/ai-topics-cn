# 用 Claude Code 半年，我才意识到 AI 时代程序员真正的瓶颈不在代码

28 岁，上海，普通公司程序员。半年前学 Claude Code ，本来是想"提效"。
提效是成功了——工作压到了一天 4 小时左右，剩下的时间跑副业（一个个人网站，月入 ¥1000 ，挺寒酸但是真的）。
可就在这种"提效成功"的副作用里，我反而开始意识到一件让我有点不舒服的事：
写代码从来不是真瓶颈。
AI 把这一段彻底消灭之后，我看清了三个真正卡我的地方。想跟同路人聊一下，也求 V 友拍砖。

1. 选品瓶颈：能做的越多，越不知道做什么
以前是"想做的东西做不出来"，所以努力学技术。
现在是"任何东西理论上都能做出来"，但每个想法刚冒出来，下一秒就被自己否决：

这东西已经有人做过了
没人会付钱
做小了没意思，做大了我搞不定分销

那个 ¥1000/月 的小站，从立项到上线只花了一个周末。但"该不该做"我犹豫了一个月。
后来观察了几个赚到第一桶金的独立开发者，他们没有比我聪明，只是愿意做那些"听起来很傻"的产品。我目前还跨不过这一关——总想找一个"听起来不傻"的方向，结果一年下来啥也没动。

2. 分销瓶颈：做出来，没人知道
之前在 V2EX 看到一个 38 岁的老哥发帖说："独立开发技术不是问题，产品/SEO/营销才是新领域。"
半年前我觉得这是矫情。现在我同意。
那个小站的 ¥1000/月，70% 来自一个早期就关注我的小社群。我自己复盘：这一年除了那个社群外，我几乎没获得任何新用户。
SEO 我学了，但每次发文都觉得"这不就是写 SEO 优化文章吗，跟我做产品的初心冲突"，然后就停了。
写视频/小红书我也试过，剪到凌晨 2 点，发出去 200 个播放。
→ 真痛点不是不会做产品。是让人知道你做了产品这件事，比做产品本身难 10 倍。
