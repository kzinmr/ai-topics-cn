# 开源 音频串流 app，从局域网电脑收发音频；通过 AirPlay 连接你的音响。 macOS / Windows

https://github.com/Tularity/AudioHub
1. 每台电脑都可以像使用自己的设备一样使用另一台电脑的默认麦克风和默认扬声器。
场景一：在同一张桌子上放了两台电脑。一台电脑上连接着性能良好的麦克风，另一台电脑上连接着扬声器，而会议则在第三台电脑上进行。过去的普遍做法是转移线缆到第三台电脑，如果只是临时使用，然而这么做显得十分笨重。
场景二：同时持有 MacBook 和 Windows 台式。台式连接着专业音响，你的工作重心在 MacBook 。过去，如果你希望播放高质量音乐，通常需要专门到台式进行播放。
AudioHub 能够很好的保证尽可能低的延迟和音质（取决设备性能和网络性能），达成远程调用音频设备。
图 1 和图 3 展现为 B 模式（虚拟设备）。

2. AirPlay ，让你的电脑能够接收来自 macOS / iOS 的音频。
作为共享端，你可以在共享协议页面启用 AirPlay ，内网其它 Apple 终端将出现你的电脑。并且终端可以直接控制你电脑的系统音量，而不需要额外调整。

3. 局限性
由于定位为免费开源 app ，编译产物没有签名。如果需要让对端作为系统音频设备，需要安装驱动，而在 Windows 下需要启用系统“测试模式”才能成功安装和启用；
macOS 平台产物同样不具备签名，但可直接自签（ app 内自动完成）安装驱动。
