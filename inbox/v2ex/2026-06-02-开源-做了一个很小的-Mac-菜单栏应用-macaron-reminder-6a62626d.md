# [开源]做了一个很小的 Mac 菜单栏应用， macaron-reminder

做了一个很小的 Mac 菜单栏应用，macaron-reminder
它是一个马卡龙风格的本地提醒工具，支持每日提醒、间隔提醒和纪念日提醒。到时间后，会从屏幕右侧滑出一个温和的小弹窗，提醒我该休息、该做事，或者别忘了某个重要日子。
这个项目目前不会商业化，也不会做得很重。没有账号，没有云同步，没有复杂后台，配置就是一个本地 JSON 文件，简单、直接、够用。
做它的原因也很朴素：我自己平时写代码、做项目，经常会忘记站起来活动，也会漏掉一些固定的小任务，所以想做一个看着舒服、不打扰心流的小工具。
技术栈是 Tauri 2 + React + TypeScript 。
对我来说，它同时也是一个 Tauri 菜单栏应用的小脚手架。以后如果想做 AI 快捷助手、定时通知工具、剪贴板工具，都可以基于它继续改。
开源出来没有什么宏大的目的，只是觉得一个自己真的会用的小东西，分享出来也许刚好能帮到同样需要的人。
小工具不一定要很大，能解决自己的真实问题，就已经有价值了。
