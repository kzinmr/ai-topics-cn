# 各位 Vibe Coder,我可能解决了你在 VSCODE 和 CURSOR 中的一个小痛点

大家好！
自从用上了 Cursor 和各种 AI 编程助手，我发现自己每天花在“盯着屏幕看 AI 打字”上的时间越来越多了。遇到稍微复杂点的任务，AI 吭哧吭哧能跑好几分钟。一直盯着看很傻，出去干点啥又怕错过什么重要的事。
为了解决这个痛点，我开发了一个 VS Code / Cursor 插件：Boomerang Notifier (回旋镖🪃)。
它的功能非常简单粗暴： 当你把需求丢给 AI 开始干活后，插件就会在后台默默帮你“监工”。等 AI 停止输出（活干完了，或者报错卡住了），它会立刻通过你设置好的通道（微信、Bark 、钉钉等）把消息推送到你手机上。就像你扔出去的回旋镖,终究飞回来击中了你。
现在你可以： 丢完 Prompt 直接起身去倒杯水、抽个烟、蹲个坑、或者找同事吹个牛。等手机一震，再回来继续牛马。
插件已经开源并上架，搜索 Boomerang Notifier 即可安装。欢迎各位试用！  
GitHub: https://github.com/gezimonkey/Boomerang
