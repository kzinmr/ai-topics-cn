# 只订阅了 Kimi Coding Plan 的朋友，可以用这个小工具让 Hermes-Agent 也接入 Kimi

写了个本地代理 Kimi2Moon ，把 kimi CLI 包装成标准 OpenAI API： https://github.com/gbammc/Kimi2Moon
配置很简单：

Base URL: http://localhost:8000/v1
Model: kimi/k2.5
API Key: 随便填

./setup.sh 一键启动，自带 Web 面板查状态。
有同样情况的朋友可以试试。
