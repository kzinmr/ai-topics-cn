# 制作了一个 AltStore 软件源： AltGallery 欢迎大家来试试

sidestore 配合 livecontainer 可以在没有电脑的情况下安装各种 ipa 了。不过很多 App 只在 GitHub Release 里放 ipa ，没有对应的源，更新起来挺不方便的。

所以用 Claude 做了这个项目 https://github.com/bebound/AltGallery, 收集了一些常用的软件，生成软件源，定时更新版本。
点 Add AltSource 就能订阅到 SideStore/LiveContainer/AltStore 了

如果有还没收录的软件，欢迎告诉我，我来加进去～
