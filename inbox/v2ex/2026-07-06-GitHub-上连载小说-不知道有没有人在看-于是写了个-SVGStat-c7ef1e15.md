# GitHub 上连载小说，不知道有没有人在看，于是写了个 SVGStat

也算赶在 Fable 5 开始按量收费之前，狠狠薅了一把，撸到现在。
起因非常朴素，甚至有点寒酸：
我在 GitHub 上连载 《底层重构》，写的时候挺起劲，更新也一直没断，但有一个问题特别真实：
我是真不知道到底有没有人在看。
不是那种“后台有几万 UV 但我还在焦虑”的不知道，是真的不知道。
不知道有多少人看。
不知道是新读者还是回头客。
不知道大家是手机看还是电脑看。
不知道是路过瞅两眼，还是半夜两点拿我小说当电子榨菜。
最离谱的是，有时候你明明觉得自己写到高潮了。
内心预期应该是“读者狂喜，剧情发酵，评论区爆炸”，结果现实是静悄悄，安静得像我刚发完工资的钱包。
于是我开始想：
能不能搞一个特别轻的统计方案？
别整一堆埋点。
也别非得有个完整网站后台。
我只想在页面里放一个东西。
然后它告诉我：
到底有没有人看。
宵夜过后这个想法越想越歪，最后就长成了现在这个项目。

这项目是干嘛的？
一句话：
把统计能力做成一张图片。
对，就是图片。更准确一点说，是 SVG 。
你可以把一个统计地址直接塞进：

GitHub README
Markdown 文档
静态网站
文档站
落地页
甚至任何能放 <img> 的地方

然后它会显示一个动态计数器或者徽章，比如：

访问量
下载量
某个页面的阅读次数
你自己定义的指标

为什么不用现成统计工具？
喜欢折腾。
喜欢轻的东西。
喜欢干净简洁。
当然，还有一个原因：自己做，比较好玩。
这个项目目前做了什么？
现在这个项目已经能跑起来了，核心能力包括：
1. 实时 SVG 计数器
最核心的能力，就是把统计做成一张能直接嵌进页面里的 SVG 。
/svg/{projectSlug}/counter/visits.svg

图片被请求一次，就记一次，再直接返回一张图。
