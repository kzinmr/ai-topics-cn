# 做了一个超级好看的 Markdown 预览编辑小工具， MD 颜值档看过来，开源免费用，希望多提使用意见

原文： https://v2ex.com/t/1227567
做这个工具的初中是这样的，自从开始用 AI 编程，每个项目和功能都要写一堆 markdown 文档，好多都是让 AI 跑的执行任务文档，为了更加直观的查看 AI 做到哪一步，哪些是已经完成了，哪些没完成。而使用了市面上好多 markdown 查看工具，都有一个共同特点，都会把主要内容限定在浏览器中间区域，而我的每条任务计划文字一长就要换行，看起来不是太舒服，我希望整个 md 任务计划清单每条一行清清楚楚显示。加上大家的格式都千篇一律，文档看起来有点眼累。
于是就有了现在这个小工具，主要特色还是主题，内置了 3 个主题都是特殊定制的，最喜欢的还是雅致主题，在预览模式下做了特殊定制。然后需要其他主题的话，最新版已经新增了 AI 主题生成功能，想要什么直接让 AI 生成，实现主题自由！！！
这次主要更新还是增加了几种字体，标题、配色等也可以自定义，还增加了打开文件夹，多 md 文档和其他文本文档打开查看。
增加了文件实时刷新，其他工具，比如记事本或 vscode 、codex 等编辑过的文档内容会实时同步。如果当前文档也有编辑但未保存，会提示内容冲突，可以选择用哪一边的文档。
这次还增加了另外一种编辑模式，以前只有预览和分屏编辑，现在可以所见即所得编辑。
以下是最新版本更新日志，因为借助 AI 开发，所以每次更新都可以增加好几个功能和修复挺多 bug 。如果有喜欢的，请给 github 加个 star 。
使用过程种发现问题也可以提，或者需要什么新功能也可以提！
