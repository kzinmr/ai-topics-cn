# 新入职的公司，乱，干得我头大

技术部门七八成的人都是最近两个月来的，项目是之前别的团队分支出来的，业务线不同了，新招了一批人。
算上前后端客户端和测试，做技术的大概二十来号人，仓库拉了代码发现没有产品文档，没有开发文档，没有数据库字典。
除了项目负责人，开发没有生产服务器权限，没有生产数据库权限，线上出了 bug 看不了日志，只能看一点生产数据，自己去管理后台找两条数据把其他数据表的关联数据查询 sql 上报，人家导出了发回来自己导到测试环境调试。
今天下午给排了个报表统计接口的重构需求，我提出需要在原先数据处理逻辑加少量日志，以及开放生产数据库的只读权限，被否了，说只能自己看代码梳理逻辑。
上个月和另一位同事一起重构了一个功能，我吭吃吭吃把我负责的部分写完了，人家告诉我他把整个文件逻辑优化了，一 merge 一片 conflict 。哥们还给原先的逻辑加了很多额外规则，导致前一天通过的测试用例第二天全部无效，测试不停给我提缺陷，我不停再本地调试把新的逻辑同步给产品和测试，上线延期 2 天。
和我前后脚入职的一个后端一个前端都已离职，今天得知有个测试妹子也提离职了。
强制加班，好在就俩小时。
一刷 boss 全都是 ai agent ，全栈，纯后端岗位寥寥无几。
走也不是，留也不是。麻了。
