# obs 笔记软件如何快速收藏文章？

想要直接清洗后（ markdwon ）的原文保存。
图片，多媒体，接 s3 。
文章加入时间戳，ai 从全文中提炼高权重 tag （语义以及重复次数的因子）。
tag 单独生成 id ，tag 用于 graph link 。每个 tag page 里顺序记录文章的
obsidian-url ，标题和时间戳。所以一篇文章会被记录多次。
第一次接触 graph rag 的概念。想用 obs 简单先从 raw 整理开始做起。用 tag 关联，
后面还想加上 Knowledge Graph 类型的 tag 。但当前不需要。体量太小。加上循环锚点，复杂化影响可读性。
有什么实操思路不？从 notion 转 obs 也没多久，并不太熟悉。主要就是为了这个转 obs 的。
希望有类似的工作流能参考下。谢谢。
