# 做了一个 Code Review 的工具

https://sabun.hamsterbase.com

不是基于 Electron 或 Tauri 开发的桌面应用。核心使用 Swift 和 C 编写；由于集成了 VS Code 的 Monaco Editor ，界面层基于 HTML 构建。
软件运行在系统沙箱中，无需联网，也没有登录或注册功能。 免费版支持每个窗口打开一个项目，商店版支持多 Tab 切换
这是一个为我自己的开发的工具。顺便拿来卖钱。
平时我会同时开发 4 ～ 5 个项目，需要随时查看 AI 修改了哪些代码。我主要关注两类变更：

当前分支中尚未提交的文件和代码改动；
当前分支与 main 分支之间的完整差异，以便在合并前全面检查整个需求涉及的改
动。

Sabun 支持记录代码审阅进度。你可以直接勾选整个文件或文件夹，也可以细化到单个改动区块（ diff block ）。例如，一个文件包含 20 个改动区块，可以逐个检查并勾选。
即使 AI 后续继续修改代码，已经审阅过的区块记录仍会保留；如果被勾选的文件又发生了变化，Sabun 会自动取消该文件的勾选状态，提醒你重新检查，避免遗漏新的改动。
