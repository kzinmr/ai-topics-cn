# 八年之隔，这可能是地球上最漂亮丝滑的 Markdown 应用！

相隔八年时间我又回 V2EX 啦，这次不鸽了（可见我古早的帖子背景），不知道还有没有当时参与过的朋友，这次终于有成品了。😼
我正在构建一个本地优先的高性能 Markdown 编辑器，它叫 Moeka 。
核心特点是适合高密内容记录，让写 Markdown 像代码一样能掌控每个字符，我基于 Rust 与 GPUI ，耗时 6 个月，自研了一整套所见所得的编辑渲染引擎，完全不使用 Web 技术。
相比 Obsidian ，Typora ，Moeka 集成了简单但高频使用的功能，基于 GPU 的渲染流畅但低开销，也集成了流行的 AI Agent 。
我做 System 开发，也会一点点设计，所以会在细节和性能上做极致打磨，目前是第一个可公开版本，欢迎大家来试试。
