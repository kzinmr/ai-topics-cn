# 小米 MiMoCode 的简单反代方案

来源-网络技术分享 t.me/wzxylh

整体流程比较简单：

1️⃣ 调用 Bootstrap 接口获取临时 JWT Token

2️⃣ 携带 JWT 调用 OpenAI 兼容接口完成对话

目前支持通过 OpenAI 格式直接调用 MiMo 模型，对于测试和接入第三方客户端来说比较方便。

获取 JWT：
JWT=$(curl -s -X POST 'https://api.xiaomimimo.com/api/free-ai/bootstrap'
-H 'Content-Type: application/json'
-d '{"client":"haha"}' | python3 -c "import sys,json;print(json.load(sys.stdin)['jwt'])")

发起对话：
curl -X POST 'https://api.xiaomimimo.com/api/free-ai/openai/chat'
-H "Authorization: Bearer $JWT"
-H 'X-Mimo-Source: mimocode-cli-free'
-H 'Content-Type: application/json'
-d '{
"model": "mimo-auto",
"messages": [{"role":"user","content":"hello, who are you?"}],
"max_tokens": 128000,
"stream": true,
"temperature": 1.0
}'
