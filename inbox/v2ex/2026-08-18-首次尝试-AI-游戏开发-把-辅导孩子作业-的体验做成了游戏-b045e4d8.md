# 首次尝试 AI 游戏开发，把「辅导孩子作业」的体验做成了游戏

游戏名称《小镇做题家长版》
主要玩法截图





 
起因很简单：辅导娃写作业过程中，感觉体验非常微妙（要控制自己情绪的情况下，让娃在指定时间内做完作业），就想把这个过程做成游戏。
玩法

扮演家长，屏幕上三条数值：娃的注意力、你的血压、作业进度。游戏获得的星星可以用来技能加点，提升娃的能力。
娃会走神、撸猫、转笔、突然问你一道题。。。（基本每条都在实际生活中有遇到）
你有四个技能：深呼吸（降压）、水果（提注意力）、河东狮吼（提注意力但涨血压）、出门冷静（离场，但离场期间娃干什么管不着）。
血压到 100 当场失败。写完作业按用时和正确率给 1-3 星，星星拿去给娃升技能。
每个年级末尾有期末考试，考试你不能干预，只能在外面干着急。

技术栈

Cocos Creator 3.8.8 + TypeScript
存档：本地 + 微信云开发双写合并，云函数校准服务端时间防改本地时钟
题库：对照浙江教材单元目录，AI 批量生成后跑脚本全量校验——结构完整性、答案分布均衡、数学题算式解析验算、关卡难度窗口越界检查。没做逐题人工复核，发现错题欢迎直接甩我。
全程零服务器成本（云开发免费额度 + 开放数据域沙箱）

踩过的坑


UGC 内容安全。上线前才发现的，只是允许玩家起名字，直接被微信封杀（还在审核期间），因为没接名字内容合规审核。只要涉及到 UGC 相关的，一定要注意内容合规和安全。虽然微信有 api 提供内容审核，但测下来不是太稳定，所以上线前干脆把起名字功能给掐掉了。。。。


数值平衡：没敢拍脑袋，复用 core 层代码跑蒙特卡洛，
模拟苦手/普通/高手三种画像 × 不同加点策略，跑出来发现三星线定 95 分时
低年级达成率是 0%，改成 90 才合理。
