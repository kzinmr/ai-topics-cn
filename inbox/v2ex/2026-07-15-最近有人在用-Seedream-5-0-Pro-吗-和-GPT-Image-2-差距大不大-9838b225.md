# 最近有人在用 Seedream 5.0 Pro 吗？和 GPT Image 2 差距大不大？

最近在折腾 AI 生图，之前基本一直用 GPT Image 2 。
GPT Image 2 确实挺稳，尤其是图片里带文字、海报、信息图这类东西，生成出来的可用率比以前高不少。
但这两天老看到 Seedream 5.0 Pro ，搜了一圈，发现已经有不少人在拿它和 GPT Image 2 对比了。
我自己看了一些案例，感觉 Seedream 这个路线好像有点不一样。
GPT Image 2 给我的感觉是「理解你要什么，然后尽量准确做出来」。
Seedream 5.0 Pro 更偏「设计师出图」？
尤其是构图、氛围、商业视觉这块，有些图第一眼确实更抓人。
当然，也可能是网上发出来的本来就是筛过的好图 😂
所以我就想自己拿同一套 prompt 跑几组看看。
Google 找测试入口的时候翻了好几个站，最后用的这个： https://seedream5pro.art/
主要是页面看着比较干净，还有个 Prompt Generator ，可以先把比较随意的描述整理成结构化 prompt ，再拿去生图。对我这种经常脑子里知道大概想要什么，但懒得认真写 prompt 的人还挺省事。
实际跑了几张后，感觉和我之前的判断差不多。
GPT Image 2 在文字、信息图、严格执行指令这块还是挺稳。
Seedream 5.0 Pro 出来的图，构图和氛围感有时候确实更讨喜，尤其是偏商业视觉的图。
但样本也不多，不敢直接下结论。
所以想问问 V 站有没有两边都长期用过的？
如果是纯生图，你们会选 Seedream 5.0 Pro 还是 GPT Image 2 ？
有没有人拿同一套 prompt 大量跑过两边？实际差距大吗？
