# [图床开源] imgli · 图鲤，一跃成链

做了个开源图床 imgli （ AGPL-3.0-only ）：

特性功能：

Go 单二进制，前端内嵌，默认 SQLite ，可选 S3/WebDAV + CDN 302
机审（ NSFW/OCR ）、用户组配额与月流量硬顶、分享页 OG 、口令/阅后即焚
PicGo / ShareX / uPic / CLI 对接

定位：博客/笔记外链与小团队自托管，不是无限免费 CDN 。

公共站： https://img.li 欢迎试用
文档： https://docs.imgli.com
源码： https://github.com/yixian-huang/imgli

一键安装：
curl -fsSL https://raw.githubusercontent.com/yixian-huang/imgli/main/scripts/install.sh | sh
imgli serve
