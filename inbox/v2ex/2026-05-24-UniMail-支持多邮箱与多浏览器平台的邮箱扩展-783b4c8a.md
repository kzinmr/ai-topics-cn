# UniMail：支持多邮箱与多浏览器平台的邮箱扩展

UniMail 是一个浏览器邮箱扩展，可以让你在 Chrome 、Firefox 、Edge 中轻量处理 Gmail 和 Zoho 邮件。
它适合经常在浏览器里工作、但不想频繁切回邮箱网页的人。打开扩展后，可以查看统一收件箱、读邮件、回复、转发、写信，并支持侧边栏邮件列表展示。

支持：

邮箱平台：Gmail 、Zoho
浏览器平台：Chrome 、Firefox 、Edge
常用流程：收件箱、邮件详情、回复、转发、写信、附件
支持侧边栏邮件列表展示

安装：

官网： https://unimail-website.pages.dev
Chrome Web Store： https://chromewebstore.google.com/detail/unimail-%E2%80%94-unified-inbox/ndakahpnkhidhhlmlfchjdehpdegaabd
Firefox Add-ons： https://addons.mozilla.org/zh-CN/firefox/addon/unimail-unified-inbox/
Microsoft Edge Add-ons： https://microsoftedge.microsoft.com/addons/detail/unimail-%E2%80%94-unified-inbox/hmgipgiddjihijbbglbhnnlbhghflndo
