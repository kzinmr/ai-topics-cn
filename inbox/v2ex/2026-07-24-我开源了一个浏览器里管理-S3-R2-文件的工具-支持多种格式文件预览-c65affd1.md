# 我开源了一个浏览器里管理 S3、R2 文件的工具，支持多种格式文件预览

项目地址： https://storageui.dev/zh

Demo 地址： https://demo.storageui.dev

GitHub 链接： https://github.com/hahahumble/storageui
目前市面上的文件浏览器不少，比如 Filestash ，但用下来体验都比较一般，界面偏旧、预览能力弱、操作也不够顺手。于是我做了 Storage UI ，一款开源的自托管文件浏览器，支持 S3 、R2 、阿里云 OSS 、腾讯云 COS 、Backblaze B2 等主流对象存储，提供现代化的 Web 界面，让您轻松浏览、预览、搜索和管理文件。
配合 Cloudflare R2 的免费套餐，还能直接当成自己的私人网盘来用。
