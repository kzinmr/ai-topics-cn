# 把写作、排版、发布装进一个桌面 App

Vibe coding 的自媒体工作台，免费，数据存在本地

下载地址
https://github.com/rokiai/lazy-ant-app

- Markdown 写长文：封面、目录、结构化排版，边写边预览  
- 图文拆卡：一篇内容直接拆成多张图文卡片，还能预览和导出 PNG  
- 主题库：文章主题、图文主题都能套用，排版不用每次从零开始  
- Skill 模板：把自己的写作方法、提示词和流程沉淀下来，重复使用  
- 热点选题：聚合多个平台热榜，找灵感更快  
- MCP 接入：可以让 Cursor 、Codex 、Claude Desktop 直接读写文章、图文和主题
