# Forward Deployed Engineer？是什么东西

最近看到很多 Forward Deployed Engineer 的字眼出现，
找了 Gemimi 查了一下，如下描述 , 这不是妥妥的 OPC （驻场外包）吗？
这种不就是全栈能力，可以把需求和客户层需求通过 AI 实现，还要驻场的全能外包吗？

这个岗位需要什么样的技能栈？
如果你关注这个岗位的技术和职业发展，通常各大厂（如 Palantir, OpenAI, Runway ）在挑选 FDE 时，会看重以下特质：
- 硬核的全栈工程能力： 熟练掌握现代全栈技术栈（如 Python, Go, TypeScript/Next.js 等），对数据结构、高并发、微服务架构有极深的理解，能够编写生产级别的规范代码。

- 数据与系统集成能力： 面对客户极其混乱的 legacy 数据库（ SQL/NoSQL ）和复杂的网络拓扑，能快速梳理出稳定、安全的数据管道（ Data Pipeline ）。

- 现代 AI 工具链的掌控力： 懂得如何利用 AI 原生工具（如 Cursor 、Claude Code 等 AI 编程智能体）在现场实现“超速编码（ Vibe Coding ）”，并对大模型、Agent 编排（ LangChain/LlamaIndex ）有实际落地的经验。

- 极强的“Founder 精神”： 能够直接面对客户高管和业务人员，在没有完美技术文档、要求瞬息万变、甚至没有后方支援的情况下，靠极强的心理素质和变通能力把事情搞定。
