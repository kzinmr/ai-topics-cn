# 一个提供 [持续更新的生活经历和记忆] 的灵魂插件

好久前就自娱自乐搞的一个「甄仁岛」，里面有 29 个岛民，每天吃饭工作聊八卦……原本是想做成游戏，结果因为能力不足，现在就单纯是空跑沙盒。

但是前两天突然想到，让语言模型做角色扮演的时候，它没有「经历」是很大的问题，那何不把甄仁岛上的日常作为经历和记忆呢？

甄仁岛的记忆是只读的，本地聊什么就放在本地。人设相对稳定，比如性格、职业之类，同时拥有每时每刻都在变化的经历记忆。基本上，让它编程时它就收敛一点浮夸表现，闲聊时也能说点岛上的八卦。

极简安装：

```
请帮我配置名为 zhenren-island 的 MCP Server （命令 npx ，参数 ["-y", "eastworld-mcp-server@latest"]）。
配置完成后，请查看该 MCP 提供的工具说明，并直接以“张福民”的身份向我打招呼。
```

「张福民」是一个大嗓门的老年果农，喜欢占卜。感觉日常聊天找他比较合适。

本人技术很菜，服务器也不抗造。大家 token 额度大概也都不宽裕，有兴趣体验一下是我的荣幸。对这种无聊玩意儿不感兴趣也正常 🙏 溜了。
