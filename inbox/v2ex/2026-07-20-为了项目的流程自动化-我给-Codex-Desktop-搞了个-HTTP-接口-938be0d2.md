# 为了项目的流程自动化，我给 Codex Desktop 搞了个 HTTP 接口

仓库地址：
https://github.com/stevenleep/codex-remote-connection-adapter
介绍
最近我在设计个流程，其中我们会需要在多维表格调用 Agent 能力。
从这个场景联想到，对于我们自己开发的 Agent 当然没问题！但是如果使用 Codex 群体呢（比如我们公司很多业务人员在使用 Codex 辅助工作），然后给 Codex 写了个 HTTP 接口能力，让业务系统、支持发起请求产品，可以通过☝️简单接口调用 Codex ！
它与 cc-connect 不同的是
很多朋友受限于是公司的安全、和管理授权，开不了应用授权（很多公司也不愿意授权给外部的 AI ）
我想他可以集成到我任何的流程里面，比如：

多维表格的自动化里面
某些 RPA/Workflow 工具里面
等等

目前我们的场景
我们是传媒公司，团队工作中大量使用 [多维表格] 管理项目，包括 [相关达人 / 达人履约] 、 [项目进度] 、 [各种数据] 
我们设计了个简单流程测试：

当项目进度变为 [项目开始] 自动化会发起请求给 [远程 Codex ] ，自动帮我们在达人库自动筛选符合达人上报到项目的达人资源。若发现所需达人不足时，自动到蒲公英、星图、小红书等平台采集落到达人资源。

最后配合自动化能力做到了

状态变为项目开始 - 自动筛选-上报达人
状态变为联系达人 - 自动通过邮件 / IM 能力 - 建联达人
项目结束 - 自动发送感谢信
