# vibe 了一个安卓通知转发程序，求测试

因为手上有些不支持升级到最新澎湃 ui 的杂粮手机，又想转发短信和其他通知到 ios 或者其他手机，用 codex 写了这个程序。
功能：将手机上的通知按规则转发到 Telegram 、Bark 、Slack 或 Email 。支持按应用、关键词、系统通知、持续通知等条件过滤。可以失败重试、发送日志、状态看板和本地配置备份
可以从 GitHub Release 下载 APK 体验：
https://github.com/naughtyGitCat/br1dge/releases
如果方便，也欢迎反馈使用中遇到的问题或建议
GitHub 版本可以正常体验应用功能，但不计入 Google Play Closed Testing 的 14 天测试要求。需要大家帮忙加入内测并保持测试状态 14 天。
测试者需要做的事情：

提供你的 Google Play 账号邮箱。
我把邮箱加入 Closed Testing 测试名单。
收到测试链接后，用同一个 Google 账号打开链接并加入测试。
从 Google Play 安装 NotifyBridge 。
打开 App ，简单体验一下基础流程。
保持加入测试状态满 14 天。

如果你也有 Android App 需要 Closed Testing ，我也可以帮你互测。谢谢！
