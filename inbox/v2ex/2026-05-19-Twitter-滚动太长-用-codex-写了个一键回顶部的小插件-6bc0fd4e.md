# Twitter 滚动太长？用 codex 写了个一键回顶部的小插件

最近刷 Twitter/X 经常一不小心滑得太深，想回顶部要反向狂滑半天，于是用 codex 写了个超轻量的 Chrome 扩展，在页面右下角加一个浮动按钮，点一下平滑回到顶部。

特点：
- 仅在 twitter.com / x.com 生效
- 平滑滚动回顶部
- 按钮位置可在 popup 里自定义
- 样式贴近 Twitter/X 原生悬浮按钮风格
- 偏好仅存本地，不收集任何数据，不请求远程代码

技术栈：WXT + React + TypeScript

Chrome 商店： https://chromewebstore.google.com/detail/twitter-scroll-to-top-but/koplhbgfkniplejmgfaabolbepcbgnki
GitHub 源码： https://github.com/mundane799699/twitter_scroll_to_top_button

完全开源，欢迎 Star / 提 issue / PR 。
