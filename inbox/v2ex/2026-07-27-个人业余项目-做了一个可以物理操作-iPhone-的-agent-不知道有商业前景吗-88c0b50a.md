# 个人业余项目，做了一个可以物理操作 iPhone 的 agent，不知道有商业前景吗？

淘宝美团常用的 app ，都没有 API ，agent 没法直接调用。走 ADB 容易被风控，豆包手机那条路似乎也很坎坷不好走。
我想，如果能用硬件直接托管 iPhone ，用摄像头观察屏幕，用机械臂点击，或许能绕过大部分风控检测。搞了几个月，agent 跑通了，使用起来还可以。
目前，最大的问题不是可行性的问题，是 token 太贵，点击一次 token 花费 0.2 元。
大家觉得这种 agent 有商业前景吗？
