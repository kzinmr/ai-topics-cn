# 关于 codex 和 claude code 的取舍

首先是 codex
优点
1.相对 claude code 要便宜一些
2.电脑操作做的真不错,还不消耗额外 token
3.官方比较人性化,经常送重置卡
4.智能方面足够了,至少我的工作是够了
5.生成图方面蛮强大的
缺点
1.回答太慢了,尤其是 5.6 sol,生成一大堆,结果没出来,额度没了
2.前端能力还是不如 claude,经常有没对齐/间距奇怪的问题,虽然可以调,但是比较费时间
3.有些位置还是有些小瑕疵,虽然问题不大,不能像 claude 那样偶尔给人惊喜
claude
优点
1.速度相对来说快一点,代码生成相对来说精简一些
2.前端效果比较满意,审美大部分时候比较在线
3.fable5 确实强
4.细节方面做的不错,偶尔能解决没想到的问题
缺点
1.容易封号,虽然我还没遇到过,帖子很多人说
2.中文支持不太好
3.比 codex 要贵一些,并且理论上 gpt5.6 sol 是对标 fable5 的,但是 fable5 说不好什么就开始按量收费了
4.图片生成能力一般
