# Termite 2.0.0 更新：为并行 AI 开发做的 macOS 原生终端

Termite 是使用 SwiftUI + AppKit 开发的 macOS 原生终端，主要用来管理同时运行的多个 coding agent 。
2.0.0 的主要更新：

通过局域网或 Tailscale 在手机上操作终端和 iOS Simulator
在 iPhone 或者 iPad 上预览操作控制 iOS 模拟器


▶ 点击观看手机远程操作终端和 iOS Simulator 演示（ 2 分 24 秒）

官网： https://termite.xinghelee.com/
GitHub： https://github.com/xinghelee/Termite
Homebrew：brew install --cask xinghelee/tap/termite
支持 macOS 26.0+，GPL-3.0 开源。欢迎试用和反馈。
