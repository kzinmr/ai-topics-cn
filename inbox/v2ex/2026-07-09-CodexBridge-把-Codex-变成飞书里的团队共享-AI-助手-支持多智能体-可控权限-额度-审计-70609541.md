# CodexBridge，把 Codex 变成飞书里的团队共享 AI 助手：支持多智能体/可控权限/额度/审计

大家好，我最近在做一个开源项目：CodexBridge 。
Link： https://github.com/Moshiii/CodexBridge
正在招募早期测试者，欢迎大家点星星，参与测试！
它想解决的问题是让团队成员能在飞书群里直接拼车用用 Codex ，又不需要把自己的 codex 账号权限直接暴露出去。
目前能做到的事情：
用户体验对标飞书自研的 Alliy 飞书助手，可以创建多个智能体也可以管理每个用户对于每个智能体的对话次数和权限，可以手动调整积分。拉同事在同一个飞书组织中然后：
1.同事在飞书群里 @ bot 提需求，bot 会回应，可以管理群聊/私聊权限
2.admin 可以管理 bot 、用户对话积分额度、审计日志、runtime 状态和 workspace
3.每个 bot 有自己的持久化工作区和上下文
4.目前也支持 Telegram 和本地 TUI ，不过主打飞书
目前还比较早期 alpha 阶段，正在招募早期测试者，欢迎大家点星星，参与测试！
为什么做这个？
因为看到了资源的错配和浪费，很多人有 codex 账号但是用不完，另外有更多的同事不会配置 codex 也不会做技能，最简单的方式就是做好了智能体在飞书上直接开权限给他用。alliy 就是这样的产品思路，但是，要额外收钱。这个项目适合已经有了 codex 不想再交一分钱的同学们。
