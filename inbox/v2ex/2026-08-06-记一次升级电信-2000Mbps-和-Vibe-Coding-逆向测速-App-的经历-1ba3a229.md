# 记一次升级电信 2000Mbps 和 Vibe Coding 逆向测速 App 的经历

最近工作空闲了，终于有时间把拖了好久电信 2000M 给升级了。合肥电信 2000Mbps 还是只给了 40Mbps 的上行真是太抠门了。办理的过程很顺利，营业厅的工作人员也很专业，还特意帮我咨询了是否能继续使用自己的光猫。我之前使用的是 Vsol 的 2.5G 光猫，但是工作人员咨询工程师傅反馈说必须使用电信的光猫，因为现在会一直检查 MAC 是否在线，回头有时间我再试试复制 LOID 和 MAC 能否使用的自己的光猫。

一个很有用的经验是，如果要保留桥接，一定要和业务员说不要下单 FTTR 业务, 只下单 2000M 光猫就好。不然安装的就是 FTTR 设备和网关，是无法改桥接的，不知道别的城市是怎样的。还好我多问了一嘴，不然我多年的公网 IP 就 GG 了。
上午办理完，师傅下午就上门安装了。因为和师傅都是老熟人了，安装过程很顺利。家里的其他网络基建也早都升级到了 2.5G/10G 的设备了，只要更换光猫重新注册就好。电信送的光猫是一个华为的 2.5G 猫，感觉质量还是很可以的。还送了两个 Wi-Fi 7 BE3 的路由器，型号是华为的 TC7620 。查了一下是海思的解决方案，不能刷机，小小遗憾。



安装完之后一切正常，拨号顺利，公网 IP 也还在，丝滑过渡到 2000M 。接下来就是激动人心的测速环节，但是发现之前常用的 Speedtest.net Suzhou ，ZhenJiang 电信节点都没有了，剩下的国内节点全部不可用了。Speedtest.cn 上面也都是没有速度的节点了。寻遍发现现在就中科大的测速网站可以跑了。但是中科大的测速现在也不是很稳定，因为测试的时间太短了，大部分时候速度上不来就结束了。不过也测出了 2030M 的结果。结论就是，现在国内没有一个可以方便的在 CLI 里面测试网速的服务了。
