# 分享一套自己尋思的插件

雖然哈吉人有努力 review,但是難免有些地方寫的比較蛆;主要是哈吉人沒有想到更好的寫法.
主要目標
其實是爲了保護隱私,但是其對瀏覽器時區\語言\指紋的變更可以用在像是 Anthropic 這樣的情景.
主要功能
僞裝

時區
語言(包括 Accept-Language)
位置 API(經緯度信息)
硬件基礎信息(CPU/RAM)
硬件架構(x86-64/Apple Silicon)
Canvas 指紋
IP 地址
