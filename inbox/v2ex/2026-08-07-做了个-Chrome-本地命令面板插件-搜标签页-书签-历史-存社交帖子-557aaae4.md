# 做了个 Chrome 本地命令面板插件，搜标签页/书签/历史+存社交帖子

背景是这样的：我平时开的标签页长期维持在 40-50 个，Chrome 自带的标签页搜索用起来还是要先点一下再滚动找，遇到窗口多的时候更麻烦。之前也试过几个标签管理类插件，要么要注册账号，要么把数据传到云端，我自己是不太放心把浏览记录这种东西交出去的。
索性自己写了一个，思路很简单：一个快捷键（ Cmd/Ctrl+Shift+K ）唤起一个命令面板，输入关键词可以同时搜到当前打开的标签页、书签、历史记录，回车直接跳转或者做一些操作（比如静音、置顶、关闭）。所有索引都是在本地建的，不需要登录，也不会往外发请求。

另外加了一个小功能，是我自己经常需要的：刷 Reddit 、X 、YouTube 的时候经常看到想留着的帖子，之前都是收藏夹一丢就再也找不到了。现在可以直接把帖子内容和链接存到本地一个小库里，之后能按关键词搜出来，导出成 JSON 也行，不绑定任何账号体系。

说明一下限制：这不是一个全能的稍后读工具，遇到平台反爬或者页面结构变动的情况，可能只能存下链接和基本信息，存不全的地方会明确标出来，不会假装抓全了。目前只对 Reddit / X / YouTube / Instagram / TikTok / LinkedIn 做了专门适配，其他网站是通用兜底方案，效果一般。
现在是 Chrome 插件形态，已经上架 Web Store ，Edge 版本也在整理。做这个纯粹是自己每天要用，顺手打磨了一下界面和交互，欢迎大家试用之后来喷体验，尤其是标签页特别多、习惯键盘操作的同学可以感受下差异。
