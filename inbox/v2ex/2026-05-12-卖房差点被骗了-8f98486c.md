# 卖房差点被骗了

前两天中介 C 火急火燎找我，说有客户要做“零首付”，问我要不要卖房。我跑过去聊了，收了定金签了购房协议
回家感觉不对，网上搜了搜，感觉骗局太大了。
先理一下人物：

我：房东
客户 A：表面上的买房人
二道贩子 B：操盘手，躲在后面
中介 C：穿针引线

1. 正常交易应该是怎样的？

假设我的房子实际成交价 100 万。
买家 A 首付：15 万
银行贷款：85 万（最高贷款 85%）
我最终到手：100 万

2. 他们想怎么玩？
目标是：阴阳合同+零首付+额外套现。
具体操作：高评高贷——把评估价做高，让银行按评估价的 85%放贷，多出来的部分套现。

实际成交价 100 万
评估价做到约 142.35 万（ 142.35 × 85% ≈ 121 万）
银行放贷 121 万给我
我私下返还 21 万给 B
我实际到手：121 - 21 = 100 万
客户 A 分具体多少不知道，但是估计半年贷款，然后断供跑路。
和 C 沟通中介费，从 1.5 到 1

二道贩子：

“大家都这么干”，
“我可以把全款先付给你”，
“银行有合作”，
“我只赚我该赚的一部分 4 ，5w”
“反正我们有合同“
我可以全款先付给你
反正我们不会跑路

中介 C：

“大家都这么干”
“银行查不到的”,
”不能走公司合同”,
"很多这种情况"，
“你担心钱到不了你的手里面么”
合同我签不了

局
在这个局中：

客户 A = 职业背债人，人消失无所谓，征信报废也无所谓，他们本来就不是来买房的。
二道贩子 B = 最核心的操盘手，赚走大头，风险最小，从头到尾不出现在台面上。
中介 C = 这盘棋的穿线人，佣金拿了就走，你找不到他追责。
我 = 唯一有资产、有房产、有稳定收入、有正经工作的人。
最终的损失 = 我的房子 + 我的征信 + 可能面临的刑事责任。

钱可以慢慢赚，牢饭我不想吃。
