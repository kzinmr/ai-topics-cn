# 做了个在线简历工具：一个简历，多种版本，用 Claude Code 改起来很爽

最近做了一个小工具：cv.pro (点了没用, 域名还没买下来, support 看网页 footer)
项目地址：
https://cv.ha7ch.com
Repo：
https://github.com/LAWTED/cv-pro
核心想解决两个问题：

简历不应该只有一个版本

同一份经历，投不同岗位时重点其实不一样。
比如：
/xxx?focus=research
/xxx?role=engineer
/xxx?company=alibaba
投研究岗就突出 paper / RA ，
投工程岗就突出项目 / 技术栈 / shipping ，
投产品岗就突出用户理解 / 增长 / product thinking 。
不用再维护一堆 pdf 。

用 Claude Code 改简历真的很爽

以前改简历要打开 Word / Figma / PDF ，改内容、调格式、重新导出、重新上传。
现在就是直接对 Claude Code 说：
这是 JD, 帮我把这份简历改成更适合 AI engineer 岗位的版本。
或者：
帮我突出我在 research 和 HCI 方向的经历。
它改完之后，在线页面直接更新。
不用手动排版，不用重新导 PDF ，也不用到处发新文件。
目前还很早期，欢迎大家试用、提 issue 、找 bug 。
