# AIComplete： Sublime Text 可用的 AI 代码补齐插件（codeium 替代品）

作为一个古早码农，sublime text 一直是我的心头好。虽然这两年使用它的频次迅速下滑...
当初 codeium “横空出世”时，我一度觉得它是我最喜欢的 sublime 插件之一。我甚至为它卸载了 LSP 类插件。就这么用着，一直到最近突然发现“终于不能用了”——其实看着它一路从 codeium 变成 windsurf 再变成 devin 我就隐隐觉得用不长久了。
这两天一开始尝试了好几款其他插件，什么 Tabnine 、CodeContinue 等，感觉都没有 codeium 好用。苦恼之下尝试问 AI 能不能实现一个，结果它二话不说给写了一个！使用体验跟 codeium 几乎一般无二。
如果你也是 sublime + codeium 爱好者，现在你可以试试这个AIComplete，
代码开源在这里（内有详细使用说明）：
https://github.com/ahu/AIComplete
安装方式：

Sublime 里 Package Control: Add Repository → 贴 https://github.com/ahu/AIComplete
Sublime 里 Package Control: Install Package → 贴 AhuAIComplete

友情提示：方法 2 目前还不能用，因为插件提交后还在审核中（据说可能需要好几周起步）

原谅我用了这么土一个插件名，没办法：AIComplete 已经被别人用了 >.<
