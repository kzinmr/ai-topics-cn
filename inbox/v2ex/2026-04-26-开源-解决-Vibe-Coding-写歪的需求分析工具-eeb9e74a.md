# [开源] 解决 Vibe Coding 写歪的需求分析工具

Vibe Coding 时代一句话写代码很容易，但需求模糊就容易写歪返工。
Vibe Coding 需求分析工具。任何 AI 编程助手安装后，自动执行多轮客户调研 → 生成结构化 PRD → 输出技术实现方案。
解决的问题是：Vibe Coding 时代"一句话生成代码"很容易，但需求模糊时产出质量极不稳定。这个工具在编码前强制做需求澄清，记录决策上下文，避免写到一半发现方向错了。
这个工具在编码前做 7 轮渐进式调研，自动生成结构化 PRD ，帮 AI 一次写对。
