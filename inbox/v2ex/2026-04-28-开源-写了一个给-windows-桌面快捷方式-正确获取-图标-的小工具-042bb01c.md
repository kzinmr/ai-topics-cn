# [开源] 写了一个给 windows 桌面快捷方式 正确获取 图标 的小工具

已经 2026 年了，在 Windows 11 桌面平台上，将常用的网页保存为桌面快捷方式时，默认得到的仍然是千篇一律的 chrome 浏览器默认图标，或是因为格式不兼容导致的“白板”报错。这简直是每一位可视化爱好者的噩梦。
