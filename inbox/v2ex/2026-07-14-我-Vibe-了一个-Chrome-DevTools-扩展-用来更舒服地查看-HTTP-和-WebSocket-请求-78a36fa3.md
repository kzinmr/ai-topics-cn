# 我 Vibe 了一个 Chrome DevTools 扩展，用来更舒服地查看 HTTP 和 WebSocket 请求

它是一个 Chrome DevTools 扩展面板，主要用来在调试接口时更清晰地查看请求和响应内容。围绕网络调试里最常见的几件事：找请求、读 payload 、追消息、复制结果。
功能

在 Chrome DevTools 中新增 Request Formatter 面板
自动捕获当前页面已完成的 Network 请求，展示请求方法、URL 、状态码、资源类型和耗时
格式化展示 URL Params、Request Headers、Request Body、Response Headers、Response Body数据
支持查看 WebSocket 握手信息、连接状态、消息列表与消息详情，并格式化展示文本帧中的 JSON 消息
支持在右侧详情区搜索当前请求或连接内容，并高亮匹配结果
支持过滤请求、暂停捕获、清空列表、复制格式化结果
跟随 DevTools 独立主题切换

隐私

数据只在本地 DevTools 中处理，不上传、不持久化

如果你平时也需要经常调试 HTTP / WebSocket 请求，欢迎试用、提建议。
