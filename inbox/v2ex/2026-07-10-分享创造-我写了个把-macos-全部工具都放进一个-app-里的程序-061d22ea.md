# [分享创造] 我写了个把 macos 全部工具都放进一个 app 里的程序

macbook 装的东西太多了，剪切板历史，截图工具，各种 markdown 笔记本，久而久之我的刘海屏都挤炸了，不得不装菜单栏管理软件收纳，但是这软件总是给我电脑整的卡卡的，偶尔有 bug 很不方便。

现在既然有了顶尖模型，不如 vibe coding 一把，我把这些工具全都*统一*收纳到了一个 app 托盘图标里（当然工具都简单重写了），提供统一的可视化面板。

全部工具可以接入到弹出面板的卡片显示，按钮区显示，也可以绑定快捷键打开等等，将他们化为我 app 的一个模块，随意安装，和搭积木一样搭配自己的面板。

目前适配的模块有：
1. 万年历，包括农历，吉凶（根据老黄历数据），可以每日抽签看凶吉（仅供娱乐不要迷信）
2. 截图工具，主要有截图悬浮，图片内划词 ocr ，翻译，复制，以及其他的基础功能（打码，框选，文字等）
3. 剪切板历史，涉及到了图片 ocr ，快捷搜索，快捷呼出搜索面板，快速过滤图片和 url 等。
4. 临时文件柜，在桌面置顶一个临时文件柜，拖放文件
5. 悬浮笔记，快捷键呼出一个置顶的可以折叠的笔记窗口，可以写一些 markdown 的小记录
6. 番茄钟，设置一个周期专注做一件事
7. 电池电量管理，包括蓝牙连接的设备如鼠标的电量自动显示
...

其他工具还没想到要写啥，总之有 gpt 就是好，啥都能实现，我想着未来也可以提供接口给大家自己创造模块，开发上架，嘿嘿。
