# 吕布骑狗新招

安装过 Claude 后，可以再安装一个 aivo 
装好之后执行
echo "alias a1m='aivo claude -k aivo -m aivo/starter --1m'" >> ~/.profile && source  ~/.profile

这样就是一个吕布骑狗的新招了
a1m

我用它日常开发，觉得完全够了，分享给大家
