# 今天给 Berth 连发了 v1.3 和 v1.4 两个版本

今天给 Berth 连发了 v1.3 和 v1.4 两个版本,全是日常高频场景:

📁 拖拽上传——文件从 Finder 拖进终端窗口,自动经 SFTP 传到 shell 当前所在目录。松手前卡片就显示目标路径,同名文件先问覆盖还是跳过,全程不往终端打一个字

🐳 Docker 面板——远端容器 compose 分组、状态色点、端口映射,打开期间自动刷新;启动/停止/重启/看日志,生产警戒主机的操作先过确认

🔑  老格式私钥直接用——阿里云腾讯云下发的 .pem 、OpenSSH 7.8 之前的 key,粘贴即连,自动转换,告别 ssh-keygen -p 。这条来自社区贡献者 coosir 的 PR,开源的美好莫过于此,感谢 🙏

🤖 AI 助手感知当前目录——「看看这个目录下的日志」直接就能干活,没装 shell 集成也能自动探测。这条来自社区 pharaohnie 反馈
