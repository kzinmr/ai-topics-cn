# 做了一个 Qwen Image 3 工具站，想听听大家对产品和 SEO 的建议

最近看到 Qwen Image 3 即将发布，就提前做了一个围绕它的独立工具站：
网站地址： https://qwenimage3.com
目前网站主要包含：

AI 图片生成工具界面
面向新手的使用引导
提示词和图片案例
Qwen Image 3 Prompts
API 、ComfyUI 和模型对比等内容页面
中英文页面
用户注册、登录和积分系统

项目使用：

TanStack Start
React
TypeScript
Tailwind CSS
Vercel
Neon PostgreSQL

目前模型的正式 API 还没有开放，所以生成能力和部分功能仍在继续完善。

这是一个独立社区项目，与阿里云或 Qwen 官方没有关联。

这也是我第一次比较完整地做这种「工具 + 内容 SEO + SaaS 」的网站。目前比较关注下面几个问题：

首页是否能让第一次访问的人快速理解怎么使用？
页面看起来会不会有比较明显的模板感？
定价和积分体系应该怎么设计比较合理？
围绕一个即将发布的模型提前做 SEO 是否值得？
英文文案和移动端体验有没有明显问题？
注册、登录和图片生成流程是否足够直观？

欢迎大家直接批评。
UI 、产品逻辑、SEO 、技术实现等方面的意见都可以。如果遇到打不开、注册失败或者页面报错，也麻烦告诉我使用的设备和网络环境，我会继续修复。
项目地址： https://qwenimage3.com
