## 一、组织架构重大调整

### 1.1 核心高管离职潮

2026年4月，OpenAI经历了一轮显著的高管离职潮，标志着公司从"多线试验"阶段进入"主线收拢"阶段。

**关键离职人员：**

| 姓名 | 职位 | 离职时间 | 后续影响 |
|------|------|----------|----------|
| Bill Peebles | Sora项目核心负责人 | 2026-04-18 | Sora项目被叫停 |
| Kevin Weil | 首席产品官（前Instagram高管） | 2026-04-18 | "OpenAI for Science"计划解散 |
| Srinivas Narayanan | 企业应用CTO | 2026-04-18 | 企业产品方向重组 |

**暂时离岗人员：**

- **Fidji Simo**（AGI部署负责人）：因病休假，曾主导"超级应用"战略
- **Kate Rouch**（首席营销官）：因病休假

**管理层调整：**

- **Greg Brockman**（总裁）：暂代产品管理
- **Brad Lightcap**（首席运营官）：转岗至特殊项目

### 1.2 产品线下架与整合

**Sora视频项目：**
- Sora应用已被正式叫停
- 核心负责人Bill Peebles在社交平台上官宣离职
- Peebles在公开信中回顾Sora从零到一的研发历程，称其为职业生涯中"最荣耀、也最像一场冒险"的经历
- 萨姆·奥尔特曼回应称将"非常想念Bill"，并肯定其创造力推动了整个行业以全新方式体验AI视频

**Prism科学工具：**
- OpenAI已决定停止独立推进Prism项目
- Prism团队（约10人）被并入Codex负责人Thibault Sottiaux麾下
- 后续相关能力将整合进桌面版Codex应用
- Kevin Weil主导的"OpenAI for Science"计划被分散到产品、研究和基础设施等多个部门

### 1.3 战略转型

正如萨姆·奥尔特曼在2026年4月10日博客中所承认的，OpenAI正从"一个混乱但充满冲劲的创业公司"，转向"一个需要以更可预期方式运转的大平台"。他写道，过去几年公司的发展"极其高压、混乱且强度很高"。

在竞争对手Anthropic持续施压、公司又准备在今年晚些时候推进IPO的背景下，OpenAI内部正推动简化产品线，把资源从边缘项目转向更具战略优先级的领域。

## 二、Codex产品演进与重构

### 2.1 产品定位转变

Codex已从单纯的编程工具演变为OpenAI的"超级应用"核心载体。数据显示：

- **每周活跃用户**：超过300万开发者
- **内部使用率**：80%以上的OpenAI员工已在使用Codex
- **非编码任务占比**：50%的Codex用户已在用其执行非编码任务

Codex的使用场景已扩展到写周报、整理反馈、起草产品需求文档、审合同、发安全培训提醒等多个方面。

### 2.2 核心技术更新

**Computer Use（计算机使用）功能：**
- AI能在后台自己开模拟器、修Bug，完全不耽误用户前台工作
- 目前仅支持macOS，欧盟和英国用户暂时无法使用
- Windows端可从其他App拉取信息到Codex里，但还不支持后台光标级别的操控
- 首次获得对Intel Mac的支持

**内置浏览器（Atlas引擎）：**
- Codex客户端内置浏览器，底层使用OpenAI自家的Atlas引擎
- 支持所见即所得的修改体验：用户只需在页面上标注，Codex在后台改代码并实时刷新
- 目前仅限localhost本地预览，未来将扩展到完整的浏览器控制能力

**"心跳"机制（自动排班）：**
- Codex能给自己安排未来的工作日程，到时间自动醒来继续工作
- 支持跨天跨周的持续任务执行
- 可复用之前的对话线程，上下文不会丢失
- 示例：检查Slack、Gmail、Google日历和Notion，生成按优先级排好的待办清单

### 2.3 插件生态系统

OpenAI为Codex一次性上线了90多个插件，覆盖开发团队日常使用的主要工具：

| 插件 | 功能 |
|------|------|
| Atlassian Rovo | JIRA管理、Confluence文档读取 |
| CircleCI | CI/CD自动化、构建失败诊断 |
| GitLab Issues | 需求跟踪 |
| Microsoft Suite | 文档处理 |
| Neon by Databricks | 数据库操作 |
| SharePoint | 文档检索与解析 |
| Superpowers | 本地代码目录分析与功能方案构思 |

用法简单：在输入框中@插件名即可调用。

### 2.4 辅助功能增强

- **记忆功能**（预览版）：记住用户偏好和纠正过的地方
- **GitHub代码审查评论**：集成到Codex工作流
- **多终端标签页**：支持同时开启多个终端
- **SSH远程开发**：接続远程开发机的功能已上线内测（2026-04-20 V2EXで発見、codex_appの内部機能として密かに追加。外部からの検出が困難な「偷偷加了」型機能追加は、セキュリティ監査の観点から透明性懸念材料となる）
- **汇总面板**：实时监控Agent的工作计划、信息来源和产出文件
- **gpt-image-1.5集成**：原生支持图片生成能力

### 2.5 与竞品的差异化

**vs Claude Code：**
- Codex更强调后台执行、多Agent并行和无人值守
- Claude Code的优势在长上下文推理和深度代码理解
- OpenAI为Claude Code制作了官方插件，主动嵌入竞品生态
- 越来越多的团队选择同时使用两个工具

## 三、硬件基础设施战略

### 3.1 算力供应链多元化

OpenAI正积极推进算力基础设施的多元化战略，减少对单一供应商的依赖：

**Cerebras合作：**
- OpenAI已下单Cerebras芯片，并考虑入股
- 作为NVIDIA的备选方案，Cerebras提供高性能AI计算能力
- 这一合作标志着OpenAI在硬件层面的战略调整

**NVIDIA依赖降低：**
- 据36kr（智东西）报道，OpenAI计划投入约**1300亿元人民币**用于芯片供应链多元化
- 目标是减少对NVIDIA的单一依赖，建立更稳定的算力基础设施

### 3.2 能源与基础设施

**核聚变能源合作（Helion）：**
- OpenAI与Helion签下能源采购协议，约定到2035年可购买最多50吉瓦电力（相当于25座胡佛水坝的发电量）
- 奥尔特曼曾是Helion重要投资人，个人净资产与该公司绑定
- Helion技术兑现出现延期，面临资金压力
- OpenAI原拟牵头参与Helion新一轮融资（约5亿美元，估值350亿美元），但最终退出
- Helion已将募资目标下调至2.5亿美元，估值目标降至150亿美元
- 奥尔特曼已于上月辞去Helion董事职务

**太空数据中心设想（Stoke Space）：**
- 奥尔特曼曾推动OpenAI与火箭公司Stoke Space展开更深合作
- 探讨过让OpenAI收购或控股Stoke Space，以支持"太空数据中心"设想
- 奥尔特曼通过家族办公室Hydrazine与Stoke存在财务关联
- 尽管奥尔特曼今年2月在印度公开称"在太空建数据中心"想法"荒谬"，但相关合作讨论仍在继续

## 四、IPO准备与治理挑战

### 4.1 融资与估值

**最新融资轮次（2026年3月31日）：**
- 融资金额：**1220亿美元**
- 公司估值：**8500-8520亿美元**（约合人民币5.8万亿元）
- 领投方：亚马逊、英伟达、软银
- 资金用途：明确用于"超级App"的开发和部署

### 4.2 治理与利益冲突问题

**奥尔特曼个人投资版图的透明度问题：**

据《华尔街日报》报道，OpenAI董事会在2023年奥尔特曼短暂被罢免又复职之后，曾承诺加强对其潜在利益冲突的管理，但这一问题并未真正消失。

**典型案例：**

1. **Helion核聚变公司**
   - 奥尔特曼是重要投资人
   - 曾推动OpenAI牵头参与Helion融资
   - 部分员工认为奥尔特曼在要求自己领导的公司为个人投资背书
   - 一些员工担心内部Slack讨论可能成为法律审查材料，因此避免参与相关讨论

2. **Stoke Space火箭公司**
   - 奥尔特曼通过家族办公室Hydrazine与Stoke存在财务关联
   - 一些OpenAI董事会成员对合作讨论不知情

### 4.3 IPO时间表与准备

- 计划在今年晚些时候推进IPO
- 当前估值约8500亿美元
- 面临资本市场、竞争对手和内部治理的三重压力
- 战略重点从"什么都想做"转向"集中火力"

## 五、竞争格局与市场影响

### 5.1 与Anthropic的竞争

- Anthropic持续对OpenAI施压
- Fidji Simo曾告诉员工，Anthropic的进展应成为一次"警钟"
- 算力巨头们正排队寻求与Anthropic合作
- 头部模型公司的算力需求已发生根本性变化

### 5.2 产品战略对比

| 维度 | OpenAI | Anthropic |
|------|--------|-----------|
| 核心产品 | Codex（超级App） | Claude Code |
| 技术优势 | 后台执行、多Agent并行、Computer Use | 长上下文推理、深度代码理解 |
| 组织状态 | 收缩期，聚焦核心 | 扩张期，持续施压 |
| IPO状态 | 准备中 | 已引发"AI国有化"讨论 |

### 5.3 市场趋势

1. **超级App战略**：OpenAI计划将ChatGPT、Codex和Atlas浏览器合并为桌面端"超级App"
2. **Agent并行化**：多个AI Agent同时在后台工作成为新趋势
3. **插件生态系统**：90+插件覆盖完整开发工具链
4. **算力多元化**：减少对单一供应商依赖，建立弹性供应链
