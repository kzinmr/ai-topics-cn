# CreatorWeave：一个本地优先的浏览器创作工作空间（工作区并行 + 多智能体探索）

我做 CreatorWeave 的初衷很简单：服务纯文本内容创作。
以前创作时，经常在编辑器、浏览器、终端之间来回切，流程很容易断。为了降低上手门槛，我从浏览器环境出发：


打开网页就能开始，不要求先装 IDE 或复杂环境


可以映射你本地授权的文件夹，直接操作本地文件


受浏览器权限模型限制，只能访问你明确授权的范围，不能越权读取未授权文件


这套方式的核心是：尽量保留本地工作的自由度，同时让第一次使用足够轻。
另外我设计了“工作区（ Workspace ）”概念：


多个工作区可并行工作，思路上类似 git worktree


但普通用户不需要理解 git ，也能做多分支并行创作/开发


我也在尝试多智能体协作工作流（参考 OpenClaw 一类思路）：


可以调整默认智能体的角色和工作模式


可以让默认智能体创建其他智能体


我当前主要用网文写作场景测试，比如“作者 + 编辑”等角色协作完成单章写作


这部分还在迭代，离稳定好用还有距离。
Roadmap （接下来）：


持续打磨 Web 端基础体验和稳定性


回补并完善远程控制能力（项目早期做过一版，后续阶段性搁置）


推进 LLM Wiki （可沉淀、可检索、可追溯的知识流）


为 Agent 增强 SubAgent 等能力，提升复杂任务执行质量


👉 在线体验： https://creatorweave.eo2suite.cn/ ｜ GitHub： https://github.com/nutstore/creatorweave
⚠️ 建议用 Chrome 打开，部分 API 在其他浏览器支持不完整或受限
