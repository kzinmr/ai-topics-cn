# 分享一个 MacOS 接绿联 CM818 USB 转 DP 转接器使用感受

分享一个 MacOS 接绿联 CM818 USB 转 DP 转接器使用感受
M4 处理器 + MacOS 15.7 + DELL 老显示器

年初 1 月份购入，刚开始的时候：外壳比体温高，从 sleep 或者单纯熄屏 唤醒显示器慢 可能要 10 秒左右才能唤醒。
使用了几周：外壳没有之前热了，偶尔出现 重新开关显示器才能唤醒的情况。
使用了 1-2 个月：外壳温度偶尔热偶尔不热，显示器唤醒更难了，需要反复多次插拔线(dp 线和 usb 口都得重新插拔) 同时配合重新开关显示器电源，才能唤醒，而且不保证一次成功。
使用了 3 个月：忍无可忍，申请了保修换新，目前使用了几周，发热正常，但是每次主机从熄屏唤醒（单纯熄屏 不 sleep ），都要重新开关显示器电源，否则哪怕等 1 分钟自己也不能自动唤醒。。

这期间转接器一直插电脑 TypeC 口，无论外接屏幕开关，无论主机 Sleep 与否，一直用 MagSafe 口充电 没用到他的充电口。
无法唤醒表现为：主机已经正确识别外接显示器型号、分辨率，Mirror 模式下内屏分辨率已经同步调整了。但是显示器端还提示"No Signal from DP"，即使点了 detect 重新刷新也识别不到信号。
无法唤醒同样发生于通过 TypeC 口连接 iPad ，每次 iPad 熄屏重连时，都需要重新开关显示器才能正常显示。
搜了下现有产品，似乎只找到了绿联做 USB 转 DP 还带 USB3 的 A+C 接口比较友好，看了一些 Thunderbolt 的扩展坞 要外接电源 待机功耗也不低，有什么好产品大家也推荐推荐。。。
