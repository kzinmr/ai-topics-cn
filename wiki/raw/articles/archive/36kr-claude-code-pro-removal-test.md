# Anthropic偷偷移除Pro用户Claude Code访问权

**Source:** 36kr
**Date:** 2026-04-23
**URL:** https://36kr.com/p/3777836165223426
**Categories:** [Claude Code, pricing, Anthropic, subscription model, Agent成本]

## Summary
Anthropic temporarily removed Claude Code from Pro tier pricing page, triggering developer backlash. Rollback after hours — attributed to small-scale test of ~2% new prosumer users. Signal: high-cost AI programming agents are forcing platform to redesign subscription model.

## Key Points
- Claude Code removed from Pro page, Max 5x/20x still included
- Amol Avasare: small-scale test, 2% of new users, existing users unaffected
- Claude Code's long-context, multi-turn, project-level usage exceeds Pro tier fixed monthly cost
- Anthropic already separated "subscription quota" from "real consumption" via Extra Usage
- Enterprise plans: seat fee + API usage separately
- Team plans: $100 premium seat with higher quota
- March 2026: Anthropic doubled free/pro/max/Team 5-hour limits during off-peak
- OpenClaw third-party tool access restrictions added April 2026

## Analysis
This is the beginning of the end of "unlimited monthly subscription" for AI coding tools. As AI agents consume exponentially more tokens (multi-hour agent tasks vs simple chat), the subscription model breaks down. The industry is moving toward "light subscription + heavy pay-per-use" hybrid model.
