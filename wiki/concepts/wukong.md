# 悟空（Wukong）— 阿里企業級AIエージェントプラットフォーム

## 概要

**悟空（Wukong/悟空）**は、アリババグループ（钉钉/DingTalk）が2026年3月にリリースした**企業級AIネイティブ作業プラットフォーム**。OpenClaw（OpenAIのOpeCLaw/OpeCLaw）に類似のローカルエージェント機能を提供しつつ、**企業向けセキュリティ、钉钉生態の統合、RealDocファイルシステム**といった独自の強みを備える。

2026年4月24日、「AI钉钉 2.0」の発表とともに大きく注目され、钉钉全面CLI化により、AIが钉钉の全機能へ直接コマンド経由でアクセス可能になった。

> **出典**: Juejin — [体验完阿里「悟空」，我想把电脑里的龙虾换掉了](https://juejin.cn/post/7618418125198196779) [T1]（15,610読者、91いいね、71スター）

## OpenClaw（OpenClaw）との比較

悟空はOpenClawの機能と類似するが、以下の**3つの本質的な差異**がある：

### 1. セキュリティ — 「降维打击」的な優位性

OpenClawの安全問題が頻繁に報道されている背景がある：

- **3000人のグループで機密情報を漏洩**（10日間育てたOpenClawが大群に機密情報を送信）
- **誤ったクリーンアップで数百通の重要メールを削除**
- **39万以上のOpenClawサイト資産がインターネット上に公開**

悟空のセキュリティ対策：

- **二重のルール体系**: 基本安全ルールは固定で、プロンプト注入でも突破不可能
- **専用サンドボックス環境**: 権限なくしてTXTファイルすら開けない
- **厳格な身元検証**: 悟空は特定のユーザー専用に設計
- **スキル検証**: Skillsも企業検証を経由し、脆弱なSkillsの接続を防止
- **モデル専用サービス**: データはモデル学習に使用されない

### 2. RealDocファイルシステム — 革命的なファイル操作

OpenClawのファイル操作方式は「愚直」：ドキュメント全体を読み込み、修正して全体を書き戻す。これはトークンの大幅な浪費かつ、エラー時のファイル復旧が不可能。

悟空の**RealDoc**は「外科手術」的なアプローチ：

- **行番号・キーワード単位で精准に操作**
- **必要な部分のみを変更**
- **自動スナップショット保存**（ゲームのセーブデータのように、変更前に自動保存）
- **ワンコマンドでロールバック**（壊れた場合に直前のバージョンに即座に復旧）

### 3. 钉钉+阿里生態の統合力

- **淘宝、天猫、支付宝、阿里云**など阿里の全コア業務Bエンド能力の統一インテリジェントエクスポート
- **钉钉AIネイティブファイルシステム**との完全統合
- **钉钉AI表格**に自動エクスポート
- **钉钉会議**の自動予約

## OPT（一人チーム）スキルセット

悟空には**10の業界別OPTスキル**が初期からバンドルされている：

| スキル | 概要 |
|--------|------|
| 一人电商 | 一人でのEC運営 |
| 一人跨境电商 | 一人でのクロスボーダーEC |
| 一人知识博主 | 一人での知識系コンテンツ作成 |
| 一人开发 | 一人での開発 |
| 一人门店 | 一人での店舗運営 |
| 一人设计 | 一人でのデザイン |
| 一人制造 | 一人での製造 |
| 一人法律 | 一人での法務 |
| 一人财税 | 一人での財務・税務 |
| 一人猎头 | 一人でのヘッドハンティング |

**一人开发**スキルは特に注目：開発ワークフローをAIが自動化。

**一人知识博主**スキルは、3日間の最新AIニュースから选题を自動発見、爆発的記事の分解、見出し付き記事の生成、钉钉文档への自動エクスポート、钉钉AI表格への記録、钉钉会議の自動予約までを**5分で完了**。

## 利用方法

悟空には**4つの利用方法**がある：

1. **独立デスクトップ版**: PCに直接インストール（ローカルPCを完全に制御する能力）
2. **钉钉内嵌Agent**: 最新バージョンの钉钉に内蔵されたAgentモード
3. **钉钉モバイルApp**: モバイルからデスクトップ悟空とシームレスに連携
4. **悟空モバイルApp**: 独立した悟空モバイルアプリ

## モデル柔軟性

悟空は**グローバルの主要モデルプロバイダー**を全てサポート：

- Qwen（阿里自社）
- MiniMax
- GLM（智谱AI）
- Kimi（月之暗面）
- OpenAI（GPT）
- Claude（Anthropic）
- Gemini（Google）

カスタムAPIキー、APIアドレス、モデル名で**任意のモデルを自由に接続**可能。

## OpenClawコミュニティの互換性

悟空は**OpenClawのスキル体系と完全に互換**：

- **26,000以上のコミュニティスキル**をそのままアップロードして使用可能
- ClawHub上のスキルを直接ダウンロードしてアップロードできる

これは、OpenClawのエコシステム資産を完全に活用できることを意味する。

## 携帯電話連携

- 钉钉のモバイルでPCの悟空にログインすると、钉钉に**悟空ボット**が自動追加
- **外出先からPCの悟空に指示**を送れる
- **钉钉経由でPCカメラの制御**も可能（権限設定が必要）
- 例：猫の出産監視のために5分おきに写真を撮影、臨産迹象を検知すると即時通知

## 開発者向けCLI化

2026年4月24日の「**AI钉钉 2.0**」発表で、钉钉が**全面CLI化**された。これにより：

- AIが钉钉の全機能を直接コマンドで呼び出し可能
- 開発者のワークフローに钉钉機能がシームレスに統合
- CLIベースの制御により、自動化・バッチ処理が大幅に容易に

## 市場影響

悟空の登場は、中国AI市場に以下の変化をもたらしている：

### 1. OpenClawの代替として

Juejinでは「龙虾漏洞太多...我准备换成企业级、更安全、自由度超高、含阿里生态的悟空」— OpenClawのセキュリティ問題に対する代替として悟空が注目。

### 2. 「一人就是一支队伍」の現実化

钉钉のキャッチフレーズ「当OPT遇见AI，一个人就是一支队伍」— 個人開発者が企業級ツールでチーム規模の生産性を達成可能。

### 3. 計算力インフレへの対応

Token価格上昇トレンドの中で、悟空のリクエスト単位課金モデルは「算力自由」（算力の自由）を提供し、トークン消費の不安を解消。

> 「阿里出手了！终于不怕OpenClaw烧token啦，直接算力自由」
