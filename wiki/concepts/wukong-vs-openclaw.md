# 阿里悟空 vs OpenClaw

## 概要
2026年4月、阿里（Alibaba）の企業級AIエージェントプラットフォーム「悟空（Wukong）」が注目を集め、OpenClaw（コミュニティ名「龙虾」）との直接比較が中国開発者コミュニティで活発に議論された。

## 比較表

| 項目 | OpenClaw（龙虾） | 阿里悟空（Wukong） |
|------|-----------------|-------------------|
| **定位** | 個人開発者向けOSS | 企業級プラットフォーム |
| **強み** | 軽量アーキテクチャ、ClawHubエコシステム | RealDocファイルシステム、企業級セキュリティ |
| **生态** | ClawHub（26,000+スキル） | OPT業界Skills + 釘釘/淘寶/支付宝統合 |
| **互換性** | — | OpenClawスキル体系を完全互換 |
| **課金** | 無料（OSS） | 従量課金（Coding Plan） |
| **モデル対応** | Claude/GPT/Gemini/Qwen/Kimi等 | Qwen-3.5/Kimi-K2.5/GLM-4.7等 |
| **セキュリティ** | コミュニティベース | 企業級（SOC2相当） |
| **中国生態系統合** | 限定的 | 釘釘・淘寶・支付宝・微信 |

## 開発者の声

## 結論
悟空の最大優位性は**RealDoc**（AI改変のロールバック対応）と**中国エコシステム統合**。
一方OpenClawは**並列ツール実行**と**ClawHubの豊富なスキルエコシステム**が強み。
用途によって使い分け：個人開発/実験→OpenClaw、企業導入/本番→悟空。
