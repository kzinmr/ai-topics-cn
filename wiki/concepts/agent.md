# AI Agent（人工知能エージェント）

AI Agentは**大規模言語モデル（LLM）を核とした自律的なソフトウェアエージェント**。LLMが「考える」能力を提供する一方、Agentはそれを「行動」に変換する。

## 基本概念

### LLM vs Agent

2026年4月の中国AIコミュニティでは、**「LLMは単なる"脳"であり、Agentこそが"スーパー従業員"である」**という認識が広がっている。

- **LLM**: 言語理解・生成に特化した基盤モデル
- **Agent**: LLMにツール使用、計画実行、環境認識能力を組み合わせた自律システム

### AI Agentの4大核心技术

1. **LLM（大規模言語モデル）** — 中核の推論エンジン
2. **Agentフレームワーク** — 行動計画・実行のオーケストレーション
3. **RAG（検索拡張生成）** — 外部知識の統合
4. **Skill（スキル）** — 特定のタスクに特化した能力モジュール

## 最新動向（2026年4月）

### 80ページのAgent综述論文の発表

2026年4月、**復旦大学NLPチーム**が80ページに及ぶ**大規模Agent综述論文**を発表。AIスマートエージェントの現状と未来を体系的に整理した。

### Dialogue Agentsの新基盤 — SpokenWOZ

**達摩院（DAMO Academy）**が**SpokenWOZ**というDialogue Agentsの新基盤を発表。音声対話に特化したAgentの訓練・評価環境を提供。

### AI Agentエンジニア技術スタック

中国AIコミュニティでは、**AI Agentエンジニア**の技術スタックと能力育成に関するガイドが複数発表されている。

### OpenCLI — WebサイトをCLIツールに変換

**OpenCLI**は任意のWebサイトを**ゼロコストのCLIツール**に変換するAI Agentインフラ。WSL2/Docker環境でのAgent開発を支援。

### Codex AppのSSHリモート開発機能（2026年4月）

V2EXで「Codex Appが密かにSSHリモート開発機能を追加した」という報告があった。これにより、Codexはローカル環境だけでなくリモートサーバー上での開発も可能になった。

- **SSH接続**: リモートサーバーに直接アクセスしてコードを編集・デバッグ
- **ローカルインストールとの組み合わせ**: 中国国内の開発者がGPT-5-Codexをローカルにインストールし、SSH経由で海外サーバーのコードベースを操作可能に
- **CLIエージェントパターンの拡張**: GUIに依存しない完全なテキストベースの開発フローが実現

📎 出典: [V2EX — Codex SSH機能追加](https://www.v2ex.com/t/1206760) `[Tier-1: V2EX/フォーラム]`
