# GPT Image 2 — OpenAIの次世代画像生成モデル

## 概要

GPT Image 2は、OpenAIが2026年4月末にリリースした**次世代画像生成モデル**。36krの報道によれば、「**屠榜**」（ベンチマーク独占）と評され、競合を大きく引き離す性能を達成した。

## 性能評価

### ベンチマーク結果

36kr（新智元）は「**奥特曼「红色警戒」5个月后，GPT Image 2屠榜，断层领先反杀谷歌**」と報じた。

- Googleの画像生成モデルを**大幅に上回る**性能
- 2026年4月時点の画像生成ベンチマークで**首位**
- 「**断层领先**」（断崖的リード）と表現される差

### デザイナーへの影響

36kr（AIX財經）は「**实测Claude Design与GPT Image 2.0：设计师的饭碗危险了**」と分析。

- グラフィックデザイナーの業務を代替する可能性
- 教育场景での活用（教材、試験問題、科研図表）
- 中国の開発者コミュニティで「**デザイナーの饭碗（職業）が危ない**」という議論が活性化

## 中国教育场景での活用

## GPT Image 2.5 — 速度/精度の2モデル分割（2026-09-08発表・単一ソース・未検証）

V2EXの実測投稿（Wenwener、2026-09-09収集）によれば、OpenAIは2026年9月8日に **GPT Image 2.5** を発表し、GPT Image 2から一転して**2つの独立モデルに分割**した。

| モデル | 位置づけ | 特徴 |
|--------|---------|------|
| **Flare** | 速度型 | GPT Image 2比でスループット2〜4倍、API既定推奨。バッチ生成（EC主画像・SNS素材）で秒級応答と報告 |
| **Sunburst** | 精度型 | 画質はGPT Image 2超。多輪編集で「変えるべき場所だけ変える」主体保持。パートナーHiggsfield AIの「什么不该动を理解する」という評を引用 |

その他主張された変更点（いずれも同投稿 singlesource・本文截断あり・未検証）:
- **@Sketch 涂鸦ツール**: ChatGPT内で草図を描くとAIが成品図化。プロンプト記述の曖昧性回避
- **透明背景の正式対応**: preview状態から脱し、Flare/Sunburstとも真alphaチャネルPNG出力に対応（製品図・ロゴの切り抜き工程が不要に）
- **4K対応**: 最大3840×2160、カスタムサイズは16の倍数、アスペクト比1:3〜3:1、quality 5段階（low/medium/high/xhigh/max）

> **出典**: V2EX t/1240850 — [GPT Image 2.5 正式发布](https://www.v2ex.com/t/1240850)（2026-09-09収集、実測投稿・単一ソース・未検証）

### 続報（2026-09-10）: 局所編集の制御性への不満（単一ソース）

- V2EX 投稿（score 0）: 「只改这里（ここだけ直して）」と指示しても GPT Image 2.5 は他のレイアウトを勝手に作り替える、という体感不満。「改修工数より検収工数が増える」構造を指摘し、多輪連続編集での細部保持を実運用のボトルネックに挙げる。上記 Sunburst の「主体保持」主張とは逆に、実際には制御が甘いという末端観察。冒頭に第三者画像生成サイトの誘導リンクを含む点に留意。全体評価は「進歩はあるが Image 2 初出時の感動は薄い、Image 3 に期待」＝期待値の平常化シグナル。

> **出典**: V2EX t/1241077 — [GPT Image 2.5 最大的槽点](https://www.v2ex.com/t/1241077)（2026-09-10収集・単一ソース・未検証）

### 続報（2026-09-12）: 再現可能プロンプト集の公開（界隈定着のシグナル）

- V2EX（score 0、2026-09-12）: GPT Image 2.5 の**オープンプロンプト集**（30事例・20の編集指示、中英バイリンガル、MIT）が GitHub で公開。運営者は商用サイト gptimage25.ai に関係する本人申告あり（利害留意）。整理過程の報告として「画像を見た≠著者のプロンプトが分かる」を論点に、**画面推导**（画風から逆算）と**編集改写**（公開指示の改変）を区別。X 検索のログイン制限・収录不完全が収集障害になった点もついでに記録。製品新情報ではないが、同一モデルのプロンプト再利用資産がコミュニティ側で体系化され始めた**生態系定着**のシグナルとして参照。

> **出典**: V2EX t/1241594（2026-09-12収集）/ github.com/VulcanEon/insane-gpt-image-2.5-prompts [T1・本人申告の利害関係あり]
