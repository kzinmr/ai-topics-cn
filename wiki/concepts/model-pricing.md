# Model Pricing — AIモデル価格戦略とインフレ動向

## 概要

2026年4月、中国AI市場で**モデル価格の構造的転換**が進行中。「価格戦（価格競争）」から「価値戦（価値競争）」への移行は、主要LLMプロバイダーの値上げ発表によって明確になっている。GLM（智譜AI）、Seedance（可霊）、HY2.0（混元）がいずれもAPI価格を引き上げ、国产モデルが初めて海外大手と同水準の価格帯に到達した。

この現象は [[token-pricing-trend]] で取り上げたトークン単位の従量課金問題とも連動しており、AI業界全体の**「計算力インフレ（算力通胀）」**を反映している。

## 価格転換の具体的データ

### 智譜AI（Zhipu AI）— GLM-5.1

- **2026年Q1**: API価格 **+83%** 引き上げ
- **トークン消費量**: 同期間 **+400%** の急増
- **GLM-5.1コーディングcached token価格**: Claude Sonnetと同水準に到達
  - これは**国产大モデル首次与海外头部厂商价格对齐**（中国製大モデルとして初めて海外大手メーカーと価格が揃った）ことを意味する

> **出典**: 36kr（锌刻度）— [告别价格战，大模型共迎通胀时代](https://36kr.com/p/3777770980300039) [T1]

### 可霊（Kling / Seedance）— 動画生成

| 時期 | 収益 |
|------|------|
| 2025年Q1 | ¥15億 |
| 2025年Q2 | ¥25億 |
| 2025年Q3 | ¥30億 |
| 2025年Q4 | ¥34億 |

- **Seedance 2.0**: 完全な15秒動画を生成可能（従来は5秒+3秒の無駄）
- 動画生成の**商用成功率**は依然として5-10%程度
- **Soraのサービス終了**背景: $30-50/分の動画生成コストに対し、30日リテンション率はわずか1%

### OpenAI — Soraの教訓

Soraのサービス終了は、動画生成モデルの経済的持続可能性の課題を浮き彫りにした:

- 生成コスト: $30-50/分
- 商用成功率: 5-10%
- 30日リテンション率: 1%
- この収益構造では**サービス維持が不可能**と判断

## Agentモードがもたらすトークン消費の指数関数的増加

価格転換の最大要因は、**Agentモード**の普及によるトークン消費構造の変化である:

| モード | トークン消費パターン |
|--------|---------------------|
| チャット | 線形増加（リクエスト数に比例） |
| Agent | **指数関数的増加**（自律的なツール呼び出し・計画・修正ループ） |

小米MiMo（Xiaomi）責任者の羅福莉（Luo Fuli）は「盲目な価格引き下げは避けるべきだ」と警告し、Anthropicが過去に陥った**「低価格→高需要→採算悪化」の罠**を反面教師として挙げている。

> **出典**: 36kr（锌刻度）— [告别价格战，大模型共迎通胀时代](https://36kr.com/p/3777770980300039) [T1]

## 構造的要因の分析

### 1. 計算コストの上昇

Agentワークロードによる指数関数的なトークン需要増に対し、GPUcomputeコストは上昇傾向にある。中国市場におけるGPU制裁（[[gpu-sanctions-china]]）の影響も計算資源の逼迫に拍車をかけている。

### 2. 市場の成熟期への移行

初期段階の「利用者獲得のための補助金競争」から、持続可能なビジネスモデルへの転換期に入っている。値上げは市場成熟のシグナルと捉えられる。

### 3. 能力の収束

中国製モデルが海外大手と同水準の価格に到達したことは、技術的ギャップの縮小を示唆する。GLM-5.1のcached token価格がClaude Sonnetと同等になった事例は象徴的である。

## 価格戦略の2つの潮流

2026年4月時点の市場では、**2つの対照的な価格戦略**が併存している:

| 潮流 | 代表例 | 特徴 |
|------|--------|------|
| **値上げ（インフレ）** | GLM-5.1, Seedance 2.0, HY2.0 | Agent需要増、computeコスト上昇への対応 |
| **価格破壊** | [[deepseek|DeepSeek V4]] | コスト73%削減、競合の1%という破壊的価格 |

この二極化は、AI業界が**「計件時代」（出来高払い時代）**へ移行しつつあることを示している。高付加価値サービスは値上げ、汎用サービスは低価格化という住み分けが進行中である。
