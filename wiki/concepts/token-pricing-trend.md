# Token価格上昇トレンド — 中国AI市場の計算力インフレ

## 概要

2026年4月、中国AI市場で**Token価格の上昇トレンド**が顕在化。「天下苦Token久矣」（Tokenに長年苦しめられてきた）という表現が示すように、計算力不足（算力不足）を背景に、主要AIツールの課金方式がトークン単位の従量課金から、リクエスト単位の定額制・パッケージ制への転換が急速に進んでいる。

このトレンドは、**DeepSeek V4の低価格戦略**（コスト73%減）とは対照的に、**既存サービスの実質値上げ**として捉えられている。

## トークン価格上昇の3大要因

### 1. 算力不足（計算力不足）

主要AI企業の算力（計算資源）が需要に追いつかず、実質的なコスト上昇が発生。

- **DingTalk CEOの発言**: 「この文档が人間と書いているのが分かったら、必ず非難する」— 企業内でAI生成文書の利用が急増し、算力消費が加速
- **OpenClaw（Claude Desktop）でのトークン消費問題**: ユーザーが意図しない大量のトークン消費を「燒token」（トークンを燃やす）と表現し、深刻なコスト不安として報告

### 2. CopilotのOpus撤退

GitHub Copilotが**Opusモデルを削除**し、Qwenへの置き換えを発表。この変更は実質的な**価格上昇**として捉えられている。

> **出典**: Juejin — [Copilot下架opus，Qwen开始按量计费，GLM限制非代码使用，Token都在涨价](https://juejin.cn/post/7631027768982503478) [T1]

### 3. GLMの非コード利用制限

智譜AIのGLMシリーズが、**非コード用途の利用を制限**。この制限は実質的にコスト上昇要因として作用し、コード生成用途に特化した利用を余儀なくされている。

## 価格上昇の具体的事例

### Copilot — Opusモデルの削除

GitHub CopilotがOpusモデルを削除し、Qwenベースのモデルへ変更。これにより、従来Opusで享受していた高性能が低下し、実質的な**サービスレベルの低下+価格不变**（または実質値上げ）となっている。

### Qwen — 按量计费（従量課金）へ

阿里云のQwenモデルが、従来パッケージ課金から**按量计费**（使用量に応じた従量課金）へ移行。これにより、リクエスト単位の予測が困難となり、ユーザーはトークン消費への不安を抱えている。

### GLM — 非コード利用の制限

智譜AIがGLMシリーズで**非代码使用を制限**。これにより、コード生成以外の用途（文章作成、翻訳、要約等）でGLMを利用していたユーザーが、他のツールへの移行を余儀なくされている。

## リクエスト課金への移行 — 解決策としてのCoding Plan

トークン単位の従量課金に対する解決策として、**リクエスト単位課金**（按请求计费）が中国市場で急速に普及している。

### Coding Planの登場

阿里云、火山云、智譜などのプロバイダーが、トークン単位ではなく**リクエスト単位**で課金するサブスクリプションモデルを相次いで提供。

> 「阿里出手了！终于不怕OpenClaw烧token啦，直接算力自由」
> （アリババが動いた！OpenClawでのトークン消費を恐れる必要なし、算力の自由を）

### リクエスト課金モデルの利点

- **コスト予測可能**: トークン消費量に関係なく定額
- **不安解消**: 意図しない大量消費のリスクなし
- **計算資源の最適化**: プロバイダーがバッチ処理で効率化可能

## DeepSeek V4 — 価格破壊との対比

DeepSeek V4のリリースは、このToken価格上昇トレンドとは対照的に**価格破壊**をもたらした。

- **コスト暴降73%**: 従来の同等モデル比で大幅低価格化
- **1%価格戦略**: 競合の1%という破壊的なコスト競争力
- **百万字コンテキスト**: 100万トークンコンテキスト窓を標準装備

> **出典**: 36kr — [是夯爆了还是拉完了？Deepseek V4第一波测评来了（附排行榜）](https://36kr.com/p/3780730845060097) [T1]

この対比は、AI業界が**「计件时代」**（出来高払い時代）へ移行しつつあることを示している。

## 市場影響

### ユーザー行動の変化

1. **Claude CodeのKimi K2.5移行**: 阿里云Coding Plan経由でKimi K2.5を使用するユーザーが増加
2. **国産モデルへの移行**: Claudeの身分認証強化を契機に、国内Coding Planへの需要急増
3. **多様なツール併用**: GLM Pro + GPT Plus、Cursor + OpenClawなど、複数のツールを組み合わせてコスト最適化

### 「外国人による争奪」現象

中国国内Coding Planが外国の開発者にも利用され始めており、価格競争力の高さが国際的にも認知され始めている。

> 「那边Claude强制「刷脸」认证，这边国内Coding Plan被外国人疯抢」
> （向こうではClaudeが顔認証を強制する一方、ここでは国内のCoding Planが外国人に狂乱で奪われている）
