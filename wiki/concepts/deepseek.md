## 概要

DeepSeekは中国を代表するオープンウェイトLLM開発企業。2024年末のDeepSeek-V3でMoEアーキテクチャによるコスト効率の高さを示し、2025年1月のDeepSeek-R1で推論能力（reasoning）におけるGPT-o1レベルの性能をオープンソースで実現し、世界中に衝撃を与えた。2026年に入り、V3.2でAgent能力の強化、Math-V2で国際数学オリンピックレベルの推論能力を実証。次世代モデルV4は1兆パラメータ規模でのリリースが予告されている。

## モデル系列

### DeepSeek-V3（2024年12月）
- **総パラメータ**: 671B、**活性化パラメータ**: ~37B/トークン
- **コンテキスト**: 128K tokens
- **訓練ハードウェア**: Nvidia H800（輸出規制下の制限版）
- **特徴**: MoEアーキテクチャによる高いコスト効率。V2から大幅改善

### DeepSeek-V3.2（2025年12月）
- GPT-5やGemini 3と同等の性能を claiming
- Agent機能の大幅強化
- モデル無料公開（オープンウェイト）

### DeepSeek-R1（2025年1月）
- 推論特化モデル。Reinforcement LearningによるChain-of-Thought能力の獲得
- arXivで3段階トレーニングパイプラインを公開
- R1-0528（2025年5月更新版）でO4-miniに匹敵する性能

### DeepSeek-Math-V2（2025年11月）
- 数学的推論特化。国際数学オリンピック（IMO）で金メダルレベルの正答率

### DeepSeek-V4（2026年4月24日 リリース）

#### リリース概要
- **リリース日**: 2026年4月24日（V4 Preview、公式リリース＋オープンソース）
- **ライセンス**: Apache 2.0（商用・二次開発自由）
- **コンテキスト**: 100万（1M）tokens（全サービス標準）
- **アーキテクチャ**: MoE + CSA/HCAハイブリッド注意機構 + mHC + Engram + Muon最適化
- **訓練ハードウェア**: 華為昇騰910C + Cambricon MLU（Nvidia非依存、完全国産）
- **リタイアメント**: deepseek-chat/deepseek-reasonerは2026年7月24日で完全停止

##### V4-Pro（フラグシップ）
- **総パラメータ**: 1.6T（1.6兆）、**活性化パラメータ**: 49B
- **API価格**: キャッシュヒット入力¥0.025/百万tokens（2.5割引、2026年5月31日まで延長）
- **キャッシュ未ヒット入力**: ¥3/百万tokens
- **出力**: ¥6/百万tokens
- **推論効率**: 単一トークン推論FLOPsがV3.2比27%、KVキャッシュが同10%
- **推論速度**: 8K入力時 単カードDecode約4700 TPS（昇騰950）
- **Agentic Coding**: コード納品品質Claude Opus 4.6非思考モードに接近
- **世界知識**: Gemini-Pro-3.1に次ぐ、全オープンモデル中2位
- **プログラミング・数学・STEM**: トップクローズドモデルに比肩

##### V4-Flash（軽量版）
- **総パラメータ**: 284B、**活性化パラメータ**: 13B
- **API価格**: キャッシュヒット入力¥0.02/百万tokens、未ヒット入力¥1/百万tokens、出力¥2/百万tokens
- **推論性能**: V4-Proに接近した推論能力、単純AgentタスクではV4-Proと同等
- **高速レスポンス**、高コスパ
- **推論速度**: 8K入力時 単カードDecode約1600 TPS（昇騰950）

##### アーキテクチャ革新
1. **Hybrid Attention**: CSA（Compressed Sparse Attention）＋HCA（Heavily Compressed Attention）。1MトークンコンテキストでV3.2比27%のFLOPs、10%のKVキャッシュ
2. **DSA（DeepSeek Sparse Attention）**: トークンレベル圧縮＋スパース注意機構
3. **mHC（流形制約超接続）**: 信号ゲインを約1.6倍に厳密制御
4. **Engram（条件記憶メカニズム）**: 計算と記憶の分離、静的知識をハッシュインデックスで直接参照
5. **Muon Optimizer**: 高速収束と訓練安定性の両立

#### V4のWebインターフェース新機能（2026年4月25日 検証中）
- **高速モード（快速模式）**: 超高速レスポンス。日常対話・クイッククエリに最適
- **専門家モード（专家模式）**: Deep thinkingを有効化。複雑な論理推論・長文対話に重点

#### mHC（流形制約超接続 / Manifold-constrained Hyper-Connectivity）
2025年末に発表。大モデルのパラメータが千亿（100B）規模に拡張した際の「信号爆発」問題を解決。
- 信号ゲインを約1.6倍に厳密に制御
- 超巨大モデルの学習安定性と推論信頼性を両立
- 「算力（計算力）依存」から「アルゴリズム効率」へのパラダイムシフトを象徴

#### Engram（条件記憶メカニズム）
計算と記憶の分離が核心。
- **静的知識**（歴史的事実、コード文法）を拡張可能な巨大検索テーブルに格留
- **動的推論能力**（論理分解、バグ修正）はニューラルネットワーク重みに保持
- ハッシュインデックスによる直接「表引き」で知識取得、冗長パラメータの活性化を回避
- 推論効率3倍向上、GPU HBM（高帯域幅メモリ）依存度を大幅低減
- Needle-in-a-Haystackテスト: 100万tokensで97%精度（内部ベンチマーク）

**意義**: Engramにより、1兆パラメータモデルでありながら活性化は37Bに抑えられ、Nvidia非依存の国産チップ（華為昇騰）での訓練・推論が実現可能に。これは「算力（計算力）が性能を決める」という業界常識を覆す。

#### コーディング能力
V4のコーディング機能は特に注目されている:
- **HumanEval**: 96.2%（V4 Preview、SWE-bench Verified 92.3%）
- **SWE-bench Verified**: 92.3%（Claude Opus 4.6の80.9%を大幅上回る）
- 50+プログラミング言語対応
- 「需求→設計→コード→デバッグ→デプロイ」全链路自動化を目標
- Engramによる長コンテキスト処理能力がコードリポジトリ全体の理解を可能にし、SWE-benchが評価する「実GitHub issue解決」能力に直接寄与

### ▼ 5月19日：特殊文字「<think>」によるモデル幻覚問題とDeepSeek公式対応

**発生日**: 5月18日〜19日
**公式対応日**: 5月19日夕方

5月18日ごろから、複数のユーザーがDeepSeekのWeb版チャットで特殊文字「<think>」を入力した際、モデルが無関係な内容（例：車の購入アドバイスや第三者との会話の断片など）を返す現象を報告。新京報など中国メディアが実際に検証し、問題を確認した。

5月19日夕方、DeepSeekは公式SNSアカウント（小紅書等）で正式な説明を発表：

- 入力文字「<think>」等の特殊文字がトリガーとなり、モデルが予期しない内容を返す現象を確認
- これは**セキュリティ問題やプライバシー漏洩ではなく、特殊文字が引き起こす「モデル幻覚（model hallucination）」**であると説明
- 技術チームによる全面調査の結果、ユーザーデータの漏洩や対話履歴の混入は一切確認されず
- 今後の対策として、特殊文字の識別・処理能力を高めるための**対処的訓練（针对性训练）**を実施し、当該問題を修正する方針を表明

**出典**: 京報網（news.bjd.com.cn 5月20日）、新浪財経（5月20日）

### Agentic Engineering パラダイム — Model + Harness = Agent

DeepSeekのHarnessチーム設立は、より広い**Agentic Engineering（エージェントエンジニアリング）**という業界トレンドの一角をなす。このパラダイムについては → [[agentic-engineering]] を参照。

核心は `Model + Harness = Agent` — 基礎モデルだけではAgentにならず、コンテキスト管理、ツール呼び出し、ファイル読み書き、端末実行、テストフィードバック、エラー訂正・収束の全サイクルを統合した**制御枠組み（Harness）**が必要という考え方。

詳細は → [[agentic-engineering]] の「DeepSeek Harness」セクションを参照。

### DeepSeek、Agent Harnessチーム設立 — Claude Code直接対抗へ

**発生日**: 5月20日

#### 技術詳細（4月30日公開技術レポート「Thinking with Visual Primitives」）

- **ベースモデル**: DeepSeek-V4-Flash（284B総/13B活性）上に構築
- **アーキテクチャ**: DeepSeek-ViT（画像特徴抽出）+ V4-Flash（テキスト推論）+ 空間座標（バウンディングボックス・ポイント）をCoTに埋め込む「Visual Primitive」方式

- **今後の方向性**: 高解像度クロッピングとの統合、自己決定型推論戦略、大規模多様データ（97,984ソース→31,701厳選→4,000万サンプル）
