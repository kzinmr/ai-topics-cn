# Claude Perceive — Claude Codeの新機能

## 概要

Claude Codeに新たに追加された `/perceive` コマンド。2026年5月1日にV2EXで報告された。

## 機能

### /perceive コマンド

- Claude Codeが環境やコンテキストを「知覚」する機能
- 従来のコード生成に加え、より深い状況認識を実現
- MCP (Model Context Protocol) との統合により、外部ツール・ファイルシステム・実行環境へのアクセスを強化

## 文脈

### Claude Codeの進化

- Claude CodeはAnthropicのAIコーディングエージェント
- `/perceive` 追加により、単なるコード生成から「環境認識型」エージェントへ進化
- OpenClaw、Codex、Hermesなどのエージェントとの競争が激化

### V2EXコミュニティの反応

- 「Claude code 现在能 /perceive 了」— 新機能の存在が報告された
- MCPとの統合により、Claude Codeがより自律的な開発パートナーになりつつある
