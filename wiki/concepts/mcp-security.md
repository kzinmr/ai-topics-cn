# MCPセキュリティ — OWASP Top 10とMSB安全基準

Model Context Protocol（MCP）のセキュリティリスクと、それに対応する安全基準。AI Agentが外部ツール・システムと相互作用する際、攻撃面がテキスト空間からツールエコシステム全体に拡張される。

## 概要

OpenClawの爆発的普及により、MCPプロトコルのセキュリティ課題が顕在化。**MSB（MCP Security Benchmark）**は12クラスの致命的隐患を特定し、MCPエコシステム向けの安全基準を提唱した。

> 「過去の大模型安全研究は提示注入など言語レベルのリスクに焦点を当てていた。MSBは、AIがツールを呼び出し実システムと相互作用する際、攻撃面がテキスト空間からツールエコシステム全体に拡張されていることを示した。」 — 36kr/新智元

## 12クラスの致命的隐患

OpenClawの事例から特定された主なリスクカテゴリー：

1. **認証・認可の欠如** — MCP Tool呼び出し時のユーザー認証不備
2. **権限昇格** — Agentが意図しない特権操作を実行
3. **データ漏洩** — Tool経由での機密情報外部流出
4. **提示注入（Prompt Injection）** — 悪意ある入力がTool呼び出しを誘導
5. **Toolチェーン攻撃** — 複数Toolの連鎖呼び出しによる予期せぬ動作
6. **リソース枯渇** — Agentの無限ループ・過剰呼び出し
7. **サプライチェーンリスク** — 第三者MCP Serverの信頼性
8. **監査証跡の欠如** — Tool実行履歴の追跡不能
9. **設定ミス** — デフォルト設定のセキュリティホール
10. **バージョン互換性** — プロトコルバージョン間の脆弱性
11. **クロスオリジン攻撃** — 異なるMCP Server間の干渉
12. **データ改ざん** — Tool出力の中間改竄

## 安全対策の方向性

### プラットフォームレベル

- Tool呼び出し前のユーザー確認（人間在ループ）
- 最小権限原則の適用
- MCP Serverのサンドボックス化
- 実行ログの完全な監査証跡

### プロトコルレベル

- MCP仕様のセキュリティ拡張
- Tool定義の検証スキーマ
- 認証トークンの標準化

### アプリケーションレベル

- Agent開発時のセキュリティバイデザイン
- Toolチェーンの可視化・監視
- 異常検知と自動フォールバック
