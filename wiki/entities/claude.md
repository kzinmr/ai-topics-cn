# Claude（Anthropic）

Anthropicが開発する大規模言語モデル「Claude」シリーズ。2026年4月時点で中国AI開発者コミュニティで急速に存在感を高めている。

## 技術概要

ClaudeシリーズはAnthropicの独自アーキテクチャに基づくLLMで、2025年から2026年にかけて大規模な性能向上を遂げた。

## 最新動向（2026年4月）

### Claude Code Proの削除テスト

Anthropicは**Claude Code Pro**プランの削除テストを実施し、ユーザーコミュニティに混乱が生じた。36krの報道によれば、このテストは製品ラインナップの整理と見られている。

### Claude 4.7 KYC凍結問題

2026年4月、**Claude 4.7**のリリース直後に大規模なアカウント凍結（KYC storms）が発生。Juejinの分析記事では、中国ユーザーを中心に認証プロセスの厳格化による影響が報告された。

### Kimi/GLMへの切替動向

Claudeのアクセス制限やコスト上昇を受け、一部の中国開発者が**Kimi（Moonshot AI）**や**GLM（Zhipu AI）**への移行を検討し始めている。

### Claude Code 32 Skills + MCP統合

Anthropicは**Claude Code**に32のSkillsとMCP（Model Context Protocol）統合を追加。開発者向けワークフローの大幅な強化を図った。

## 市場評価

- **時価総額**: 2026年4月時点でAnthropicの評価額は**1兆ドル（約150兆円）**に達した（36kr報道）
- **中国開発者コミュニティ**: Claudeの性能は評価される一方、アクセス制限やコスト面での課題が指摘されている
