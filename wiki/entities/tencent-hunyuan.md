# 混元 (Hunyuan) — 騰訊自研の大規模言語モデルシリーズ

> **開発元**: Tencent（騰訊）
> **首席AI科学家**: 姚順雨（Yao Shunyu、元OpenAI研究員）
> **最新モデル**: Hy3 Preview（2026年4月） / HY 2.0（2025年12月）
> **アーキテクチャ**: 混合專家（MoE）、快慢思考融合
> **重要度**: 高 — 騰訊AI生態全系の「底座（基盤モデル）」

## 概要

**混元（Hunyuan）**はTencentが全チェーン自研する大規模言語モデルシリーズ。2026年5月時点、腾讯元宝（C端AIアプリ）、WeChat検索、CodeBuddy、WorkBuddy、QQ、腾讯文档など腾讯エコシステム全域に統合されている。2025年末に姚順雨（元OpenAI研究員）が首席AI科学家としてLLMチームとAI Infraを再編し、「実用主義」路線に転換。2026年4月のHy3 Preview公開でオープンソースコミュニティにも参入した。

## Hy3 Preview（2026年4月）— 最新詳細

### 技術仕様
- **総パラメータ**: 295B（MoE）
- **活性パラメータ**: 21B（推論時に実際に使用されるパラメータ）
- **Experts**: 192（top-8活性化）
- **コンテキスト長**: 最大256K
- **MTP Layer**: 3.8B（Multi-Token Prediction）
- **推論効率**: 前代比40%改善（同等精度で少ないトークン消費）
- **ライセンス**: オープンソース（GitHub / HuggingFace / ModelScope）
- **サービング**: vLLM / SGLang対応、OpenAI互換API

### ベンチマーク性能
| ベンチマーク | Hy3 Preview | 備考 |
|-------------|------------|------|
| **SWE-bench Verified** | 74.4% | Claude Opus 4.6は80.8%（追従圏） |
| **Terminal-Bench 2.0** | 54.4% | コードAgentタスク |
| **BrowseComp** | 競争力あり | 検索Agentタスク |
| **WideSearch** | 競争力あり | 検索Agentタスク |
| **IMO-AnswerBench** | 国内トップクラス | 国際数学オリンピック |
| **HMMT2025** | 国内トップクラス | ハーバード・MIT数学コンテスト |
| **HLE（Humanity's Last Exam）** | 大幅改善 | 汎化性テスト |
| **ARC-AGI** | 大幅改善 | 汎化AI推論 |

### 3つの核心突破方向
1. **複雑コンテキスト処理**: CL-bench及びCL-bench-Lifeで上下文学習と指令追随を評価
2. **複雑推論**: FrontierScience-Olympiad、IMO、清華大学数学博士試験などで高スコア
3. **コードとAgent**: SWE-bench、Terminal-Benchで実運用レベルの能力を獲得

## 2026年5月16日〜22日 最新動向

### 1. 腾讯云AI产业应用峰会（2026年5月21日）

5月21日、北京で「2025（原文ママ）腾讯云AI产业应用峰会」が開催され、腾讯の大模型戦略が初めて全面的に披露された。

**湯道生（Tang Daosheng）基調講演**:
- 「四個加速」戦略を発表：大模型創新加速、智能体応用加速、知識庫建設加速、基礎設施升級加速
- 「すべての企業がAI企業になりつつあり、すべての個人がAIによって強化された『超級個体』になる」
- 腾讯の各業務は全面的にAIを採用していると明言

### 2. 混元TurboSとT1の大規模アップグレード（5月21日）

**TurboS（快思考旗艦）**:
- Chatbot Arenaで**全球第8位**（国内ではDeepSeekに次ぐ第2位）、コード・数学で全球トップ10
- 事前訓練のトークン増訓と長短思考連鎖融合技術により、理科推理+10%、コード能力+24%、競技数学+39%向上

**T1（深度思考）**:
- 競技数学+8%、一般常識QA+8%、複雑タスクAgent能力+13%向上

### 3. T1-Vision 視覚深度推理モデル（5月21日正式発表、5月12日元宝先行搭載）

- マルチ画像入力対応、原生成長思考連鎖
- 「画像を見ながら考える」が可能
- 全体効果：従来のカスケード方式比5.3%向上
- 理解速度：50%向上

### 4. Hunyuan Voice 端到端音声通話モデル（5月21日）

- カスケード方式比、応答速度30%以上向上（1.6秒まで低減）
- 擬人性と感情応用能力が大幅向上
- **腾讯元宝Appでグレースケール提供開始**
- 近日中にリアルタイムビデオ通話AI体験を提供予定

### 5. Hy-MT2 翻訳モデル オープンソース化（5月21日）

- 33言語対応の多言語翻訳モデル
- 3サイズ：Hy-MT2-1.8B、Hy-MT2-7B、Hy-MT2-30B-A3B
- 1.25bit極低ビット量子化版は440MB、Apple A15でHy-MT1.5比1.5倍の推論速度
- FLORES-200評価でGemini 3.1 Proに迫る性能
- 金融・政治・教育の垂直領域でGemini 3.1 Proを超越
- 小程序「腾讯Hy翻译」も同時リリース

### 6. 混元Image 2.0 リアルタイム画像生成（5月16日）

- 業界初の**ミリ秒応答**リアルタイム画像生成モデル
- パラメータ数が前世代比で一桁増加
- 強化学習と人間の美学知識アライメントにより「AI臭」を排除
- ユーザーがタイピングや発話しながら同時に画像生成可能

### 7. OpenRouter週間ランキングの最新状況

**4月27日〜5月11日**: 3週連続でOpenRouter週間総合1位を獲得（限定期間終了後も継続）
**5月11日〜17日**: Hy3 previewの週間トークン使用量**2.66兆**で首位を維持
- 前週比**210%増**
- 中国大模型の週間トークン使用量は米国の**1.81倍**（中国大模型が3週連続で米国を逆転）
- DeepSeek-V4-Flash（2.06兆トークン）が2位

## 課題と展望

### 課題
- **C端での存在感**: 元宝でDeepSeekと混元が併存、混元単独でのブランディングが課題
- **微信Agent未発表**: 13億ユーザーのWeChat×AIは最大の潜在力だが、まだ準備段階
- **限定期間終了後の持続性**: 無料期間終了後もOpenRouterトップを維持しているが、有料化後の動向が焦点
- **最高精度での差**: SWE-benchでClaude Opus 4.6に6.4ポイント差

### 展望
- 2026年5-6月にHy3.0正式版リリース予定
- WeChatエコシステムへの全面統合が実現すれば、中国最大のAIユーザーベースを獲得
- OpenClaw/QClawとの連携でAgentエコシステムを拡大中
- 2026年AI投資は前年の2倍以上を見込む
