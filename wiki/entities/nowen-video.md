# Nowen-Video — 軽量家庭メディアサーバー

> **ソース**: V2EX [T1]  
> **カテゴリ**: オープンソース・家庭用メディアサーバー  
> **技術スタック**: Go + React + Docker

## 概要

Nowen-Videoは、家庭用NAS向けに設計された**軽量メディアサーバー**のオープンソースプロジェクトである。EmbyやJellyfinといった既存ソリューションが小規模NASにとって過剰に重いという問題意識から開発された。

「単一バイナリ + SQLite、Dockerでワンクリック起動」を設計理念とし、小規模ホームラボ環境での実用性を重視している。

## 技術アーキテクチャ

| 層 | 技術 |
|----|------|
| バックエンド | Go + Gin + GORM + SQLite（WALモード） |
| フロントエンド | React 18 + TypeScript + Tailwind CSS（Docker内シングルポート） |
| クライアント | Android ネイティブ（Jetpack Compose） |
| デプロイメント | Docker Alpine、単一ポートサービス |

## 主要機能

### メディア管理
- **自動スキャン**: MKV/MP4等9フォーマット対応
- **FFprobeメタデータ抽出**: 自動メタデータ取得
- **リアルタイムファイル監視**: `fsnotify`による即座の反映

### 再生機能
- **ブラウザ互換フォーマット**: 直接ストリーミング
- **HLSオンデマンドトランスコード**: 非互換フォーマットは360p〜1080pで動的変換
- **ハードウェアアクセラレーション**: Intel QSV / VAAPI / NVENC対応

### Provider Chainメタデータスクレイピング
独自の**Provider Chainアーキテクチャ**により、複数のメタデータソースを階層的に活用:

```
TMDb → 豆瓣（Douban） → TheTVDB → Bangumi → Fanart.tv → AI兜底
```

- 中国語コンテンツには**豆瓣（Douban）**、アニメには**Bangumi**を優先
- すべて失敗した場合は**AIメタデータ補完**が最終手段として機能
- ポスター、概要、評価値を自動マッチング

### エピソード識別
- `S01E01` / `第01集` / `EP01` 等の命名形式を自動認識
- シーズン別ディレクトリ構造に対応

### AI機能
- 自然言語検索
- スマートレコメンデーション
- メタデータ拡張
- ファイル名自動リネーム
- AI対話式管理アシスタント（OpenAI / DeepSeek / 通义千问 / Ollama対応）

### ユーザー管理
- 個別アカウント
- 閲覧履歴・お気に入り・プレイリスト
- きめ細かい権限制御
- コンテンツレーティング（年齢別フィルタリング）

### 互換性
- **Emby互換API**: サードパーティクライアントからの接続可能
- 既存のEmby/Jellyfinエコシステムとの緩やかな統合

## Emby/Jellyfinとの比較

| 特徴 | Nowen-Video | Emby/Jellyfin |
|------|-------------|---------------|
| リソース要件 | 軽量（単一バイナリ + SQLite） | 高（専用サーバー要件） |
| デプロイ | Dockerワンクリック | 複雑なセットアップ |
| メタデータ | Provider Chain（豆瓣/Bangumi/AI含む） | 標準ソース（TMDb/TVDB等） |
| 中国語コンテンツ | 最適化（豆瓣優先） | 限定的 |
| スケーラビリティ | 小〜中規模家庭向け | 大規模ライブラリ対応 |
| AI統合 | 組み込み（マルチLLM対応） | プラグイン依存 |
